# 驗證資料閱讀順序

1. independent/QA-RESULT.json：這份凍結模型的獨立結論與限制。
2. INDEPENDENT-QA.md：檢查方法、原始 strict=false 的保留方式，以及未試印限制。
3. source-review/：最終九圖與原始模型的建築來源／外觀審查。
4. v15-full/ 與 v15-recorded-rays/：作者的原始數值資料及每一個 actualhex 警示的精確補證。
5. independent/geometry/：獨立重跑的原始數值、完整射線、切片與全部精確接觸證據。
6. controls/：正反控制完整 archive、原成員 hash index、安全解包與重播驗證。
7. PUBLICATION-BINDING.json 與 EVIDENCE-COVERAGE.json：每個公開原 bytes 的來源對照，以及所有原始結果的覆蓋／私有省略理由。

公開範圍僅由最終明確清單決定。執行日誌、未清理原 PNG、歷次未採用版本與診斷失敗均留在私人備份，不會用修改後的報告取代原始科學輸出。工具控制通過、來源外觀 GO、數值 strict 結果與此模型的有限範圍補證是不同欄位，應一併閱讀。

# 國衛院竹南院區機電中心：初步近似量體（身分信心中等）

這是依公開歷史空拍及舊院區圖對照製作的低細節、初步近似量體。**建築身分為中等信心，並非已由附名近照確認的精確模型。** 不宜用於丈量、工程、現況調查或精確建築辨識。

## 來源與識別限制

1. 國衛院公開院區環景「院區高空2」，畫面標示「2017 春景」。實際檢視空拍中的低矮長翼、加深端部、平屋頂及低女兒牆。
   https://campus.nhri.org.tw/
2. 同一公開環景的院區高空2縮圖。
   https://campus.nhri.org.tw/3dspace/thumb/075.jpg
3. 國衛院《2009年年報》印刷頁95「竹南院區交通及院區圖」。圖上機電中心位於停車庭院一端，廢棄物處理中心位於另一端；用作空拍位置及粗略輪廓的對照。
   https://vod.nhri.org.tw/seminar/AR_2009_CH.pdf
4. 互助營造國衛院竹南院工程實績，列有機電中心1F。
   https://www.futsu.com.tw/p_public.html

來源核對日期：2026-10-11。空拍本身沒有直接標示「機電中心」；身分來自與舊院區圖的相對位置比對，保留中等信心。舊圖不是2026年竣工測量圖；2017年影像不證明當前外觀未改變。包內不含第三方參考照片。

## 已呈現與未確定之處

- 一個低矮、淺色、平屋頂的長翼，與較寬深的端部形成概略L形／退縮量體；加上低矮屋頂邊緣。
- 所有長寬高、端部比例、屋頂高差及背面輪廓都是視覺近似。只能辨識粗略外殼，沒有地面近照支持精細門窗位置，因此保留平整牆面。
- 只製作公開可見外殼，不包含屋頂設備、管線、室內、服務運作或保全配置。
- 為列印穩定性，建築與底座合併成單一連通實體。屋頂的淺凹邊緣直接向外開放，沒有隱藏封閉內殼。
- 整體尺寸：150.0 × 72.0 × 24.8 mm。最長邊含底座為150 mm；建築主體約130 × 50 mm。這是獨立微縮模型，並非與其他院區模型共用比例。

## FDM列印建議

- 底座朝下，以mm匯入。可先使用0.4 mm噴嘴、0.16–0.20 mm層高、3道外牆、10–15%填充。
- 底座厚3 mm；屋頂邊緣寬1.6 mm、可見凸起約1.3 mm。沒有獨立柱桿、薄懸臂或另行裝配的零件。
- 概略形體沒有刻意設計大幅懸垂；仍須在切片軟體檢查後決定支撐及實際參數，不能視為免支撐保證。
- 不建議未重查細節就大幅縮小。預覽材質顏色只供辨識，STL不含顏色。
- 尚未做實體列印或切片軟體驗證。

## 交付內容

- model.stl：mm單一連通列印網格。
- model.obj：通用可編輯網格。
- scene.blend：直接匯入實際STL的可編輯Blender場景。
- previews/front.png、rear.png、elevation.png：實際STL的兩側斜視及正視圖，含完整底座。front/rear僅為模型預覽方位，不宣稱為已測定的官方立面方向。
- build_model.py：可重建的原始碼；無個人路徑或網路依賴。
- render_preview.py：Blender預覽及場景生成腳本。
- requirements.txt、validate_model.py、validation.json：依賴及數位幾何驗證。
- model-info.json、SHA256SUMS：來源與限制摘要、檔案完整性雜湊。

## 重建與驗證

本次使用Python3.12、Blender4.3.2。先安裝requirements.txt的依賴，再執行：

```sh
python build_model.py
blender -b -t 4 -P render_preview.py
python validate_model.py --output validation.json
```

驗證直接檢查原始交付STL的有限座標、已儲存法線及三角形朝向、非退化面、封閉性、每邊兩面、各頂點連結環、單一連通表面殼、無獨立封閉內殼、正體積、平底和150 mm最長邊，再以來源重建比對STL雜湊，並載入已保存的Blender場景比對三角形幾何。驗證不修補交付檔，也不是完整自交檢驗或物理列印合格證明。

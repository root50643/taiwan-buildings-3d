# 臺大34件模型：2026-10-13新增列印幾何補查

這是十批模型完成後新增的輔助檢查，不表示先前已作過，不是實際切片或試印。原凍結檔案均未改動。34個原版中33件在新增截面有效性檢查通過；工科海洋入口段原版發現局部零寬折返輪廓，必須改用同名v2列印修訂版，不增加建物件數。

## 方法與範圍
- 實際STL、固定共享邊端點方向後求平面交點，再以1e-6mm座標取整；每0.2mm、自z=0.071mm起，個別輪廓及組合多邊形均須閉合且valid，禁止用buffer修復吞掉自交。
- 每1mm、自z=0.071mm起，通過閉合/valid斷言後作半徑0.4mm的形態學opening，以面積損失作0.8mm參考特徵指標。尖角、曲面收尖也會被計入；不是最小壁厚、擠出路徑或免支撐保證。
- 此thin v2源自本專案NCU作者修正版；舊版NCU thin工具曾未拒絕不閉合輪廓，NTU此前未使用該thin工具。NTU原0.2mm固定邊方向閉環工具不受該端點方向故障，但原先只查閉合度，不充分排除平面折返自交，故此次新增valid斷言。
- audit-summary.json逐件記STL SHA256，checks逐件保存薄篩與0.2mm有效輪廓結果。所有34個供發布版本（33個凍結版及ESOE v2）均完成上述計算。

## 三件超過1%指標的精確定位
1. 國發所：z=78.071mm，菱形裝飾上方三角山牆的最頂尖，x=-0.305337至+0.305337mm、y=-28至-20mm；當層僅4.885392mm²且全部小於0.8mm opening。距頂78.3mm剩0.229mm。這是尖端收束，不是孤立細柱或主承重牆。切片時頂尖可能被截短或加寬，需檢查最後兩層；支撐不能讓噴嘴解析度變細。
2. 第一學生活動中心：z=38.071mm的16.597%損失主要在折板屋頂左右端尖脊；兩側x=±71.394353至±72mm、y=-24.5至34.5mm，各35.733173mm²，當層寬約0.606mm。是屋頂端斜坡收尖，距頂38.5mm剩0.429mm，不是整片屋面皆薄。切片可能少印頂端細脊；須檢視末端線寬，可接受小幅截頂/加寬再輸出自用版，不應以支撐宣稱解決細節解析度。
3. 地質前棟：z=17.071、18.071、31.071、32.071、44.071mm，損失1.121–1.907%，集中正立面y約-19.4至-14mm的外凸拱窗罩上段及屋簷細節。這些是由0.9mm名義框寬逐漸收尖的附牆拱形裝飾，損失小片多為x向0.71–0.78mm，並非背後實心主牆或獨立柱。保留曲面辨識但可能有局部細節消失；檢查拱頂路徑，必要時為自己的噴嘴另作加粗裝飾版，外凸窗罩仍需評估支撐。

未發現這三件警示指向必須靠孤立薄柱承擔主要量體的情形；這不等同全面強度或壁厚證明。其他31件沒有超過1%指標層，也不代表不存在任何小於0.8mm的細節。

## 工科海洋入口段原版退役與v2
原版z=12.071mm的窗橫框端點，在x=-31.5mm直線由y=-28走至-26，再反向回-26.5，形成0.5mm重疊邊。raw端點與round5至12皆復現，不能歸因round6；拓撲edge2、vertex link與閉合度合格也未排除此問題。
v2只將窗橫框6.2mm改5.8mm，各端縮0.2mm。278層0.2mm輪廓全部closed/valid；56層薄篩最大opening損失0.0396%、0層超過1%。原STL僅供追溯，不列為可印發布檔。修訂後仍需實際切片器與局部支撐評估。

## 重跑
Python3.12與requirements.txt列出的既有套件：

    python check_valid_sections.py /path/to/model.stl /path/to/output
    python thin_canonical_v2.py /path/to/model.stl /path/to/output

腳本不修改輸入STL。以audit-summary.json的SHA256核對實際版本。無來源照片、無私人資料；原有來源與外觀近似限制仍以各模型README為準。

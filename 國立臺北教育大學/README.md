# 國立臺北教育大學｜臺北校區建築模型

第四批新增行政大樓暨圖書館建築群、至善樓、明德樓3模型。行政A＋圖書館H覆蓋2個名冊建物但合計只算1模型；既有9模型逐檔原樣保留。合計12模型、13個命名館舍範圍，其中芳蘭樓仍只有入口局部；其餘量體近似仍有未知面，不代表全校完成。各件自建，最長150毫米含底座，各自獨立比例。

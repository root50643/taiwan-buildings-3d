150mm有界近似。17高拱保留9窗8實交替、22m四坡頂、44m名義圓角方形（42–46m界），兩屋突相鄰近垂直。背／側窗飾未知，素面只是省略，非全四面測繪；最高23.5m為20–27m寬界推估。331跨層高損樣本含角外非零，需獨立及具體例外接受。局部射線非全域壁厚；未試印、不可任意縮小，支撐另判。來源、全數值、重現及SHA見建物頁。

# 吳鳳科技大學・生有樓

原創桌面尺度外觀代表模型，以校方標稱2014的校園空拍為主要視覺基準，另以2025-10樓層配置資料交叉核對平面與核心關係。這些來源不是同年竣工圖，不代表2001落成外觀精準復原，也不代表2026現況。

## 模型內容

- 1–5F較低的兩斜翼，圍繞開放三角中庭；6–9F延續較小的三角高體。
- 正面尖角的三層高入口孔、4–5F跨角量體、入口台階。
- 中庭深廊、分層步道、低於入口的庭底與局部突出平台。
- 高體面向中庭的四道主要上部窗帶；低翼外側、內廊與高體的不同立面深度。
- 分段中央斜屋面、淺色採光面、兩側與高脊附近的大露空構架。
- 兩個缺乏完整實照的斜背面採中性低細節封閉。素面是省略標記，不代表真實建築沒有窗。

不包含鄰接圓中庭建築、白色高樓或完整跨棟天橋。沒有增加完整第十層，也沒有重建講堂座席、內部房間配置或設備。

## 尺度與用途

檔案輸出單位為毫米，底板設計220×186×3毫米；底板不是測量基地邊界。模型長寬、層高、屋脊高差、薄板及柱梁厚度均為相對估計或列印簡化，沒有精準1:N比例。完整成品外接尺寸與原始STL雜湊以最終build-report為準。

這是外觀代表性作品，不適合工程、測繪、消防、室內配置或導航用途。詳細數位檢查與實際試印是不同事項；尚未進行實體試印，不保證任一印表機、材料或擺放方式都會成功。大型門廊、走廊、平台與屋頂需要支撐規劃，見PRINTING-LIMITS.md。

## 檔案與重現

原始參數、CSG建模程式、未修補STL、只使用原STL三角形的Blender場景，以及原創九視圖供核對。場景沒有外部來源照片貼圖。原始驗證失敗紀錄保留；若另有精確補證，必須與原嚴格結果分開閱讀，不能把strict=false改成通過。

影像鍵front/rear/east/west/north/south/top只是固定驗證介面，並非地理方位。圖說應讀作入口斜視、後側斜視、圖面右／左側、圖面下／上正向及俯視；courtyard-gallery是內庭深度，courtyard-arcade是屋頂露空近景。

公開成果只包含原創模型、原創渲染、原始驗證材料與重新撰寫的來源摘要。原始影片、照片、抽幀、CAD/PDF、下載HTML及含內部人員配置的文字均保留私人。

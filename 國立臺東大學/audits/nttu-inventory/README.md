以113學年度45項年報資產＋校圖盤點；資產項不等於獨立樓棟。built表示交付該公開外觀模型，partial保留未完成範圍，evidence-gap表示本次可取得來源不足，並非宣稱網路不存在照片。

## 已交付範圍
第三批已通過父QA3件；鏡心D疑似混棟照片已隔離、不發布、不計數。第四批餐飲中心單件已通過父QA。前兩批7件保持freeze。合計11件可交付外觀模型，不等於11個完整資產項，也不代表全校完成。

## 校圖額外名稱与拆除核對
- 電算中心、幼兒探遊館、教研所：校圖仍有標示；與年報資產及現況別名尚不能逐一對應，保留evidence-gap。
- 仁愛樓、信義樓、和平樓、榕園樓、語教樓：113年報明載108年已拆除，不列現存待建模型。
- 鏡心D：來源導覽標題不夠排除包含A/B，須補官方D單棟定位及正側外觀；E僅年報名稱，需完整外觀與定位。

## 補證據最有用的資料
每棟標明名稱的正面、斜側及屋頂公開照片；若背面沒有資料，仍可簡化，但正面與主要深度不可僅靠校圖方塊猜測。無需室內、設備、住戶或安全配置。

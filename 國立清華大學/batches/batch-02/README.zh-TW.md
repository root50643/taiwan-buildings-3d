# 清華第二批：3件公開外觀近似模型

本批只包含第一綜合大樓、清華名人堂、台積館，與首批3件的manifest分開，避免重複發佈。不是全校完成。

各件最長150mm（含底座），獨立比例；附Python原始碼、STL/OBJ、Blender、實際STL正背與立面預覽、公開來源及近似/支撐說明。

`batch-validation.json` 列這3件的雜湊與驗證摘要。各件18項幾何檢查通過；0.2mm逐層截面抽樣全部閉合。0.8mm XY薄特徵篩查：行政大樓僅一層在太陽能浮雕斜緣/分格交界被標記，已在個別README說明；名人堂、台積館沒有超過0.2mm²警戒面積。這不是正式切片／G-code驗證，尚未實體試印。

大禮堂未製作：[場地頁仍列增改建停借](https://affairs.site.nthu.edu.tw/p/406-1165-56560,r3512.php?Lang=zh-tw)，[君山音樂廳專頁](https://y114.site.nthu.edu.tw/p/406-1615-285200,r11.php)述將於舊址興建；未取得足夠的已完工現況照片，避免把舊照或效果圖當現況。

來源照片未隨成果發佈，校方原始3D模型未擷取。各件僅做公開外觀，不含室內、地下或敏感配置。未見背面統一以明示的素面近似處理。

# 國衛院竹南院區有眷宿舍

依公開外觀及院區配置圖製作的概念微縮模型。這是一棟有眷宿舍的多翼量體，不是兩棟宿舍，也不是精確測量模型。

- 國衛院2011-10-04〈單人宿舍第二期啟用〉明載一期有眷宿舍一棟、一期單人宿舍一棟；不可用房間數當作棟數。
  https://enewse.nhri.edu.tw/jenews_ViewMore.php?indx=8714
- 互助營造竹南院區工程實績列有眷宿舍為地上13層。地下層不在本外觀模型內。
  https://www.futsu.com.tw/p_public.html
- 國衛院官方環景，畫面標示「2017 春景」，第41點「宿舍區圓環」可清楚看見正面、入口及上部量體；第38點「網球場、籃球場」補充側向窗列與屋頂較高端牆。高空視角另有「有眷宿舍」標名。
  https://campus.nhri.org.tw/

## 模型與估計範圍

- 98 × 98 × 150 mm，最長邊是高度。這是獨立微縮尺寸，和其他院區模型不採統一縮尺。
- 四個斜向翼體接中央量體，保留面向入口的內凹立面、十三層窗列節奏、寬窗／陽台凹紋、較高端部實牆及弧形入口棚架。
- 球場視角可見的較窄窗列與立面凹凸亦以保守淺浮雕呈現；只做窗型節奏，不聲稱每扇窗位置或背立面已完整確認。
- 翼長、角度、深度、中央屋頂及未見側後面均為粗略估計。模型用簡化四翼表達公開圖面的輪廓，沒有套用精密施工尺寸。
- 陽台與窗戶為有實體背板的淺凹表面，不製作室內或分戶空間。未加入樹木、幼兒園內部或住戶資料。

## 列印建議

底座朝下，0.4 mm噴嘴、0.16–0.20 mm層高、至少3道外牆、約10–15%填充可作起始設定。底座厚3 mm；主要窗格寬1 mm，端部豎邊厚1.6 mm；入口棚架弧帶厚1.4 mm，兩根前柱直徑2.4 mm。

入口棚架跨距約30 mm、向前伸約13 mm，必須在切片軟體仔細檢查；建議為棚架下緣添加局部支撐。窗凹深約0.8–1.1 mm，通常只需短距離跨越，但仍依機台與材料確認。高塔與薄柱不宜直接大幅縮小。STL沒有顏色，預覽材質僅為顯示。

尚未實體列印，也未以切片軟體驗證；數位封閉性通過不表示保證列印成功。

## 檔案與重建

model.stl為mm列印模型；model.obj為相同通用網格；scene.blend保留實際STL網格、材質與攝影機。previews含正面、後側及正視PNG。build_model.py、render_preview.py、validate_model.py及requirements.txt可重現建模、預覽與驗證。SHA256SUMS核對全部交付檔案。

本次使用Python3.12及Blender4.3.2。安裝requirements.txt後執行：

```sh
python build_model.py
blender -b -t 4 -P render_preview.py
python validate_model.py --output validation.json
```

validation.json包含原始STL法線／面朝向、封閉性、每邊兩面、頂點連結環、一個連通表面殼、無額外封閉內殼、正體積、尺寸及底面檢查。工具另外在臨時目錄重建模型核對STL雜湊，並實際載入保存的Blender檔比較三角形幾何。檢驗不修補交付STL，不宣稱完整自交測試或實體列印合格。

# 國立臺東大學：知本校區第二批四件外觀模型

第一批三件保持不變。本批不是全校完成。

- [鏡心書院主要教學棟](../../知本校區/buildings/zhiben-jinsin-academy-main/README.md)：照片可見的連接式主要教學棟群。未宣稱包含獨立 D 棟或所有附屬量體。
- [行政服務大樓](../../知本校區/buildings/zhiben-administration/README.md)：公開實景確認的主要外牆和開放中庭組合；不是測量級的全棟竣工模型。
- [人文學院廣場側棟群暨演藝廳](../../知本校區/buildings/zhiben-humanities-plaza-complex/README.md)：只涵蓋公開正面廣角照片可見的廣場側主立面、右翼及橢圓演藝廳，未完成全學院後側翼棟。
- [學生活動中心暨綜合體育館](../../知本校區/buildings/zhiben-student-union-sports/README.md)：公開外觀的低矮體育館、露天入口庭院及地景斜屋頂組合；未建立任何室內場館。

每件含最長邊 150 mm STL（含底座）、獨立原始程式、可編輯 Blender、實際 STL 正背面圖片、來源與近似、支撐說明、完整網格／重建／Blender 一致性檢查。另附 0.2 mm 逐層數學截面報告；不能稱作切片器測試或試印。

建物名稱先與校方文章標題和校圖核對。行政大樓建築師的概念模型照片只協助外部配置，與建成實景分開記錄。人文學院僅有一個主要廣場視角，所以模型明確限制在廣場側可見部分，不補造完整後方翼棟。原始參考照片不收入公開套件。

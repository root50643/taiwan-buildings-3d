## 十張預覽是否足夠

已觀看 `front`、`rear`、`left`、`right`、`deck-end`、`back-end`、`top`、`roof-detail`、`bridge-detail`、`underside` 全部十圖。兩張全景與側、端、頂視圖共同顯示完整主要外廓、甲板、層級與雙側翼；細節圖補足桅杆、屋頂及橋，底視圖暴露翼與橋下方，不需要再大量渲染。

局部細節圖本來就會裁切其他部位；完整外廓由全景及正側頂圖補足。少量低對比白面沒有掩蓋主要量體，但不能從這些渲染宣稱已切片、生成支撐或證明可拆支撐。`front/rear` 是模型視角名，不是地理方位。現有 README 將其說為低細節、未定年外觀、非實測，保留不確定高度、隱藏下緣及未試印聲明，沒有看到將這些預覽描述成精密現況的文案。

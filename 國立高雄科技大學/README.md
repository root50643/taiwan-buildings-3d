# 國立高雄科技大學｜校園外觀模型

累積 **4件局部外觀模型**：首批第一西區產創園區A棟主立面段、燕巢圖書資訊大樓入口翼段；本批新增建工行政大樓中央曲面入口段、楠梓水食實習大樓長立面暨入口段。沒有完成整棟測繪；**全校尚未完成**。其他建築繼續列在研究清冊，不以少數模型代表全校。

四件外觀覆核與製作者數位QA通過；首批2件獨立QA已通過且附件逐位元未變，本批2件尚待獨立幾何審核。未執行遠端發布，不是實體試印保證。

## 使用與限制

STL單位毫米，底座朝下；先用自己的切片軟體檢查細件、橋接與支撐。露廊、雨遮、柱廊與架高屋頂可能需要支撐。未知背面採封口，進深及細部為近似；每件README與sources.json列明來源日期和省略範圍。

原始網格、保存法向、單殼、重建SHA、Blend一致、0.2mm全層輪廓valid及thin皆做數位檢查。0.8mm XY形態opening不是全面最小壁厚或工具路徑測試，不保證免支撐或實體列印成功。第三方照片及PDF未收入公開包，只附來源連結。

# 國立成功大學・勝利校區

本校 **42 套**；官方VR勝利分類目前 **4 套**，非全校完成。

[返回學校總覽](../README.md)

本校區目前收錄 4 件數位外觀近似模型；包含局部段或同一財產不同量體，件數不等於完整建物棟數。既有3件含底座最長150mm；新增紀念校門160mm展示寬，非測量縮尺。尚未完成全校，未實體試印或進行印表機切片驗證。

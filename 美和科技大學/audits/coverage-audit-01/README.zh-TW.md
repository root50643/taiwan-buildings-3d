# 美和科技大學逐項覆蓋及缺口

截至2026-10-13，北／南／東三校區原11項研究候選中，本輪完成8件外觀微縮研究，3項仍不足以可靠建模。11項不是已確立的11棟唯一建築；致和軒可能含多棟，C及致美軒亦有完整翼群範圍缺口。不能稱全校逐棟完成。

## 可發布版本
- batch-01：仁發C、傍興D、美和SC
- batch-02-v2：興春G／醫護生技、商學E、民生SB高核心修訂
- batch-03：基礎醫學B、致美軒內院主翼及部分回翼
- 原batch-02不發布。第三方原圖和內部對照不發布。

8件均有150mm含底板独立尺度、重建Python、STL、可編輯blend、實際STL正背預覽、繁中說明、來源URL、hash及驗證。原始STL法向、封閉流形邊與頂點、正體積、單一連通外表面、無分離內殼、重建SHA及blend幾何對照通過；0.2mm截面通過。0.8mm XY形態篩檢仍有SC 2層及G/E各1層>1%面積損失提示，包含角點，不等於完整壁厚或切片器檢驗。未實體試印。

## 尚未建模
- A瑞昌樓：已知入口，不足以確立整個屋頂與側翼。圖書館和4F綜合體育館是同棟用途，不另列。
- F保健大樓：只有院側走廊小照片；需全長立面、屋頂、鄰棟界線。健康促進大樓別名待官方進一步核對，不增加假想建物。
- 致和軒：學務處局部照片未能對上A／B棟。官方PDF確立A棟存在，二手B棟資訊不能代替現況棟界。需官方全棟照片和分棟平面。

## 已建模仍有範圍限制
C僅入口照片可見圓弧量體及左翼，後方翼群未完整辨識。致美軒只內院主翼及部分回翼，不能代表全部宿舍群。所有模型深度、背面與遮蔽部分均是近似，非測繪。官方頁面仍可讀不代表照片拍於2026年。

美和中學、SA托兒所大樓及幼兒園排除。下一步需取得合法公開的全棟多向外觀、較完整校圖或官方翼棟表，再新增不可變修訂版本。校方相簿曾回傳憑證驗證失敗，未繞過安全檢查。

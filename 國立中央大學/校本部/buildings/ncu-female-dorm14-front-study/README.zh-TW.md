# 國立中央大學女十四舍主入口量體研究（局部外觀）｜150 mm 外觀模型

此為公開外觀資料研究模型，非測繪、施工或正式切片檔。每棟獨立縮尺，含底座最長150 mm，不能直接當作同一比例校園拼圖。本檔尺寸約 150 × 83 × 122.8 mm。

## 保留的識別特徵
- 不對稱階梯式正面高低模組與前突陽台遮屏
- 中央深入口凹槽、內縮短橋、半圓入口拱框
- 前方高低成組壁柱、低簷與入口階梯

## 證據與簡化
- 本件只研究主入口立面的主要量體，不是整棟完整模型。兩端延伸附翼、完整基地輪廓與後側未能可靠配準；模型後側以素面平截封閉，深度為目測假設。不得列為女十四舍全棟已完整重建。
- 校方宿服照片與防災圖冊入口近照支持同一主立面。2008年Commons另一側照片顯示不同凹凸與設備，但缺定位平面，僅列後側證據缺口，不把照片當模型rear的同視角對照。
- 校方照片未註拍攝年；2025圖冊日期不是照片拍攝年份。2008 Commons不代表2026現況。
- 窗屏以厚框/凹槽近似，實際密百葉、冷氣、欄杆和玻璃分格省略；入口半圓玻璃僅保留拱框，前方壁柱小圓拱窗省略，頂層屏風與樓板層距粗化。

全部來源及照片/設計圖區分見 sources.json。來源原照片、PDF、內部對照圖不隨模型發布。照片年代不同，不聲稱完整2026現況。

## 檔案與重建
- model.stl：單一連通列印實體，單位毫米
- scene.blend：由交付STL匯入的可編輯網格（不是參數化BIM）；預覽材質只供展示
- build_model.py：可攜參數化量體來源，無需來源照片即可重建
- previews/front.png、rear.png、elevation.png：從實際STL渲染，不是設計效果圖；名稱為相機視角，非精確方位

使用 Python 3.12，依 requirements.txt 準備相依套件，Blender 4.3.2。

    python build_model.py
    blender -b -t 2 -P render_preview.py
    python validate_model.py
    python check_layers.py
    python check_thin_features.py

## 幾何檢查及列印限制
原始STL法線與繞序一致、水密、每邊兩面、頂點鏈單環、單連通表面、無分離內腔殼、正體積、乾淨重建同SHA-256、已存Blender/STL三角幾何一致，詳 validation.json（passed=True）。

0.2 mm幾何截面共 614 層，全部閉合=True。另以1 mm間距檢查0.8 mm XY形態開運算薄特徵，0 層損失面積超過1%；尖角也會被計入，見 thin-feature-check.json。這不是全域壁厚保證，也不是正式切片或試印。

底座平放。中央拱框、入口橋、前突出遮屏與低簷需支撐/橋接評估；深凹入口支撐可移除性尤其要檢查。建議先以0.4 mm噴嘴、0.2 mm層高在實際切片軟體檢查外壁、橋接、支撐可移除性與底板附著，再決定列印設定。小窗框、曲面尖端與薄簷口可能不完整重現；不得將幾何通過寫成「免支撐、保證可印」。

SHA256SUMS含可發布檔案雜湊。尚未實體試印。此為全校持續研究中的一件，不代表全校完成。

## 截面數值方法修訂與補查

本發布包已直接採用canonical-edge-v2薄篩工具與結果，固定共邊插值方向，要求節點度數2、閉環及各Polygon有效，再做1 mm間距的0.8 mm XY開運算。舊版可能因共邊端點分開計算後取整而漏環，不能沿用舊面積值。這項修正不改STL、Blender或重建來源；真實薄特徵警示照常保留。

另以0.2 mm間距逐層補查閉環及Polygon有效性，共 614 層通過，見[有效性報告](contour-validity-check.json)與[可攜檢查程式](check_contour_validity.py)。這項較密補查沒有做薄篩開運算；薄篩採樣間距仍是1 mm。兩者都不是正式切片、試印或全域壁厚保證。

## 目前範圍
- 圖資只做入口段；體健只做五菱窗球館及矩窗翼端側段，未完成連接廳或未知背面。
- 排灣族石板屋是一棟；原保地竹屋、穀倉、地下屋等仍待續接。雕帶以概括浮雕表達，並非藝術原件精確複刻。
- 各學院、宿舍與行政等群棟仍待調查；已核宿舍2025正式舊新名稱見續接。
- 中科、中六、臺北辦事處仍是待調查校外場域。2026施工中的校碑／風雨球場不當完工；預計2030整併的修平不提前当現有暨大校區。
- 地圖項目、使用單位和實體棟數不同，尚未核定全校建物總數。

## 使用與驗證
毫米單位、底座朝下，每件獨立縮尺。下載STL後先自行切片檢查屋簷、遮板與欄杆支撐，避免直接再縮小。

各件附STL、可編修Blend、參數腳本、來源URL、原STL拓撲法向／重建SHA／Blend一致、0.2毫米輪廓與已核fail-closed v3輔助篩檢。數位QA不等於Cura/Prusa工具路徑或實體試印，沒有保證一次成功或不需要支撐。

公開包不重散布第三方照片、PDF或校圖。資料查閱：2026-10-13。

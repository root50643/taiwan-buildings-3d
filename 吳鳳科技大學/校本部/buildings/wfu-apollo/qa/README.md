# APOLLO 主館獨立幾何 QA

本檢查直接讀取生成後的 STL，沒有改動模型，也沒有使用來源照片或 PDF。這是幾何檢查，未產生噴嘴路徑、未進行實際切片或試印。

## 重現

依賴：Python 3.13.9、trimesh 4.12.2、numpy 2.5.4、shapely 2.1.2。

```sh
python independent_geometry_qa.py /path/to/model.stl --json /a/new/directory/qa-report.json --negative-controls
```

若腳本收入模型套件的 `qa/`，可使用：

```sh
python qa/independent_geometry_qa.py models/v1/model.stl --json /a/new/directory/qa-report.json --negative-controls
```

## 負控制

- 從實測模型移除一個三角面：檢查拒絕。
- 將實測模型所有三角面反向：檢查拒絕。
- 在實測模型旁加入分離的 1 mm 立方體：檢查拒絕。
- 正常立方體：自交檢查未誤報。
- 兩個重疊立方體：偵測到 18 組相交／非預期接觸面對。
- 僅共用一頂點的兩個立方體：偵測到 1 個非流形頂點 link。

## 限制與實際失敗

0.2 mm 截層可能略過更薄的 Z 向細節。0.8 mm 侵蝕檢查是截面核心穩定性檢查，不能證明任意方向的全域最小壁厚，也可能漏掉連接於厚本體的薄小突出物。支撐包絡不模擬橋接、擠出、冷卻、收縮、黏床或材料強度；結果不能代替切片器預覽或實際試印。

第一次使用本地 `.venv` 執行，`trimesh.split()` 因缺少可用圖形引擎而拋出 `ImportError: no graph engines available!`，該次沒有有效報告。保留事件於 `failed-first-run.txt`。之後改為腳本自帶的面鄰接遍歷及截線閉環遍歷，正式重跑使用系統 Python 3.13.9 與上述依賴。模型沒有因本 QA 改動。

`qa-report.json` 保留每層數值和負控制結果；報告不含第三方來源圖檔。


## 原碼與場景重現

`verify_reproducibility.py` 重建 STL 到工作區暫存副本，比對原 STL 的完整 bytes，再將已存 Blender 場景中列印物件的方向三角面多重集與 STL 二進位單精度座標比對。實測均一致，五張預覽的雜湊也與渲染清單一致；見 `reproducibility.json`。此檢查不重複渲染，不宣稱 Blender 檔案自身可逐 bytes 重現。

屋脊數學尖端本來逐漸收斂到零寬；最高取樣層核心仍存在不能推論尖端任意高度都超過 0.8 mm。此為實心主館，沒有短暗邊壁或大跨中空屋頂的列印主張。

初次渲染過曝後只調整照明，原幾何雜湊不變，五視圖各重出一次；首輪渲染雜湊保留於 `first-render-hashes.json`，最終原始輸出為 `render-final.stdout.log`。工具與檢查實際失敗、修正紀錄在 `validation-events.json`。

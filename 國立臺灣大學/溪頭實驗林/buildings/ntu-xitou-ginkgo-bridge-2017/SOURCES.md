# 銀杏橋來源、版本與推估界線

本模型為**國立臺灣大學溪頭自然教育園區銀杏橋2017竣工版本的完整外觀近似**，不是施工圖復原、結構計算或2026年現況測繪。研究日期為2026-10-22。原始照片、圖紙、PDF、裁圖與HTML僅供私下研究，**不隨模型包公開**；下列連結指向原出版者，原始資料bytes／SHA256另記於[`sources.json`](sources.json)。

## 一、主依據

### 1. 臺大土木系杜風電子報：2017基本資料與完整平／立面

溪頭木橋設計團隊，〈[銀杏橋基本資料及特色介紹](https://www.ntuce-newsletter.tw/archives/511)〉。HTML發布時間為2017-06-03 09:45:08 UTC，修改日期2017-09-15；[原始平／立面圖](https://www.ntuce-newsletter.tw/wp-content/uploads/2017/06/圖片-1.gif)為738×411像素的單幀GIF。

- **採用：** 2017圓曲版本的完整主橋、直線平面、兩端橋台、兩主墩、左岸轉折接續及階梯；端→峰→谷→峰→端的連續橋面；主橋36m，跨分8＋20＋8m。
- **正式文字數據：** 主橋全長36m、中央跨距20m、總寬2.0m、淨寬1.6m、橋高3.08m；國產柳杉集成材、鋼接合部及RC基礎；2017-05-28啟用。
- **限制：** 小尺寸圖不能用作所有構件的精密測繪；橋高3.08m不直接作模型連地下基礎與底板的總高。本模型僅將主橋長、寬按名義1:120配置，其餘高度與局部構件仍有推估。

## 三、從來源到模型的界線

| 可由來源支持的完整構成 | 模型的推估／簡化 |
|---|---|
| 直線主橋、36m及8＋20＋8m跨分 | 精確曲率、高程與各點微小偏移 |
| 兩個RC主墩；每墩兩側各一扇、每扇四主肋 | 肋截面、曲直程度、扭轉、鋼板內部及接頭厚度 |
| 雙峰中央下凹的連續橋面、側主梁與扶手 | 木板數量、厚度、拼縫及小橋面支架細節 |
| 分格欄的銀杏扇紋／變向斜格 | 欄格精確數、各細木條角度；程式每側30格為規則化表達 |
| 真實透空扇孔、雙排扇架間及橋底負空間 | 小連桿、橫梁及斜撐的截面、節點與間距 |
| 兩端橋台、落岸及左岸轉折階梯 | 橋台深度、露出高度、階數、轉折角與有限接續長度 |
| 柳杉木構、鋼件與RC的材質區別 | 顯示色、風化狀態、木紋及所有微小螺栓數 |

地下聯合基礎、地層與未見構造不宣稱復原。模型額外的薄矩形展示／列印底板不是地形、溪床或實際基地界線。不能為單殼或列印便利而將扇孔、橋底或兩墩之間填實。

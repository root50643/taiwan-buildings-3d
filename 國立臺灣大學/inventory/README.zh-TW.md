# 臺大全校清冊與具體缺口

[返回總圖鑑](../README.md)

已批准40件，仍非全校完成。臺北校區官方2026-08-17索引解析180項只是待核基線，可能包含其他機構、設施或多棟複合體，不能當現存NTU建築總數；敬賢樓代碼仍待核對。外校區候選清冊也不保證完整。

- 人文館：新館多角度照片已取得，翼樓/橋接整體量體仍待確證。
- 鄭江樓：2010 E23照片為已拆農機二館，2018七層新館須用當代照片；已取得官方斜鳥瞰，但另一側與南北棟關係待補。
- 水源校區檔案館W21：入口照片受樹遮，缺側面/屋面。澄思樓W15：已確認出版社使用，待完整公共外觀多角度。
- 竹北科技創研、進修推廣教育大樓：不得把規劃或招標渲染圖當已建成現況。
- 梅峰、南投竹山實驗林管理處、宜蘭等：逐棟盤點，缺現況多角度者不作泛化箱體。
- 化學館、思亮館、計資中心等仍在後續研究，不在本40件發布包內。
- 原中研院原分子所N21等其他機構不計為NTU模型；E62舊環工館/納環館版本關係需查。

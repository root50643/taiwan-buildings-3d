4. [106學年度傳統工藝與創意設計學系新生手冊](https://ccd.nuk.edu.tw/var/file/44/1044/img/604/155948566.pdf)，PDF第5頁／印刷頁碼4，下圖明標 C 棟空間位置；支持兩段長條教室、中央服務核心、前階與兩端形狀。上方 A 主樓二／三層圖不混用。

## C 專屬幾何判讀

- CA–CM 軸線105.50m，端部延伸23.00與20.55m，教室深12.80m；1F+0.20、RF+4.00m，屋頂圖表面+4.45m。剖面寫明覆草與30cm覆土。
- 前側為兩段戶外階梯看臺，中間 C201 平台；中央向外上揚遮棚依剖立面及移出屋面圖共同定位，不在圖紙移出位置另造一棟。
- 四個屋面自然通風口依 RF 圖之窄矩形重建：名目寬1.00m，兩列位置近似，非四個大型方亭。獨立目視審核曾抓出首版過寬，已修正。
- 欄杆、窗分格、階梯細部及服務室外形為微型化近似；後側和遮棚部分主要由設計圖支撐，沒有假稱四面完成照均已確認。
- 草綠、暖土黃、暗灰玻璃及金屬灰來自 C 專屬照片；座階灰色以剖面抿石子標註作中性近似。不是 A/B 色彩套用，也不是現場校色。

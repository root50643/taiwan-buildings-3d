# 高雄美國學校建築研究模型

現行收錄 **1 套模型包**；套件數不等於完整建築棟數，亦非全校／校區完成。

**本件是2016建築師竣工供圖外觀研究模型，不是精密竣工測繪或2026現況。** 刊載高度17.4m，其餘尺寸依圖面比例估算；不含地下泳池、室內或一期教學樓。玻璃不透明、底座為列印用自製，球場線為示意；未實體試印。

建築設計：MAYU architects+ 張瑪龍陳玉霖；攝影：Yu-Chen Tsao 趙宇晨。本件僅含自行重建幾何與模型渲染，不附來源原圖／原照片；公開可讀不等於任意再散布或商用授權。建築設計與攝影權利仍歸原權利人，不由同庫其他素材或通用授權推定本案建築設計／照片的使用權。 [來源與使用說明](校本部/buildings/kas-farrell-athletic-complex-2016/SOURCE-RIGHTS.md)。

2024年8月部分拆除前歷史美術館三翼：官方註記北翼及中翼於2024年8月拆除，南翼仍使用。本件為拆除前三翼有界外觀近似，不是2026現況、現存南翼或新教學研究大樓；絕對尺寸與窗列估計，未知外側中性封閉，0.075–0.15mm細件須放大加粗及切片支撐評估，未試印。

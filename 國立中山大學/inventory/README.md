# 續接狀態與棟界

目前4套近似外觀，國立中山大學全校尚未完成。[精確逐項來源與下一步](continuation.json)區分已做、照片/圖已看尚未建、未研究與確實現況缺口。49個安全圖文件不是49棟。尚未逐棟核清的群棟不得用總數代替。

- 西子灣校本部：官方景觀相簿與安全圖49文件已抽取索引。行政、圖資、逸仙及西子樓已建；西子樓的原單件與六件製造變體合計只算一套。體育館的4張官方照片已實看，可優先續作。
- 西子樓校友會館不是逸仙館別名；已核官方四頁平面／屋頂圖、外觀照片拼圖及沿革頁。[推薦六件製造方案](../西子灣校區/buildings/nsysu-xizi-alumni-hall/manufacturing/v2/README.md)保留供應印向與100% rectilinear等指定條件，原單件仍需支撐。PDF的2022-07-29 metadata不是測繪或刊登日期，照片拍攝日期未知；外部高度依照片估算，不是精密測繪比例，也不宣稱已驗證2026現況。尚未試印、拆brim、乾組或膠合。
- 仁武：2025官方記錄仍涉及試掘與開發；2026預算續有重大工程款，但不能由此推斷教學大樓竣工。舊「預定2023完工」與效果圖不作現況證據。
- 苓雅：2026-03-13基金會議記錄仍為醫學院先期規劃審查。將它與仁武、舊國際商工分清，無竣工外觀證據前不建「既成」樓。
- 東沙：官方確認合作研究設施，外觀尚未研究，不能混成西子灣的一棟或與海管處管理站混名。
- 圖資大樓內圖書館、西灣學院、醫學院不是三棟；逸仙美術館在逸仙館同棟。行政左右相接學院不算已完成。
- 蔣公行館／西灣藝廊於2024修復後為360藝文空間，古蹟名西子灣行館（原高雄觀光館）。下一輪必須看修復後照片，不能用舊相簿的紅瓦白牆外貌代表現在。
- 海資館與遊覽圖海灣館、勵志樓與西子樓等近似名稱，棟界尚待官方圖與資產頁交叉確認，不能只靠名稱猜合併。

附中及海外合作中心不逕視為臺灣大學校本部建物；若之後納入，另明確限定範圍。

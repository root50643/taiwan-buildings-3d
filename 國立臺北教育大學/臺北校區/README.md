# 國立臺北教育大學｜臺北校區建築模型

第八批新增防空洞第一入口地上段、舊警衛室2024可見段、舊琴房山牆簷廊段3模型；既有19模型逐檔原樣保留。合計22模型覆蓋18個主要命名館舍範圍與5個補充／局部範圍，行政A＋圖書館H合計只算1模型。芳蘭樓仍只有入口局部，其他量體近似亦有未知面。18名冊覆蓋不代表所有歷史／附設建物或全校完成。各件自建，最長150毫米含底座，各自獨立比例。

# 國立屏東大學｜屏師校區

現行收錄 **2 套模型包**；數量不等於完整建築棟數，亦非全校／校區完成。新件與既有件的年代、截段範圍及未試印限制請閱各模型頁。

### 既有批次來源與列印限制（數量為各批歷史範圍，非現行總數）


本批只有音樂館圓廳段，未包含相連教學翼、室外樓梯與表演廳。屏師即舊林森；國際學苑A、B棟跨道路仍列在本校區配置，非第五校區。

## 支撐與探針距離的正確意義

**仍有真懸垂，不能稱免支撐。** 以五條最大 0.25 mm 間距採樣路徑，測最近三角面距離並扣半步長，得到連續路徑「中心線到模型表面距離」的保守下界。再減探針半徑 1.5 mm，才是直徑 3 mm 球形探針表面的保守淨空：

| 取用區域 | 中心線距離下界..採樣上界 (mm) | 探針表面淨空下界 (mm) |
| --- | --- | --- |
| 右翼外側 | 3.875..4.0 | 2.375 |
| 左翼外側 | 3.875..4.0 | 2.375 |
| 入口橋下 | 4.674999..4.799999 | 3.174999 |
| 下橫桿下 | 3.875..4.0 | 2.375 |
| 兩橫桿之間 | 3.875..4.0 | 2.375 |

五條掃掠探針皆無碰撞；起終點與完整採樣界見 `support-corridors-v3.csv`。JSON／CSV 欄位 `continuous_clearance_lower_bound_mm` 指的是**中心線距離**，不是已扣半徑的球面淨空；v2 舊摘要所用「路徑淨距」也應按此中心線意義解讀，本 v3 摘要補充並優先使用明確術語。

這些數據證明主要外側懸垂區有名義工具取用通道；四向開放射線也只是一維面心採樣。它們沒有決定真實支撐形狀、黏附或拆除結果。淺窗凹槽、細屋頂唇、桅杆及橫桿仍須在切片器中確認支撐策略、方向及移除順序。**沒有生成支撐、沒有切片、沒有試印。** 本結果為審查候選 GO，保留上述列印限制。

## 重跑方式

四個獨立工具都不修復或重寫 STL；輸出同名檔已存在時拒絕覆寫。從候選包根目錄可按實際工具位置執行：

```text
python qa/independent/tools/independent_qa.py model.stl --out new-qa.json
python qa/independent/tools/independent_geometry_probes.py model.stl --out new-probes.json
python qa/independent/tools/independent_closed_cardinal.py model.stl --out new-cardinal.json
```

附加 CSV exporter 支援 `--stl`、`--out-dir`、`--revision`、`--history-v1`。其輸入 `geometry-probes-{revision}.json` 必須與 STL SHA 相符。依賴 numpy、trimesh、rtree、scipy、shapely；這些是檢查工具依賴，不是 STL 使用條件。

這是竹工凡木設計研究室 CHU STUDIO／邵唯晏團隊的**完整地景式候車亭外觀近似**：可登上的兩片不對稱植草坡、共用前端高屋簷、中央長槽、樹孔與吊網孔，以及下層錯落平台和候車空間。不是站牌小變體，也不是2007北門竹湖旁「竹棧」或2024「蜷蜷亭」。

依2020年校方成果照片、設計團隊提供的公開實拍與圖紙重建，**不代表2026現況，也不是實測、竣工或施工模型**。

## 檔案
- `model.stl`：246×196×60mm，毫米、單一閉合連通網格，無色。
- `model.3mf`：同一組三角座標和面順序；9組可編輯逐面材質，不是已設定耗材或已切片的列印檔。
- `scene.blend`：同一可編輯真實網格、9組材質、相機與燈光；無外部貼圖、照片或內嵌執行腳本。
- `previews/`：前斜、後斜、正立面、頂視、左斜，共5張1200×1200，由最終網格渲染，不是AI概念圖。
- `build_model.py`、`render_model.py`、`rebuild.py`：參數生成、渲染、隔離重建。
- [來源與推估界線](SOURCES.md)、[實際QA與保留警告](QA.md)、`sources.json`、`qa/`、`SHA256SUMS`。

## 保留的建築與必要簡化
- 斜切整體平面、前高水平連接帶、後低雙植草坡；**不是傳統人字雙坡頂**。
- 中央長槽有短平前端、向後開放，沒有填成實牆或玻璃天窗。樹孔保留通孔，不建樹；吊網孔只有下垂格網，不填實心綠面。
- 從候車正面看，左翼有樹孔與較密階台，右翼有吊網及較疏平台；從後面看左右相反。
- 設計者文字確認**29根細柱**。模型有29個下層柱軸：18個依一層平面相對點位近似並為圖紙套準略調至屋緣；後方11個由多角度推估。上層護欄立柱另計，沒有把延伸段當成額外承重柱。**29是來源數量，具體座標不是已知實測值。**
- 保留下層高低木色平台、中央階梯、灰色T形桌、簡化售票／螢幕箱與部分柱燈、柱頂繩包。不刻畫不可辨識的UI、小字、繩結或地下基礎。
- 選用校方2020文件與實拍第8張可見的**白網欄狀態**。官方p27上圖與其餘多張宣傳照只見裸立柱；兩種照片確實不同，不能據此推定拍攝先後或現在的樣貌。
- 護網採稀疏交叉繩、吊網採簡化下垂格網；網結數、張力和節點不是工程復刻。柱直徑1.76mm、護欄柱1.36mm、主要繩線直徑0.88–0.96mm、屋板垂直厚3mm，均為此模型強化／近似值。
- 246×196×2.5mm低灰板是**額外列印／展示連接底座**。上方灰褐色地形僅表達後高前低，裁切邊界與填土體量是近似；不是校園鋪面、擋土牆或實際基地邊界。保留了亭下空隙，沒有用整個實心斜楔取代候車空間。

## 列印限制
**未實印，不保證免支撐。**大面積屋板底面、懸空平台、吊網及細護欄都需要切片、擺向、支撐與製程評估；細網還有斷裂及支撐清除風險。246mm長邊也不代表適用每台印表機的有效列印範圍。縮小模型會同步縮細柱與網線。

原始網格水密不等於可印或強度合格。全局與局部薄件測試的真實失敗保留於QA，不以相鄰厚屋板掩蓋網線細節，也不把侵蝕測試稱作完整壁厚／FFF模擬。

## 可重建、可改色
已驗證Python3.12.14、`requirements.txt`及Blender4.3.2。常規重建不需要網路、字型或原始照片。
```sh
python -m pip install -r requirements.txt
python build_model.py
blender -b -t 8 --python-exit-code 1 --python render_model.py
python qa_model.py
python check_features.py
python verify_exchange.py
blender -b -t 8 --python-exit-code 1 --python verify_scene.py
blender -b -t 8 --python-exit-code 1 --python verify_render.py
python rebuild.py --output ../rebuilt-nycu-shelter
python verify_package.py
```
`rebuild.py`必須使用不存在的新目錄，核對STL、3MF、mesh、palette及5張PNG bytes一致。Blend容器本身不要求逐次bytes相同；已另外驗證其幾何、材質、單色編輯後儲存重開及確定性重渲染。改幾何或材質後需重作QA與來源hash終審，不能沿用本版證據。

本包於臺灣建築物3D模型庫的分類：`國立陽明交通大學/光復校區/buildings/nycu-south-gate-bus-shelter-2020`。未包含第三方原照片、設計圖或PDF。

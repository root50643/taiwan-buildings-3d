# 臺大校總區第二批：5件外觀近似模型

新增綜合體育館、博雅教學館、普通教學館、新月台、第一學生活動中心歷史前棟。五件各自最長150mm，均非測繪與共同尺度沙盤。活動中心僅前棟；其他館舍未見背面與深度亦明確簡化，詳見各館README。

本批5件通過原始STL、來源重建、Blender幾何比對，以及總計1362層、0.2mm間隔的抽樣截面閉合性檢查。新增截面檢查是幾何驗證，不是3D列印切片器測試；沒有試印，不保證免支撐。

## 尚未製作的人文館
已檢視官方2025照片（外部角落、長立面、公共院落及空橋）與國藝會公開高角度院落照。各翼相對位置、全部量體範圍及屋頂關係尚不足以可靠重建。沒有把舊提案模擬圖當現況，也沒有將農業陳列館誤當人文館。詳見humanities-evidence-gap.json。待補全景空拍或多方位現況外觀後續作。

這批不代表全臺大完成。每館附來源連結，照片不重新散布。第一批5件未被修改。

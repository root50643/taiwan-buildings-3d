# 臺灣建築物 3D 模型

依地點整理的臺灣建築外觀模型集，收錄 **604 組模型／列印包**：國立聯合大學 42 組（原38組加二坪山校名柱警衛亭、八甲站2單跨、站1弧形端段與南大門中央門牆共4組）、國家衛生研究院竹南院區 9 組、臺灣各地地標 25 組，另新增下列大專校院 528 組。模型套件數不等於獨立建築棟數，也不表示全校或全國完成。

全庫有 **111 所大專校院至少一套模型**，合計 **571 套校園相關模型**；另有 **33 套非大專校園模型**。下方新增目錄為110校／528套，另計國立聯合大學42套及東海大學路思義教堂1套；東海已在新增目錄中，校數不重複。國衛院9套與其餘地標24套不列入高教校數。

每個地點資料夾保留模型、可編輯原始檔、Blender 場景、實際模型預覽、來源說明與既有驗證資料。點選下方圖片，進入該地點的三欄建築圖鑑；個別模型的詳細資訊可展開查看。

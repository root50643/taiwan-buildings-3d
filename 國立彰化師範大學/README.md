# 國立彰化師範大學｜3D列印外觀模型

目前8件，全部是有實拍依據的局部外觀段；**全校與全棟均尚未完成**。2026-10-20新增白沙大樓歷史入口片段、王金平活動中心湖面側局部及綜合中心弧形入口段；截至2026-10-13已核對兩校區主要地圖/清單，另保留臺中校外宿舍的歷史範圍。

各件採獨立展示尺寸；舊件最長150 mm，本次王金平局部含底座184 mm，均非已知實測比例；可下載STL、Blender及參數程式。第三方照片與PDF不重新散布。數位網格/逐層輪廓检查不等於實際切片工具路徑或實體試印，凸簷、柱廊可能需要支撐。

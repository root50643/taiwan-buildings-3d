# 國家衛生研究院竹南院區：二期單人宿舍

這是依公開竣工外觀照片製作的獨立可列印微縮模型。不是測量模型，也不是整個院區的等比例縮圖。

## 識別與證據

- 瑞助營造的本案頁面明確標示「國衛院竹南院區二期單人宿舍新建工程」、地上 10 層／地下 1 層、設計單位及 2011-08-31 完工日期。主照片用於確認階梯狀突窗、中央玻璃立面、端部實牆與入口外形。模型只呈現地上外觀。
- 國衛院 2011-10-04 院務紀事記載二期宿舍於 2011 年啟用；該文的工程完工／驗收月份與承包商日期屬不同記載口徑，並未把它們當成同一日期。
- 本包未包含第三方原始照片。建築名稱作識別用途，不表示獲官方認證。

## 模型內容與近似範圍

- 底座 150 × 76 mm，整體高 80 mm；以 mm 匯入切片軟體。
- 保留兩側逐段升高的成對多角形突窗、兩側較高實牆、中央凹入窗帶、較高的右側窗塔、入口淺拱與短階梯。
- 窗戶是淺凹紋理，不是穿透孔。深度與左右比例依單張前方照片估計，沒有使用施工圖或丈量數據。
- 未見的後側及側面以簡潔實體面封閉，未捏造窗戶或設備配置。後方預覽刻意如實顯示此證據缺口。
- 屋頂採實體簡化，不製作看不清的設施、細欄杆或室內空間。
- 這是一個建築模型；宿舍房間數不作為建築棟數。

## 列印建議

- 預設底座朝下，建議 0.4 mm 噴嘴、0.16–0.20 mm 層高、至少 3 道外牆、約 10–15% 填充。這些是起始設定，需自行切片確認。
- 底座厚 3 mm；主要窗格間實體至少約 1.1 mm，拱形入口帶厚約 1.4 mm，中央窗帶橫向凸紋厚 1.4 mm。
- 窗凹深約 0.65–0.75 mm；局部凸出横帶與入口雨遮的下緣有短懸垂。切片時檢查其下表面，視材料／機器啟用局部支撐，勿宣稱必然免支撐。
- 底座外挑與小階梯已連成同一實體，沒有分離小零件。若縮小，請重新檢查窗格與入口薄帶，不宜直接縮到 70% 以下。
- STL 本身沒有顏色；PNG 與 Blender 的暖石色只用於預覽。
- 尚未實體列印，也未宣称做過切片軟體驗證。

## 檔案

- `model.stl`：列印用 mm 網格。
- `model.obj`：同一幾何的通用編輯格式。
- `scene.blend`：實際 STL 匯入的可編輯 Blender 網格、材質及攝影機，單位 mm。
- `build_model.py`：可重建的原始建模程式。
- `render_preview.py`：從 STL 重建正面、背面及正視預覽。
- `validate_model.py`、`validation.json`：數位幾何檢驗工具及本次結果。
- `requirements.txt`、`SHA256SUMS`：Python 依賴及檔案雜湊。

## 重建與驗證

使用 Python 3.12，安裝 requirements.txt 的套件；Blender 4.3.2 為本次實際測試版本。

```sh
python -m pip install -r requirements.txt
python build_model.py
blender -b -t 4 -P render_preview.py
python validate_model.py --output validation.json
```

驗證讀取原始 STL 的面法線與座標，不修補交付 STL。檢查封閉性、面朝向、每條邊兩個面、每個頂點連結為單一環、一個連通表面殼、沒有另外封閉的內殼、正體積、底面與尺寸，並在臨時目錄重建比對 STL 雜湊，以及載入保存的 Blender 檔比對三角形幾何。這不等於物理列印合格證，也不宣稱完整自交驗證。

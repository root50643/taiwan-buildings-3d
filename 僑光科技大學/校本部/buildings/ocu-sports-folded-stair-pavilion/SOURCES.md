# 來源與實景登錄

主來源：[境向聯合建築師事務所：Overseas Chinese University Leisure and Sports Center](https://eds-tw.com/en/eds_projects/overseas-chinese-university-leisure-and-sports-center/)。建築師標示 2012 年完工；照片拍攝日期未知，網址中 2024/08 是上傳路徑，不是攝影日期。

- **e0** 總覽竣工照片前景棚：確認步道側紅橘凹入面、開口、欄杆、屋頂折線與大小三角天窗。
- **e3** 反向竣工照片前景棚：旅館位置反轉及前景次序支持為同一物件，確認跑道側長實牆、主要斜面與天窗。不能把後方另一座棚拼接為本棚。
- **e1 是實體設計模型**，不作竣工幾何證據。
- e4/e5 樓梯／坡道提供整體語彙背景，未具名指定到這座棚，因此不複製其精確階數、坡度或完整地下平面。
- [台灣建築雜誌建築師撰文](https://www.ta-mag.net/ta/News.php?id=586)：2013/11 第 218 期，網頁 2015-08-21，說明折板意象、東西向垂直出入口及色彩導引。
- [建築師雜誌頁](https://www.twarchitect.org.tw/works/僑光科技大學多功能休閒運動中心/)：2015/08，重複刊登的總覽與旅館照不計為獨立新角度。

本模型不是整棟實習旅館或全運動中心。沒有取得量測平面；不同來源總面積數字不一致，均未用於此棚定尺。所謂東側較北一座只依建築群文字方向推定，非官方編號，標題不宣稱編號。

## 去重
建模時檢視既有 `僑光科技大學/校本部/buildings/ocu-library-information` 的 README 與路徑樹：它是 2007 年圖資大樓，圓筒冠環及高低翼，與此 2012 年小棚不同。Library 以 slug／中文名稱搜尋未找到對應標題；搜尋索引不等於完整列舉，主要去重依 repository 路徑和來源物件。

參考照片只供私下研究，**不隨交付、Library 備份或 Git 套件再散布**；預覽均是交付網格的 Blender 渲染。

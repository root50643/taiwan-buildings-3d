博愛校區新圖書館：2020竣工／2021啟用的整棟地上外觀有限細節近似，混合官方樓層導覽、實景與屋頂正射；來源拍攝日期未定，不是精確2021復原、已核實2026現況或測繪縮尺。六個地上高度區段並非六條等高窗帶；保留不對稱外緣、東北低層退縮、西南上層退縮、東大簷、北凹棕柵/玻璃塊、南開放格柵與東南核心。未知西立面細節中性化，中央暗頂不判定天井覆蓋/深度，155.81m²屋突為樓地板面積非投影/高度，不加完整屋頂樓層。212×216×140.15mm為含展示底板正規化尺寸；10材質3MF、STL、原生Blend和470隱藏建構元件、公開Python及9張實際圖。隱藏重疊元件不可直接與成品同印；無地下三層、室內、1972舊館或2008未建競圖。0.85mm棕柵、1.2mm格柵梁與0.65mm附著窗框浮雕，以及大簷/懸挑需支撐和近220mm列印床邊距評估，尚未試印；不作工程/避難/無障礙動線依據。

# 政大公企中心整案模型：獨立審查摘要

審查日期：2026-10-16。對象為住宿棟、會展棟及公共連接的一整套外觀近似模型，底座 150 × 130 mm，總高約 126.87 mm。

## 結論

原始幾何、保存場景、來源重建與完整交付內容已完成獨立審查。沒有發現原三角面的非法自交／共面面積重疊，也沒有低於 0.8 mm 的已採樣第一材料弦長。仍有 **4 條原射線的共面邊界旗標**；審查僅接受這四條原線沿邊界行進的限定例外，原嚴格結果仍為 **strict=false**，完整檢查入口仍回傳非零。不能宣稱所有嚴格檢查均已通過。

## 已驗證範圍

- 30,186 個原三角面，單一封閉外殼、正體積；精確座標邊連接、頂點連結環、面朝向及儲存法向通過。沒有修補、刪面或座標取整。
- 全部原面對以精確閉包圍盒篩選，383,193 個候選逐一做精確交集檢查；只允許原本共享頂點或完整共享邊，非法交集為 0。
- 0.2 mm 間距、0.031／0.071／0.137 mm 三個偏移，共 1,903 層、4,338 個原始 Polygon。逐一有效，0.8 mm 開運算無消失或分裂；每個損失均保留，最大面積損失約 0.950%。
- 每個原面十個固定法向樣本，共 301,860 條。已採樣最短第一材料弦為 0.9198865 mm，低於 0.8 mm 者為 0。四條旗標各重新遍歷全部 30,186 面，保留原點、原方向、交點及完整材料／邊界／空氣區間，沒有改換射線或清除原旗標。
- 保存的 Blend 重開後，原始有向三角面完全一致。隔離重建的 STL 與七張 PNG 均逐位元組相同；一般 Python、Python -O、Blender 例外退出及指定負控制已核驗。
- 原完整包 217 檔、精簡公開包 228 檔及其壓縮證據已核對雜湊、內容與隱私；七張 PNG 的解碼、CRC 與中繼資料檢查通過。未包含來源照片、街景截圖、私人研究板或 bytecode 快取。

## 四條旗標的範圍

一條原射線穿出住宿外牆後，沿凹窗邊界行進，經空氣段後又沿上庭園斜樓梯盒屋面行進；另外三條沿設備圍屏邊界行進，再穿過另一段實體。精確幾何補證沒有漏列橫向交點，仍完整保留原奇偶／交叉方向相關旗標。這些個案不提供所有方向、所有位置的壁厚保證。

## 比例與列印限制

本件依 2021–2022 公開影像作外觀近似，並非測繪。採用的高度方案為住宿主屋面 49.4 m、主要屋突頂 58.5 m，會展主屋面 45.5 m、主要屋突頂 53.5 m，中央庭園 34.5 m。來源所載 49.4 m 的標高定義未釐清；若其已包含最高屋突，仍存在較低的替代解釋。校方明示的 4F／6F 廊橋及模型中的橋間、橋下空隙均保留。

尚未實體試印；廊橋、凸盒及部分屋突需要切片與支撐規劃。有限切層與法向採樣不等於全域壁厚證明、切片工具路徑驗證或特定機器的成功率保證。

精簡包為 228 檔，只外置 `qa/dense/dense-original.csv.gz`：31,248,909-byte gzip、248,127,151-byte 解壓內容，含全部 301,860 條原射線及四條旗標。這是完整診斷資料，不是「全通過快取」。四旗標的原始 rows、逐 Polygon 損失、全部交集、短弦／失敗檔及原科學程式仍隨包保留。原外層程式、manifest、validation 和負控制報告的原 bytes 另留作歷史追溯。

在解壓後資料夾，用本包 STL 與原碼即可重建並保留完整 CSV，毋須登入或私人檔案：

```sh
python -B replay_dense_cache.py --out ../nccu-public-center-cache/dense-original.csv.gz
```

獨立重建驗得 gzip SHA-256 `8f44fc56b4aa937bbfde7966becf7f663876509a84f12ae7f13b7ae9622b0ead`，解壓 SHA-256 `a4b9ef13468cbbd4d5163dd9e0f9a93a2a0747a97704e935e5db7e80dacfa1f9`，並保留原四旗標與 strict=false。重建工具返回 0 只表示診斷檔精確重現。參考環境及其他平台 hash 不符即停止的限制見 README。

配送完整性、讀取已重建的完整證據、本次科學重跑分開記錄。配送門返回 0 時，`full_evidence_verified` 與 `current_science_replayed` 仍為 false；完整模式缺 CSV、錯 CSV、偽 metadata 重綁或假舊成功報告均須拒絕。

```sh
python -B run_checks.py --out ../nccu-public-center-full-replay
```

`--out` 必須是尚未存在的外部資料夾；不需先手動 build/render。獨立執行完整 `-B -O` 入口，16 個有序階段均完成：重建 CSV、原幾何、原面交集、場景重開、STL／七 PNG 重現與 17 項彙總負控制均重新執行；包內 228 檔未被改寫。當次 `current-run.json` 的 `current_science_replayed` 與 `full_evidence_verified` 為 true；原幾何及最終嚴格彙總依四旗標返回 1，`strict_passed` 仍為 false。另以一般 Python 與 `-O` 執行共 28 項獨立外層控制，缺檔、內容或壓縮 bytes 錯誤、偽造歷史鏈及異常摘要均正確拒絕。

# 國立成功大學・光復校區

[返回學校總覽](../README.md)

本校區目前收錄 19 件數位外觀近似模型；包含局部段或同一財產不同量體，件數不等於完整建物棟數。原16件含底座最長150mm；波簷尖峰片段為104mm展示底座寬，小西門為108mm展示寬，懸鏈・榭歷史實作亭為約157mm展示寬，各件獨立縮尺；懸鏈・榭場址為成品與校方院照交叉定位推論，不表示目前仍存。尚未完成全校，未實體試印或進行印表機切片驗證。

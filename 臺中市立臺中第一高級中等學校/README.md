# 臺中市立臺中第一高級中等學校建築研究模型

現行收錄 **1 套模型包**；套件數不等於完整建築棟數，亦非全校／校區完成。

**本件為2012年調查報告 A 組所記錄的主要完整外殼，不是原始竣工狀態、B組修復提案或今日修復後現況。** 原委託校名「國立臺中第一高級中學」為同校歷史名稱，不另計學校。名義1:150；軸線尺寸不等於最外廓，圖面高程差、估配厚度、淺浮雕封窗與平坦展示底座等限制詳見模型頁。沒有實體試印，網格與格式檢查不代表列印成功。

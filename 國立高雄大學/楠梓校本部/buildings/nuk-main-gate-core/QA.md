# QA 範圍

以 QA.json 與 BLEND-QA.json 的實際最終結果為準。驗證 finite vertices、正面積、封閉一致法向、單連通、每邊兩面、STL逐三角及3MF頂點/面/材質、Blender重開一致性。

字形三角化在float32輸出可能出現共線零面積面；build_model.py對這些面執行最短邊合併修復，詳細長度記錄於font-mesh-repairs.json，修復後再次全網格驗證。最終此版紀錄為空（已消除原始產生條件），沒有實際執行邊合併。不是忽略失敗。

這些測試不等於真實建物完整性、可列印壁厚或實體試印；未知反面／尺寸估計與薄格柵、字形及簷口限制仍保留。預覽僅限定照片所支持中央核心外觀。

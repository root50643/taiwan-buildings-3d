# 來源與可支持範圍

- [校園景觀今昔／2022活動中心與2009池側照片](https://sh.isu.edu.tw/page/校園景觀今昔-5UF7o1RYZC57)：四坡、北門廊四柱、上2下2窗排、東池側分組窗；照片年份依校方標註

- [官方工程海報第7頁](https://eng.isu.edu.tw/storage/files/UuJr3MRt1GiTGDAls9NUhVP6mgjpx7lMi13fZpAz.pdf)：正面柱跨、入口三角玻璃及背後通空；未提供樓層剖面

- [官方場地照片PPT第9頁](https://oga.isu.edu.tw/storage/files/Km6DE8Ph3SQ88EewcwBKUTZiNGcOFIdxJlsVppNg.pptx)：東南池側及下部窗列局部；攝影年份未明

- [官方校園設施說明／無障礙總圖](https://oga.isu.edu.tw/storage/files/mDrRiJ3FWKbLjmbwCPSHP6YqN7K78kYm6vi0UhY8.pdf)：館界、入口、東平台與相鄰設施；非建築各層平面

- [校園環境照片](https://oga.isu.edu.tw/page/校園環境Photos-LZZQhXv3dcPW)：西側/西南園地視角，樹遮下部未推測背窗

- [校史初生](https://sh.isu.edu.tw/page/初生-2CjodIM2CtZS)：B1＋5F；地坪2563/2569平方公尺與1988/1989時序口徑矛盾，不反推模型尺度

- [NLSC正射：圖內2024](https://wmts.nlsc.gov.tw/wmts/PHOTO2/default/GoogleMapsCompatible/20/456285/874997)：完整屋面簷線、南設備凹口與東北低附體；影像視差未校正

- [OpenStreetMap way733307174](https://www.openstreetmap.org/way/733307174)：北牆約40.4m僅獨立量級粗核；照片薄簷不支持直接套入同心牆寬

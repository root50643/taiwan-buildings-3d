# 原始表面密測與有限根接補充

本補充使用交付的原 STL，沒有修補、合併、刪面或更換正式 Polygon。原作者 7 點法為 63,770 點；本獨立 15 點法為 136,650 點。原法向短首段及後續空氣保留，不能以另一方向長射線取代原短值。

- 3,926 短段分為 3,840 母體淺窗框側弦及 86 輪廓角。側弦最短 0.6826324462890625 mm；64 處預選母牆內 0.8 mm 實芯盒經所有原三角形 SAT 與內點 winding 核驗。各種向背方向、內偏起點和固定中心的首出口數值方法不同，見摘要。
- 79 輪廓角能配對實際相鄰凸邊；另外 7 處近共面分片不聲稱同一精確平面，採原面切向 21 站路徑，最大移動 0.2 mm，末端首弦最少 0.8106800786954436 mm。
- 四處作者式 0.4 mm 切向檢查在獨立 1e-8 mm 的原面門檻失敗。實際首入偏差為 4.8350e-8 至 4.83293e-7 mm，作者 5e-5 mm 容差較寬；這是鄰近 float32 分片差別，不代表真空洞。四點另有真正共享凸邊根證。所有原失敗和替代方法均保留。
- `independent-nearest-edge-failed-alternatives.json.gz` 保存 7 個最近邊診斷，其中四條替代根 <0.8 mm、兩個所選邊為凹角；這些不是採用的合格證據，不被長根或改門檻抹除。
- 141,336 個原法向／預選母牆或雙面方向的首段、後空氣、途中及出入控制全通過。18 條原射線的第一出口之後另有 41 個原面沿面區間，詳另一組件補充，不能算作 air 或延長 bulk。
- 這些有限原面、局部實芯與連接證據不等於全域最小壁厚、製造公差保證、免支撐或實際試印。

## 重現

在原模型副本中安裝模型 REPRODUCE.md 所列 Python 套件，另備支援 C++17／OpenMP 的 g++。執行：

    python independent-audit/dense/reproduce_independent_dense.py --model-dir . --output independent-dense-reproduction

程式使用系統暫存目錄編譯附帶的原三角面計算器，全部輸出使用 gzip 並附 SHA。需要數分鐘。退出 0 代表重現完成，不代表原警示或所有替代方向通過。`.py.in` 是完整可讀模板，由程式僅代入模型及暫存路徑；沒有私有資料依賴。原 CSV 的 `inf` 表示射線後方沒有第三次入射；嚴格 JSON 的相應 `null` 不代表零或缺失量測。

# 數位幾何與來源限制核對

## 證據範圍

本件為長庚大學學生活動中心跨來源近似模型；主要量體及入口／塔列印簡化外觀已核准。最大150 mm，140×150×43.60800171 mm。原STL有6268三角面、3104唯一頂點，單一封閉表面殼、每邊雙面、頂點連結有效。未使用最終網格修補吞掉錯誤。所有尺寸仍受來源限制，不是建築測繪。

validate_model.py 記錄源碼重建STL byte SHA一致、Blender幾何SHA一致；check_preview_rebuild.py 重渲9張actual STL PNG byte SHA一致；check_readme_views.py核三層README正背同列、六連結皆存在。公開預覽含完整底座，私人近圖可裁切以核細節。

## 原Polygon逐層與高損樣本

每0.2 mm、偏移0.071 mm取得218層、564個原Polygon，保留原WKT。每一原Polygon半徑0.4 mm侵蝕及開運算皆非空且不分裂。263個>1%開運算損失樣本分六族，並非263件薄構件：

- 司令台4柱：84層樣本，原矩形最短約1.053497 mm，最大角損11.9035%。
- 低翼9廊柱：其中8柱出現64高損樣本，最短1.1173 mm，最大4.5568%；第9柱受端牆／地形接合，未形成同類獨立高損切面。
- 塔X背芯與環帶聯合體：31樣本，為同一聯合體不同高度，最大2.7398%，不能把4.4692 mm外框跨度稱為最薄壁。
- 15屋脊採光蓋上唇：30樣本，上唇原進深1.117298 mm，最大1.4346%；原0.479 mm薄唇已改源加深。
- 塔頂4角柱：44樣本，原短邊1.2769 mm，最大8.4732%。
- 同一有限截頂斜帽：10樣本，截面隨高度縮小，最上抽樣跨度1.272633 mm，最大8.5300%；真正頂面約1.10 mm，另原面核對。

每筆損失、原截面與數值殘差保留於 layer-component-check.json 及 CSV，不以理想矩形替換正式Polygon。作者固定0.6 mm角區外損失約數值殘差；自適應角區最大半徑2.297339747 mm，兩者均不是獨驗真角0.41 mm口徑。獨驗v1中未變更的其餘五族，0.41 mm真角外最大：台柱0.000521111353 mm²（0.04427206354%）、塔聯合體0.0001050099053 mm²（0.000692943254%）；這些小量不能寫成零。實際厚根由 recess-root-check.json獨立原面射線核對；百分比、零split本身都不自動授予例外。v2已完成獨立原STL全套重驗，主審接受下列具體六族例外，並非一般薄件百分比門檻放寬。

## 實際薄件、根與簡化

787項原STL控制（逐射線及切面交集見recess-root-check.json）核塔角柱、每層每面X斜撐端根、退背芯、鐘面背牆、尖帽實心斜面及有限頂面；入口細X每條多點背根；低翼9柱／司令台4柱上下根；低翼接合與後U欄；15採光蓋上唇與雙根。詳見腳本和逐射線結果，非另造簡化表面。

塔原X孔封背，尖帽原三角開孔完全封實，不保留淺凹或真孔，入口0.26 mm細框為背牆浮雕而非獨立細棒。細節在150 mm總長下加粗、填背、截尖；不建議任意再縮小。屋頂/懸挑仍可能需支撐，數位篩檢不是切片器或實體試印保證。

## 重現

安裝 requirements.txt，執行 python build_model.py，再以 Blender 4.3.2 執行 blender -b -t 4 -P render_preview.py；執行 python run_all_checks.py 重跑全檢查。原照片／PDF僅私人核對，不包含於本包。

## v2 原面修正

v1 四面三角淺凹在 z42.664001 mm 終止，獨立原面射線於 z42.671 mm 發現斜面首實體僅0.0132062／0.0132488 mm，之後進入凹槽。這是真薄唇，不是角損或數值差；原先只量凹槽背厚未涵蓋此唇。v2從源移除四面凹槽，採實心有限截頂；其餘五族幾何不變。v1保留為HOLD，不作發布。v2另重驗原命中點與四向各高度法向首實體。

原v1命中兩點於v2首實體已為3.798492／3.798342 mm。擴展四面法向檢查也保留近帽底外角短弦：z40.670 mm首弦約0.022641 mm，出口為帽底z40.658 mm外平面，並非內盲凹槽。原面命中面ID、內外狀態、帽底下0.2 mm承接交集另留證，不把所有短弦當全域薄壁，也不宣稱全表面皆厚於0.8 mm。

帽底承接採原STL切片：z40.659 mm帽截面為一原Polygon、面積22.9177769 mm²；向下0.2 mm至40.459 mm是四根原柱截面，交集總6.5221524 mm²。四個承接區各1.6304749–1.6306013 mm²，分別侵蝕0.4 mm後仍為單核，剩0.2274341–0.2274813 mm²。這是「帽單核＋四柱各單核」，不是四柱聯集單核。面內區z41.4–43.5 mm、橫向為該高度半寬的-0.5、0、+0.5位置抽驗法向首實體最薄1.400083 mm；不擴稱全域最小。

另保留刻意頂角掠射最短0.002800 mm，屬真外角短弦控制；不得移作內部壁厚下限。

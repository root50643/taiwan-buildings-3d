## 範圍與版本
以 2023 年改造完成後的公開外觀為準：五跨、兩層的方格入口框架、兩側磚紋高量體、入口自然草坡，搭配長條左翼、中央露天山之廣場與右側較大的展示館及屋頂採光量體。不是南科考古館；也不是改造前的日晷水池版本或尚未實現的概念圖。

- 尺寸：150 × 142 × 30.7 mm（含底座）
- STL 以 mm 為單位；正面 −Y；底面 Z=0
- 交付 model.stl、原創 build_model.py、可編輯 scene.blend、實際 STL 的正背面預覽
- 範圍為主要館舍及簡化入口。遠側圓形會議棟、學術活動棟、停車場、大片後花園與完整基地不納入
- 僅製作公開可見外形，不含室內、設備、地下結構或營運資訊

## 來源與判讀
先實際檢視館方電子報的改造後門口、遠景，再以 2023 年開館報導中標示由館方提供的空拍照片核對館舍配置。另參考館方舊建築介紹的實景空拍，只用於辨識長形左翼、中央廣場及右側展示館的位置；舊照片中的日晷、水池、入口大階梯、圓柱和館銜文字均未沿用。

框架的五跨兩層、磚紋兩側量體與新草坡有現況照片支持。並未取得測量圖或完整正投影，所有尺寸、退縮、窗列間距和高度比例均為照片估算，局部後側採規整化重建。框架及窗改成向外開放的深盲槽，部分外廊與後拱也實體化，避免薄柱及室內空洞。山之廣場的地景丘和座階只保留概括輪廓；牆面磚紋放大，不重現每片磁磚。請勿用於施工、現況測量或考據定論。

## 建議列印
底座平放。PLA、0.4 mm 噴嘴、0.16–0.20 mm 層高、3 道外牆、10–15% 填充是起始建議。150 × 142 mm 的寬底座需要足夠平台，建議注意首層黏著及翹曲。方框盲槽頂部、屋簷與局部退縮可能需要支撐，請逐層查看切片。約 0.55–0.8 mm 的磚紋、窗線與屋簷細節縮小後容易消失。未實體試印，不保證免支撐。

## 重建
使用 requirements.txt 的固定依賴版本，建議 Python 3.12：

    python build_model.py
    python validate_model.py model.stl --output validation.json
    python verify_rebuild.py
    blender -b -t 4 -P render_preview.py
    blender -b scene.blend -t 4 -P verify_blend.py

驗證檔列出：連通封閉、所有邊兩面共用、頂點鄰域單环、面方向、正體積、平底與 150 mm 最長邊；原始 STL 法線及閉合邊界數；無負體積內殼；可重建 SHA-256；Blender 網格與 STL 一致。數位拓撲檢查不等同試印，亦非獨立的全域三角形自交證明。

# 東海大學｜校園建築外觀模型

現行校級主圖鑑共 **5 套**：本校新增目錄 **4 套**，另含地標分類既有路思義教堂 **1 套**；教堂不重複計入新增目錄或全庫件數。模型套件不等於整棟建築，亦非全校完成。

既有原藝術中心歷史外觀研究模型：不是現況測繪，也不代表全校建物已完成。尺寸、殼頂形式與部分細節的史料推定限制詳見模型說明。

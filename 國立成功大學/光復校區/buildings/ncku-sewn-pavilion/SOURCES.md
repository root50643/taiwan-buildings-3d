# 懸鏈・榭（Sewn Pavilion）｜來源與判讀界線

國立成功大學／光復校區／建築系館院落；模型識別`ncku-sewn-pavilion`。本件為研究實作亭的歷史完整外觀近似，不是現況調查、測繪復原或施工重建。

## 場址是成組影像交叉定位推論
成品夜照與官方具名院照同時對上：左側下層柱窗與上部外挑連續窗帶、草坪邊斜方格鋪面、右側大寬階及分段側緣、階頂樹與相鄰翼樓的相對位置。這些組合支持「建築系館院落」，再接官方系館沿革分類為「光復校區」。日照的局部梁窗／磚柱只補充，不靠風格相似單獨定位。

文章明確區分早期擬在榕園的課程涼亭與後續完成的論文實作：前者在2012年課程結束時未集體搭建。因此**不稱榕園亭，不以未建方案場址代替已組裝成品位置**。2025上傳的院照沒有本亭，既不證明2025仍存，也不確定拆除日期；不以新院落構件替換歷史亭體。

## 未量測、簡化與模型範圍
- 所有絕對尺寸、曲帶三維曲率／冠高／翼端角、厚度與腳部露出高度都是展示模型近似；沒有完整原尺寸／測繪座標，不能杜撰實物公尺尺寸或精確縮尺。
- 中央框片局部曲面及小三角孔大小是圖示拓樸的近似實現，不是從完整竣工俯視測量的數據。
- **模型強化而非來源尺寸：** 曲帶名義法向厚度0.95mm；中央框片保留擬合中心曲面／孔形，按垂直厚度`0.95 / max(0.12, abs(n_z)) mm`加厚，目標近法向0.95mm。`n_z`是局部單位法向的垂直分量，極陡近腳的垂直厚度上限約7.92mm，底面裁至展示z≥0。這些數值全部是建模設定，沒有宣稱原作採相同板厚；布林重疊與近腳上限處以交付raw-STL法向ray診斷為準，不能把目標值當成全域最小厚度保證。
- 非均勻穿孔保留存在與代表性分布，照片中成組微孔省略，確切孔數、形狀與位置未逐孔複製；接縫、邊帶、腳部接片與細件按縮尺簡化／加厚。來源各帶上緣有錯層與局部上翹；模型以**連續邊界曲帶＋細接縫**近似這種層次，不是逐片折曲或逐片上緣的精確復原。曲帶仍可辨，但不能把連續曲面處理說成完整施工裁片復原。
- 以日照淡木為色彩基礎。構築圖藍色僅為說明，不增造藍漆金屬帽；不把夜照燈色當成材料色。
- 只重建亭體可見外觀；不納入院落樓房、樹木、草坪、石塊、臨時照明、整座大階梯、人物及不可見基礎。不是整個校園完成。
- 未實印、不保證免支撐；薄片、孔邊與懸挑需自行檢查。拓樸與材料往返驗證不等於結構安全／可施工或可直接切料證明。

# 公開證據與原始記錄

本目錄公開的是固定候選 `8758edad39f1ce64a1625e46cde6deb170c02cce` 與其獨立增量覆核的公開副本。為排除私人環境資訊，10 件既有文字記錄及選定獨立證據的環境路徑已作明示正規化；原始候選、原始失敗、補證與獨立報告的位元組保留在同一 Library 的最終自足備份中。

逐檔來源、原始 SHA-256、公開副本 SHA-256、轉換方式與核對結果見 [path-normalization.json](path-normalization.json)。其中 `original_sha256` 對應備份原件；`public_sha256` 對應本庫實際公開檔案。即使檔名含 `raw`，若列於正規化記錄，公開檔案也是只改環境路徑的衍生副本，不能宣稱與原始位元組完全相同。沒有列入轉換的數值、`false`、`null`、SHA、Git 身分及原始行號均保留；失敗旗標沒有被改成通過。

`<candidate-workspace>`、`<slicer-tool-workspace>`、`<analysis-output-directory>` 等占位符只標示當時環境角色，不是可直接執行的檔案位置。記錄中的程式 SHA 代表原執行版本；本次沒有重新執行去路徑副本，也沒有新增幾何、切片或獨立覆核。原始方法程式保留於最終 Library 備份。

獨立覆核請由 [最終增量覆核](independent-review-8758/FINAL-INCREMENTAL-REVIEW.zh-TW.md) 開始閱讀。`identity.json` 綁定原固定候選的 188 個 Git 檔案，並不聲稱本次公開去路徑副本仍逐檔等於舊候選。原 R2 與填實變體的 STL、場景及預覽沒有因本次去路徑作業更改；各版本的測試結論應依其對應 SHA 閱讀。

Library v2 回條是已完成的歷史官方下載驗證。獨立覆核只核驗該作者回條及既有下載檔，沒有假稱再次下載；原歷史 `pending` 記錄與後補已完成狀態一併保留。[原始來源證據清單](independent-review-8758/raw-source-evidence-manifest.json) 是 v2 狀態更新後的 18 件原件清單，SHA 對應備份原件，不代表公開去路徑衍生檔的 SHA。較早的 14 件清單及狀態更新前原文保留於最終 Library，沒有被當成目前完整清單。加入本次公開發布資料後的最終備份身分，以另列的最終發布驗證記錄為準，不以 v2 冒充最新版。

製造結論保留為有條件可用的代表模型。實際切片沒有發現具體完全封閉支撐，不能推廣為全域無困料；A／D／E 及門廊／平台的全部清除、工具可達與拆除力仍未經試印驗證。不一律要求可溶支撐；若採用，仍須核對雙材料設備與液體進出路徑。通用 G-code 僅為 QA 證據，標示 **NOT-MACHINE-READY**，未實體試印。

本公開證據集合不含第三方原照片、憑證、簽章傳輸網址、Library helper 私有狀態或執行環境快取。模型前棟屋頂／露台為此次改良重點，後棟尚未全面深化。

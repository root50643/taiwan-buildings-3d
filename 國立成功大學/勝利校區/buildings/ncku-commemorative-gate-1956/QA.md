# 品質、製造篩查與未驗證事項

## 原始輸出拓撲

以原始 binary STL 僅做精確座標合併索引，不補洞、不刪面、不修法線：205,216 三角面、102,610 頂點、單一封閉連通殼；零面積、重複面、不合二次邊、反向邊及頂點 link 異常均為 0。帶符號體積正值 190,464.5197 mm³。完整數據見 [qa-topology.json](qa-topology.json)。

## 截面與局部細節

- [qa-layers.json](qa-layers.json)：原始模型每 0.2 mm（另最高處下 0.001 mm）共 640 層；輪廓有效，每個正面積連通分量均可在半徑 0.4 mm 侵蝕後存活。這只證明全域層分量，不代表雲紋尖端通過。
- [qa/local-features.json](qa/local-features.json)：先截取實際頂部雲帶，沿四面的外法線於凸出 0.1、0.5、0.8 mm 取真實截面；西／東各 97、兩端各 8 個可分辨輪廓，均有效並可存活。這確認浮雕實際存在於輸出，而不是僅由程式的名義參數推斷。
- 同報告另把西面外側浮雕單獨截出，再逐 0.2 mm 水平截面篩查：**19 個高度有雲尖分量無法通過嚴格 0.8 mm 存活測試**。保留全部失敗，不四捨五入、不刪尖端、不豁免。0.27 mm 階肩也不保證被小型 FFF 完整保留。
- 雲紋根部設計侵入雲帶 0.2 mm；最終單殼拓撲及各面實際浮雕截面共同支持其沒有懸浮小殼。不是力學黏結強度測試。
- 兩個基座在低層本來就是兩個分量，到門楣才連接；不可因此把低層強行補上不存在的底板。

## 交換格式與可編輯性

交換格式核對記錄在 `qa/exchange-validation.json`：3MF 與原始 STL 三角座標／順序逐一核對、lib3mf strict 載入、編輯單一材質後另存重開、其餘色彩及指派保持；重建 STL、3MF、網格清冊與材質清冊雜湊一致。可用 `BUILD_PYTHON` 指定有完整建模依賴的 Python，lib3mf 驗證可在另一個具該套件的 Python 進行。

Blender 記錄在 `qa/scene-validation.json`：一個可編輯 mesh、原始三角形完全一致、3 種材質顏色／指派一致，實際材質編輯另存重開。沒有嵌入照片、腳本或外部資產依賴。`qa/render-manifest.json` 包含 5 個實際模型相機的包絡檢查；`qa/render-reopen-validation.json` 記錄以保存的正面相機重開重繪，去除文字時間欄位後 PNG 位元組完全一致。

## 不可誤解為認證

未做實體列印、列印機特定切片、橋接或支撐測試。直立約 106 mm 的門楣跨距需要個別支撐策略。未驗證耐力、色料、噴嘴細節保真、地下結構或現況尺寸。書法留白、端面配置近似、平頂技術封口及省略現場小物詳見 README 與來源表。

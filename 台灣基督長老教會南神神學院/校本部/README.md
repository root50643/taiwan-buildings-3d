# 校本部｜東門路一段117號

目前3件有明示範圍模型：禮拜堂1957建物／修復前外觀、本館2024修復後外觀近似及西校舍1957／2025修復後外觀近似；不稱全校完成。正式學校於2017年6月22日經教育部准予設立，與歷史台南神學院同址承接，不另計第二校。校方edu校圖直接列本禮拜堂；此處不推定校舍為獨占產權。

## 西校舍1957

西校舍1957完整主要外觀近似：兩層長條、單長脊四坡灰水泥瓦頂、東4拱＋中央平頂貫通門廊＋4拱、南廊端真拱口及北一跨短穿廊止於本館接縫；不含本館、禮拜堂、噴泉或景觀。東上9拱窗、西上8拱窗＋北3小窗，西下矩窗非鏡像；廊後南3門5窗/北2門3窗，北2F接點D2門/旁窗代理。依2025官方修復報告與2024–2025完成照，2026原拍僅補接口，非2026全棟現況或測繪。63.25×200.75×57.982mm，8色Blend/3MF/STL、5真mesh圖＋2無切網格通道圖；16462三角單閉殼、290有效切層、37空實點/3ray/21局部切片、strict材質與Blend頂點存讀、乾淨9件bytes一致及獨審通過。保留205層0.8mm薄島警示（0.715mm落水管等），0.33mm窗格/0.303mm瓦紋；拱廊/簷/接口需支撐，未實印，不是通用最小壁厚認證。

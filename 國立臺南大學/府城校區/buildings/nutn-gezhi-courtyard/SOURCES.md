# 來源、誤植與年代限制

研究下載與視覺檢查：2026-10-27。來源僅私存研究，不包含於此包。

1. 國立臺南大學「今日南大／格致樓」官方相簿：https://www.nutn.edu.tw/gac420/今日南大/格致樓/格致樓圖像.htm 。實看五張原始照片：格致樓000101.jpg、格致樓000201.jpg、格致樓0702.jpg、格致樓0602.jpg、格致樓0502.jpg。年代未列，不以頁面存取日期當照片拍攝日期。
2. 總務處官方111年10月（2022）監測計畫PDF：https://oga.nutn.edu.tw/upload/120230905160506.pdf 。51頁文件，實看PDF第48–50頁內部格致樓平面。舊www.nutn.edu.tw/oga路徑目前失效，使用同校新總務處網域實際PDF。
3. **頁外標題誤植**：PDF第48頁內圖是「壹樓」且C101等，外caption標四樓；第49頁內圖「肆樓」C401等而外caption標伍樓；第50頁內圖「伍樓」C501等但外caption是榮譽校區。以內部文字、室號、相互一致的圖形判讀，不依錯置caption。
4. 軸線總尺度約4830×3020cm；建築外牆並非滿軸線矩形，右翼部分約4700cm且存在突出部。各牆厚、層高、窗型、設備並無精確實測，屋頂簡化平頂。

官方照片支持凹入中庭走廊、淺米磁磚、中央粗圓柱挑空、右側實心欄牆陽台、前景低屋頂。材色未校色，照片中偏粉不視為可靠粉色材料。缺乏攝年與近期勘查，不作2026外觀承諾；本模型不代表校方認證。

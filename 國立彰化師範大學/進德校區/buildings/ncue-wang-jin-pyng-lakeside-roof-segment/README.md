# 國立彰化師範大學進德校區｜王金平活動中心湖面側立面與淺拱屋頂局部

**新建、七色、來源限定的局部展示模型，不是全棟復原或測繪模型。**

依校方會場照片與校方屋頂光電規劃 PDF 的現況照片，表現不對稱白色帶狀立面、兩個分開的斜收口窗洞、內退玻璃帶、樓板、成對柱、右側深色塔體及局部淺拱屋頂。校園圖把本棟「王金平活動中心」與「王金平游泳館」及舊「活動中心」分別標示，沒有混為一棟。

![湖面右前視角](previews/lake_right.png)

## 檔案
- `scene.blend`：可編輯三角網格、七個獨立材質、相機與燈光；無外部貼圖。
- `model.3mf`：七個可編輯顯示材質，單一網格。**不是多噴頭／多耗材列印配置**。
- `model.stl`：相同幾何的無色 STL。`mesh.json`、`palette.json` 提供幾何與材質對應。
- `build_model.py`：可重建幾何、配色與 3MF。`render_model.py`：由交付 3MF 渲染並建立 Blender 場景。
- `previews/`：front、lake_right、elevation、top、rear 共五張同幾何預覽。
- `qa-topology.json`、`qa-layers.json`、`qa/`：原始拓撲、截層、局部細節、交換格式與場景驗證。

## 邊界、尺度及誠實限制
- 尺寸是任意正規化展示單位，檔案以 mm 儲存；**184 × 91 × 97 mm 只表示輸出模型包圍盒，沒有已知真實比例**。不應換算建物實際尺寸。
- 僅表現有照片支持的湖面側與屋頂前段。屋頂深度為展示裁切深度，不是整座屋頂長度；不補造未見後立面、樓層平面、屋頂機電或完整側翼。
- 底座、後封板、左側素面、地面後牆及內部連接塊是**展示裁切／網格連接支撐**，不代表實際牆體或工程構造。`rear.png` 刻意展示這些簡化邊界。
- 淺拱弧度、外殼斜度、窗梃數與等距配置、方柱截面、塔樓深度、面板尺寸均為照片判讀的近似。柱子作成成對方柱只是可辨識展示簡化，非實測柱型。
- 兩窗洞確實切穿白色前殼，內側玻璃為後退的不透明展示材質；**不是整棟貫穿的門洞，也不是透明玻璃物理模擬**。
- 官方 PDF 標題為「增建建物規劃」，其中藍色太陽能板格網與容量是規劃資訊；本模型**沒有把規劃 PV 陣列當成現況**。
- 文字招牌、植栽、湖水、鄰棟、階梯及遮蔽處細節未重建。照片版權仍屬原權利人，交付與備份不包含來源圖片／PDF。

## 列印限制
原始 STL 是單一連通、封閉且定向一致的網格，這不等於保證可直接列印。全層組件 0.8 mm erosion 篩查通過，但**局部屋頂肋尖與斜收口仍有細節衰失**；詳見 `QA.md`。懸挑立面、樓板與屋頂須由實際切片器檢查支撐。未做實際列印、載重或工程驗證。

## 重建
```sh
python -m pip install -r requirements.txt
python build_model.py
python qa_model.py --out .
python check_features.py
python verify_exchange.py
blender -b -t 3 -P render_model.py
blender -b -t 3 -P verify_scene.py
```
建模腳本及原創幾何依 `LICENSE`；來源 URL 與使用邊界見 `SOURCES.md`。

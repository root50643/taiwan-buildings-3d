# 國立臺北教育大學｜臺北校區建築模型

第七批新增百年紀念鐘樓、正門入口段2模型；既有17模型逐檔原樣保留。合計19模型覆蓋18個主要命名館舍範圍與2個補充構造範圍，行政A＋圖書館H合計只算1模型。芳蘭樓仍只有入口局部，其他量體近似亦有未知面。18名冊覆蓋不代表所有歷史／附設建物或全校完成。各件自建，最長150毫米含底座，各自獨立比例。

# 國立臺南藝術大學 3D外觀模型圖鑑

本輪核准的外觀近似模型套件；全校尚未完成。套件可能包含相連群組、局部或歷史外觀，件數不等於完整建築棟數。未正式切片、未生成經驗證G-code、未實體試印。各件警示、來源年代、背面簡化及支撐需求請讀詳頁。只公開來源URL，不散布原照片或PDF。

14件中音樂暨宿舍為相连群組、南北畫廊為雙館組群、職務宿舍僅可見局部屋帶；弧頂棚為歷史影像版。

本輪共14套，每件獨立縮放，並非統一比例校園拼圖。

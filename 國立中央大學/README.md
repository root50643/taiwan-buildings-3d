# 國立中央大學｜校本部與校外觀測基地模型

現行收錄 **23 套模型包**；數量不等於完整建築棟數，亦非全校／校區完成。新件與既有件的年代、截段範圍及未試印限制請閱各模型頁。

### 既有批次來源與列印限制（數量為各批歷史範圍，非現行總數）


22件公開照片衍生的有界外觀模型：桃園中壢校本部21件，另有校外鹿林天文台觀測基地SLT主樓1件。含女十四舍入口與聽松台街側局部研究、工五B增建翼單獨模型，並非22棟完整測繪或全校完成。校本部原20件含底座最長150mm，聽松台街側長220mm；鹿林SLT底板長192mm，皆為各自獨立比例近似。SLT是1999白色主樓的2022–2023可見外觀近似，非LOT、全基地或2026現況。

## 驗證與證據界線

校本部原有20件通過原始法線、邊與頂點流形、水密、單連通表面、正體積、乾淨重建同hash、Blender/STL一致檢查。0.2 mm有效截面補查共9097層通過；另行1 mm間距薄篩保留光電1層、遙測5層警示。需要支撐與實際切片評估，尚未正式切片或實體試印。

新增鹿林SLT另有來源五圖終審與完整格式／重建QA；476全局層保留8薄層，局部48薄樣本與懸挑風險照實記錄，未實印。

未知背面、深度與設備有明示簡化；照片拍攝年未提供時不以文件年替代。女十四舍不是整棟完整模型。模型原始參數可編輯，Blender是可編輯網格，不是BIM。來源原照片及內部並排圖不公開。

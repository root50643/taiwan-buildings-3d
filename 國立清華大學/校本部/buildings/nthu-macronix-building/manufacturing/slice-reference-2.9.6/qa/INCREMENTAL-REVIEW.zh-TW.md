# 參考切片增量文檔覆核

結論：指定 README、執行摘要及五份 QA JSON 的主要數字與限制互相吻合，未見把有限數位退路寫成整棟製造／硬支撐拆除通過。另有一處小標題可收斂措辭，見下文。本輪只讀核對並實看既有 PNG，沒有重切片、重跑解析、改幾何或修改候選檔案；也沒有試印。

範圍為 `manufacturing/slice-reference-2.9.6/` 的 `README.zh-TW.md`、`slicer-run-summary.json`、`qa/ACTUAL-SUPPORT-AUDIT.zh-TW.md`、`support-audit.json`、`actual-support-routes.json`、`model-path-audit.json`、`model-path-layer-supplement.json`、`cap-support-link.json` 與 `actual-path-sections.png`。本覆核核對既有記錄，沒有獨立重算整份 G-code。

## 核對結果

| 項目 | 文檔／記錄核對與適用界線 |
|---|---|
| 一套實際 G-code | 摘要只有一個 `slice` 動作且 returncode=0；另一次是 3MF 匯出，不是第二次切片。實際輸入是**填縫變體** STL `6801f9c4…1351b2a`，不是直接把 R2 原件當作本次切片輸入。G-code 20,642,153 bytes、SHA-256 `7f614cbe4a31e59cfed5e843f90b797f1032984c173da044284fc36ab18219de`；有列出該 G-code hash 的指定 QA 記錄相符。 |
| Generic 配置 | README 明列 generic Marlin2、NOT-MACHINE-READY，並非已識別真機。溫度等為繼承參考值；3MF 缺完整 print-profile，須配套 INI；609 個 layer-change 混合模型／支撐事件，沒有誤當 609 個模型層。 |
| 40 個原幾何疑點 | 文檔明確否定「40 點＝40 個真困住支撐／40 個必須可溶區」。實際支撐 29,675 段、介面 25,019 段，合計 54,694 段；另 608 段 Bridge infill。段數不是支撐塊或困住件數，區域包絡可重疊。 |
| F／C 填料 | F 的 8 縫及 C 的 12 個填實背槽均命中 0 支撐／介面；C 深 bay `Y=-20.9…-19.1` 三帶亦為 0。這是此配置／查詢區的結果，並非聲稱所有 C 外口都沒有支撐。低兩帶仍有前唇小片。 |
| B 有限退路 | 後上蓋完整高度查詢盒命中 2,843 線／86 個沉積 Z，已測截片可 +Y 8 mm 後上提，投影交疊為 0；前淺槽 306 線／10 個沉積 Z 有 −Y 8 mm 候選退路。兩者均以**先分離的小片**為前提；未證明連體支撐能原位剪開、工具進得去或施力安全。 |
| G 的 11 條介面 | G 包絡命中 507 段，真進三個 bay 的只有 3／5／3 條介面，均在 Z 頂=36.45，宣告 HEIGHT=0.4 mm。上端開口為 2.2 mm，沒有誤套常規 6.2 mm 格縫。已測局部外退不等於整體三維支撐已斷開。 |
| 0.8 mm 肋的前層依附 | 206 個實際模型層、824 次豎肋測試；原同層連牆測試的 12 個 false 未覆寫，四道橫條共 22 層連續性檢查為 0 failure。補證來源 hash 與原報相符；12 個前部構件均與前一模型層沉積有正面積重疊，約1.272–1.341 mm²。因此不能把原 12 個 false 讀作12處缺絲，但也不能把數位足跡重疊讀作層間強度或拆除後存活證明。 |
| 上蓋 HEIGHT 與 gap | Z 頂=54.3 的外環有 23 段 Overhang perimeter，宣告 WIDTH=0.4、HEIGHT=0.4 mm，底為53.9；下方實際介面頂53.7，差0.2 mm，XY 重疊約28.802 mm²。這解釋原「同層分件／只查前一模型層」判讀不足；0.2 mm 是宣告沉積幾何間距，不是實物間隙或可拆性量測。 |

有限掃掠只在各沉積層下／中／上三個 STL 截面查碰撞，未證明層內每個 Z、工具或變形情況。原把 U 形凹口填滿的凸包假碰撞另檔保留；凹形掃掠控制為真實線性 sweep 交疊0、凸包假交疊4 mm²。沒有將原結果直接改成全綠。

## 檔案與預覽

- `model.stl`：毫米單位；底座、館體、門廊及屋頂棚一體成形。
- `build_model.py`、`requirements.txt`：完整幾何原始碼及 Python 依賴。
- `scene.blend`：由同一份 STL 匯入的 Blender 場景，另有不列印的攝影棚地板、相機與燈光。
- `render_preview.py`、`previews/front.png`、`previews/rear.png`：實際列印網格的正、背面預覽，沒有以貼圖補出模型不存在的窗格。
- `validate_model.py`、`validation.json`：法線、連通性與邊／頂點流形檢查。
- `rebuild-check.json`：連續重建 STL 的雜湊比對。
- `evidence.json`：官方證據、判讀內容與限制；`SHA256SUMS`：檔案核對值。

## 依照片保留的辨識特徵

- 寬而高的主館，依正面可辨的約十排樓層窗帶安排立面。
- 頂層密集窄直窗，下方以成組橫窗及少量窄窗形成不同節奏。
- 中央直向突出窗帶與厚窗臺，兩端不同高度的塔狀量體。
- 中央弧形入口門廊、上下兩道弧形厚帶、粗圓柱及前方短階梯。
- 兩個斜向視角可見的端部外側垂直玻璃窗帶，以凹窗與粗化窗框表達；未臆定內部機能。
- 低矮而長的屋頂太陽能棚、左端屋頂設備遮屏。

模型範圍只含 H1。官方現行教室代碼表列為「產研創新暨推廣大樓 H1」；此套件沒有另建無法核實的 H2，也沒有把旁邊 F1 或其他館舍併入。

## 尺寸、比例與未知處

含底座外尺寸：150 × 80 × 121.4 mm。最長邊為 150 mm；每棟各自縮放以方便列印，與其他校舍模型不是統一縮尺。

主館約 132 mm 寬、38 mm 深、100 mm 高。前立面寬高及窗排參考官方照片的透視比例；平面深度、後緣與基地高程沒有實測資料。底座是列印支承，不表示校地邊界或實際基礎。

- 官方照片以正面及兩個前側角度為主。完整背立面未確認，背面保持實牆，沒有鏡像複製正面窗戶。
- 端部窗帶與館體完整接合、屋頂俯視、設備配置與後側附屬物仍不足以精確復原。
- 入口弧度、柱徑、階梯級數及屋頂棚坡度皆為外觀估計；為列印強度作了粗化。
- 樹木、旗桿、車輛、空調、纖細天線、招牌文字及鄰棟不建模。模型沒有房間、管道或封閉內部空腔；外側門廊和棚下開放空間仍保留。

## FDM 列印注意

1. 平底朝下。建議 0.4 mm 噴嘴、0.16–0.20 mm 層高、3 道外壁；填充密度由切片軟體決定。
2. 窗框最細約 0.8 mm；屋頂支柱 1.4 mm；棚板約 1.35 mm；入口圓柱直徑約 3.5 mm。這些是原始碼設計值，並非全網格自動厚度掃描。
3. 弧形門廊下方、屋頂棚底與小窗凹槽都有跨距或懸挑。請在切片預覽逐層檢查，門廊和棚下通常需要支撐；建議使用可移除的局部支撐並確認拆除通道。
4. 太陽能格線及設備遮屏刻線是淺凹槽，小尺寸或較粗層高會降低辨識度。不要未檢查就等比例縮小。
5. 尚未實體試印。網格檢查通過不代表免支撐，也不保證所有材料或列印機都能一次成功。

## 重建與檢查

安裝 `requirements.txt` 後執行：

```sh
python build_model.py
python validate_model.py model.stl --longest-edge 150 --output validation.json
blender -b -t 5 -P render_preview.py
```

預覽程式以 Blender 4.x STL 匯入介面製作。重建驗證使用套件所列版本；跨版本布林運算的三角形排序可能改變，雜湊一致性以同版重建為準。

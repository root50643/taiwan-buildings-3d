# 驗證範圍

本模型為歷史照片有界外觀近似，未知背面及另一短端中性封閉，不是完整實景復原。

- 幾何：有限座標、正三角面積、封閉流形、每邊恰兩面、正體積、單一連通、法向一致。
- STL：直接解析二進位每一三角形，與原始 mesh-data.npz 的 float32 三角形逐項相同。
- 3MF：core XML 毫米單位、頂點、三角索引、每面基本材質索引逐項相同；未執行 lib3mf 驗證或切片機實測。
- Blender：重新開啟檔案，唯一可見外觀 mesh 的頂點、三角面與來源 mesh 相同。隱藏的 136 建構部件留作編輯，非可直接分件列印包。
- 沒有來源照片／航照貼圖。Blender 可能帶有內建 Render Result viewer，此非外部圖片或參考圖嵌入。
- 視覺：對照官方照片，修正下水平縫至低百葉上緣；不宣稱被樹遮住或未攝的立面已驗證。
- 未實體試印，不保證最小壁厚、色料切片分配、支撐或列印成功。凹槽及細線有縮尺簡化。

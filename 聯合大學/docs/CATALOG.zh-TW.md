# 國立聯合大學兩校區建築建模目錄

資料整理日期：2026-10-11。用途：校園建築辨識、模型規劃與公開來源索引。模型完成狀態以儲存庫首頁為準。

## 完整性與計數原則

本版共50筆「建物／待確認附屬量體」候選：二坪山21筆、八甲29筆。不是50棟現存建築的斷言。現行官方導覽、教室代碼與校史使用執照表交叉整理；舊表編號止於47，另補M10/M11及未編號機械房。若國際會議中心或機械房只是附屬量體，需合併；若A1/A2拆為各翼，零件數會增加。已取得並檢視兩校區官方示意原圖；八甲中大門、南大門及二坪校門小型附屬構造另列選配，館舍分界仍待照片確認。不得對外宣稱已涵蓋所有現存建築。

- A1、A2各含三個字母分翼；B1–B4、D1–D2、E1–E3、G1–G3是官方分棟。
- 行政單位、系所、書軒、教室、餐廳商家不因名稱不同而另建一棟。
- 同名必須按校區／代碼辨識：M8國鼎館是二坪宿舍；L1國鼎圖書館在八甲。
- 宿舍名稱曾更動：現行M1水雲、M2紅夢、M3影山、M4霽齋、M5恕先；八甲現M6是校史舊M5。舊表代碼不可直接沿用。
- 本次沒有核實任何建築「已拆除」。功能遷移、清單缺漏、計畫書提到拆除檢討都不等於實際拆除。
- 通霄教育園區及行政管理中心新建構想不納入現存建模清單；本次無足夠一手竣工證據。

## 尺寸與建模精度

校史面積是總樓地板面積，不能視為建築底面積，不能開平方當長寬。未取得各棟可量測長寬、屋頂高程或完整立面圖。所有footprint_dimensions_m／height_m保留空值。模型應明示「依公開外觀資料製作的近似模型，非測繪模型」，不可捏造精確比例。

## 首批三個建模研究候選

1. 理工學院一館A1：官方竣工照片＋現行分翼資料＋樓地板面積，先做整體A1群。
2. 理工學院二館A2：官方竣工空拍＋現行分翼資料；能補足屋頂與平面輪廓。
3. 立德樓C1：現行名稱清楚，官方正面照片，辨識性強；與八甲新校區建築風格不同。

更新：已取得並檢視理工學院35張官方空拍相簿中的多張縮圖。A1的16–24張可辨內院與前方連接量體；A2的26–29張明確覆蓋U形院落、背翼內立面與兩側屋頂，現況屋頂含太陽能板。A1/A2可進入有來源的近似外觀建模；仍不能聲稱測量級精度。C1相簿8張已檢視，照片2/7覆蓋正面及右側整棟，其他呈現入口階梯、門額與立面；背面及屋頂細部仍缺。

## README與模型檔命名建議

每筆用「校區＋代碼＋繁體中文名」作為標題，並列原始照片來源、模型實際mesh預覽圖、尺寸假設、目前狀態。示例：八甲校區 A2｜理工學院二館。圖片以模型實際網格渲染為主；未取得授權的校方照片保留來源連結，不直接打包重製。

可組合建築群維持一個manifest，子翼可獨立列印但不能在完成率重複計數。來源照片年份與現況不一致時，把差異列入限制。未核實館舍用「待補資料」，不要用通用方盒模型冒充完成。

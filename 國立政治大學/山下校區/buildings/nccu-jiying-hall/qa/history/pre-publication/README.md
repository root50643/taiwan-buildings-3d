# 國立政治大學・集英樓

山下校區集英樓（官方校圖 A22、資產編號60-17）的多色外觀近似模型。依官方PDF記錄的照片與各層簡圖建模，**不是測繪竣工模型，也不是已查證2026現況**。

模型包含完整十字式三層主樓、較小局部地下層的外露接地代理、退縮窗背與實際開放陽台、上層厚外挑及斜肩、分側屋簷、入口凹廊與牌篷、折階及連接坡道。三樓中央為實體使用房群，不是露天天井。沒有另加新樓層或推測的機電塔；未納入全校地形、鄰樓、地下內部隔間與設備。

## 檔案

- `scene.blend`：可編輯幾何、材質和攝影機的Blender場景。
- `model.3mf`：毫米單位、逐面基礎材質的多色交換模型。
- `model.stl`：與3MF同一幾何的無色網格。
- `previews/`：同一模型的五個實際渲染視角。
- `build_model.py`、`render_model.py`及驗證腳本：無需來源圖像即可重建。

使用Python依賴見`requirements.txt`；Blender4.3.2。執行`python build_model.py`，再執行`blender -b -t 4 --python-exit-code 1 --python render_model.py`。`python run_all_checks.py`會檢查輸出的原始網格、空實特徵、交換格式與原生場景。`rebuild.py --output 新目錄`可另目錄重建四項核心資料與五張預覽並逐byte比較。

## 可見性與近似限制

B1順時針90°、1F逆時針90°、2F180°、3F原向，以共同柱列、梯、單框/雙框與廁所位置共框；像素配準不是實尺。框的用途未證，官方表列電梯0座，不把X框稱為電梯。

雙照較強候選為同一西側的西北與西南視角，與北/西較深簷更直接吻合，但東側替代尚未唯一排除，側向不是唯一恢復；未看見的立面以平面窗線及規整中性窗帶簡化，不宣稱四面照片齊全。門篷、階坡細尺寸、樓層高度、斜肩曲率、色彩與窗框間距皆近似。北/西較深屋簷參考三樓圖外灰帶，東/南不鏡射同深簷。未取得獨立屋頂圖，以有限平頂閉合；照片中細小屋面構件的精位/用途未證，未添加。

## 製造限制

**未實際列印，不保證可直接列印或免支撐。** 細窗框、欄杆可能小於0.8mm，長外挑、簷底、門篷及底下空間可能需要支撐。局部地下基腳與西側窄地腳不同；西側底下保留空間，不能當封死的滿底地下室。封閉房群為外觀實體量塊，不是室內復原。若另行空心化，需另評估排液、通氣、困料、支撐與壁厚。數值抽樣與剖層結果不是全域最小壁厚或製造認證；詳見`QA.md`。

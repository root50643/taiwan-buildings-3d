# 國立政治大學樂活小舖

官方PDF記錄外觀／簡易平面參考版，資產編號 **60-13**。兩層L形主樓、右側兩bay局部B1與同高梯間，保留左端寬階、長面長廊／坡道、右外階、B1內梯及內凹小階。鄰棟樂活館（60-12，校圖A12）、獨立棚架及整片道路／景觀不納入。

## 檔案

- `scene.blend`：可編輯頂點與8種材質的Blender場景。
- `model.3mf`：逐三角形材質索引的毫米制彩色模型。
- `model.stl`：同一表面的單色列印交換格式；STL本身不含顏色。
- `previews/`：同一網格的五張實際渲染。
- `build_model.py`、`render_model.py`、`rebuild.py`：幾何、渲染及獨立目錄重建。

## 範圍與限制

依五張官方外觀照／簡圖共同柱梯框架建構。兩翼皆兩層；左翼在平面較深，不當成更高塔樓。上層鏤空磚以不透明背板與粗略淺浮雕近似，下層是實際店舖牆面／門窗代理與開放雨棚下長廊，非整層透空。B1僅右兩bay，保留與梯間相通的負空間，不填成滿底地下室。屋頂在可見女兒牆高度作有界平頂近似，不增未知塔體、設備。

來源為消防簡圖而非完整竣工立剖面；高度、細窗、階坡坡度、材質色與未見立面細節為近似，室內隔間未重建。非B1區僅有限貼樓周界地腳與階坡接地代理，底下中間保持開放；共同模型datum不是測量地形。局部外階地坪設定z2、B1模型截底z0；左寬階、右短階及內凹小階腳各有可見有限低平台與有界斜面，長坡低端接連續右側地坪。斜面僅表達局部接地與模型切界，不是現場坡度／高程重建。右梯保兩層真側門／有限接收凹腔；上梯是有限厚階板，保下方B1階路頭空，並以原well內西側窄走道與南腳landing有限接續。不宣稱完整室內交通或現場法規淨高。攝影日期未知，不代表已核實2026現況。山下校區是官方校圖與相鄰樂活館照片的綜合定位，A12不是本舖自身標號。

# 國立中興大學小禮堂：重建後主廳外觀研究

![主廳外觀模型](previews/front.png)

依據興大影音網 **2015 年 11 月 30 日空拍**與《興大校友》第 16 期第 59 頁「小禮堂現貌」照片製作。這是 **921 震災後重建版本的主廳外觀簡化模型**，不是 1943 年原建築，也不代表已驗證 2026 年現況。

## 範圍

- 主廳長矩形量體、完整可見雙坡屋頂、正面三角山牆、五道半圓拱門廊、三個閣樓通氣口及紅色門廊斜屋頂。
- **不含旁側中庭、附屬迴廊、廂房、角塔、連接廊道及周邊校舍**，不是小禮堂建築群的完整重建。
- 樹木遮蔽或照片未交代的側面與後面細部，用淺色無細節平面表示；不代表實物沒有門窗或通道。
- 所有尺寸、屋頂坡度與門廊深度均為照片比例估計。模型約 100 × 186.5 × 74.75 mm，沒有對應實測比例尺。
- 門廊後方深色開口是等距簡化色塊，不能據此推定實際門窗數量、尺寸或用途。五個半圓門廊拱洞與三個山牆通氣口的數量則有正面照片依據。
- 地面底座是展示支撐；階梯數、柱腳與窗框為製作性簡化。未重建室內、磚石接縫、瓦片、燈具、植栽及人物。
- 顏色為未校色照片近似。3MF 含七種面材質，其中「未知側後牆」與「展示底座」為說明性配色，不是實物材質測量。

## 檔案與檢查

包含可重建 Python 程式、STL、彩色 3MF、Blender 場景、預覽及格式 QA。Blender 可編輯構件保留在隱藏集合，正式可見模型為單一連通聯集。

拓撲與格式檢查不等於完成實機試印。來源照片僅作私人參考，未附於公開模型包。來源與限制見 [SOURCES.md](SOURCES.md)，重建步驟見 [REBUILD.md](REBUILD.md)。

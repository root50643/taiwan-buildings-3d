# 校本部（三芝校區）

本批只完成多功能教學活動中心（K棟）2013落成版本的來源限定外觀近似；未稱全校完成。2025年8月1日前校名馬偕醫學院，為同一校，不與馬偕醫護管理專科學校混同。校區用教育部「校本部」，校方亦稱「三芝校區」。

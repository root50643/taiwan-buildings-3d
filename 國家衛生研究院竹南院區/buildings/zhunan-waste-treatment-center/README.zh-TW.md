# 國衛院竹南院區廢棄物處理中心：公開外殼

依公開真實外觀照片製作的獨立微縮模型，未使用施工圖或現地丈量。不是院區統一比例模型，也不是竣工測量檔。

## 已呈現與範圍

- 白色方格外牆、高女兒牆正面、兩個寬闊的關閉捲門與左側較低的附接量體。
- 只建置一個可見建築外殼；未製作處理設施、設備、管線、運作或內部配置。捲門只是封閉實體上的淺凹紋理，沒有穿透。
- 只有公共外觀主立面可清楚辨識；總深度、背面、被樹木遮住的左端外形為估計。
- 模型尺寸：150.0 × 84.0 × 51.6 mm。以mm匯入；最長邊150 mm。單一連通實體，底座是模型的一部分。
- 檔案採實體外殼及淺凹窗紋，不含室內、實驗室或保全配置。

## FDM列印建議

- 底座朝下；0.4 mm噴嘴、0.16–0.20 mm層高、至少3道外牆、10–15%填充可作起始設定。
- 底座厚3 mm；門上水平眉梁厚2.2 mm、約1.5 mm外挑；屋簷線厚1.1 mm。捲門與磁磚線為0.3–0.42 mm表面紋理，細線可能受噴嘴寬度影響，並非承重薄壁。門窗凹紋深約0.8–0.9 mm；請檢查短懸垂，視切片結果局部加支撐。
- 不建議直接大幅縮小；縮小後需重新檢查最小細節。材質色只供預覽，STL沒有顏色。
- 尚未進行實體列印或切片軟體驗證，並未保證免支撐。

## 交付檔案

model.stl為mm列印網格；model.obj提供通用編輯網格；scene.blend是實際STL匯入的可編輯Blender場景；previews含實際STL正面、後面及正視PNG。build_model.py是可重建原始碼，render_preview.py從STL製作預覽，requirements.txt列出依賴。validate_model.py和validation.json記錄數位驗證；SHA256SUMS供檔案完整性核對。

## 重建與驗證

本次使用Python3.12、Blender4.3.2。請先安裝requirements.txt，再執行：

```sh
python build_model.py
blender -b -t 4 -P render_preview.py
python validate_model.py --output validation.json
```

驗證直接檢查交付STL的原始面法線、有限座標、非退化面、封閉性、朝向、每邊兩面與每個頂點的連結環，確認只有一個連通表面殼、沒有另行封閉的內殼、正體積、平底及尺寸，再重建比對STL雜湊並載入保存的Blender檔比對實際三角形幾何。此檢查不修補交付檔；不是完整自交檢驗或物理列印合格證。

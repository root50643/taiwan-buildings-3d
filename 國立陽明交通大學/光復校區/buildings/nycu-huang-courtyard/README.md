# 陽明交通大學光復校區｜炎松之圓（2024）

**科學三館中庭的完整獨立紀念看臺／舞臺外觀近似，不是科學三館整棟，也不是整座中庭模型。** 依2024專案刊載的完成照片製作，沒有現場測繪；個別照片拍攝日期未知，**不宣稱2026現況**。

## 保留的完整外部構成

- 近圓形薄不鏽鋼晶圓意象外殼：前半近水平、後半向上彎起，背緣中央較高而向兩側下降。不是整片斜平板或厚實圓柱底座。
- **七排水平格柵座臺**，沿圓界向後縮短；格孔為真正幾何開口，排下保留負空間、斜向薄板支撐、細橫肋與前緣框。不是七塊實心階梯或封閉立板。
- **僅正面左側的七個插入半階**，包括低舞臺上的第一階；不是十四排座臺，也未鏡射成雙樓梯。
- 單一後／側半弧扶手、疏列支點與前端下折固定；**前低舞臺弧緣沒有環形欄杆**。
- 淺凹座墊與向下捲的半圓裙邊，藍、淡藍及透明白色分組排列；沒有改成椅背、椅腳或球體。
- 依完成照片06逐粒交叉辨認，最低前排至最高後排為 **10、8、7、7、4、3、2，共41個可辨座墊**。這是該照片狀態，不是官方永久座數；分組位置按照片比例近似，未任意各排均布。

## 尺度、狀態與簡化

輸出以**盤徑約160mm**作顯示尺寸選擇，不代表測得的建築比例尺。來源列50㎡，但沒有可據以復原精確直徑、曲率或施工截面的量測資料；不能將面積反算結果冒稱實測。盤曲率、各排高度與間距、斜板截面、格柵密度、欄杆支點及座墊位置／逐墊配色均屬照片近似。

模型刻意降低格柵密度，但保留真正格孔及主要排下空間。省略微小安全纜線、LED、焊縫、地板晶片蝕紋、細排水縫、人物肖像及背部長段文字；左側半階原銘字「道、天、地、將、法、容、易」未在此尺度雕刻。來源04下緣可見的細小足點省略；隱藏基礎與精確底部固定方式未測繪，不補造完整工程構造。

**20張私有來源影像均無EXIF拍攝日期。** 2024是專案／文章資料年代，不能當作每張照片的拍攝日；圖片網址中的資產日期或查詢參數也不是拍攝日期。概念剪紙、晶圓加工意象及效果圖只作概念理解，不拿效果圖取代完成照片的座墊數量與形體。

座墊是有厚度的實體網格。Blend／3MF以材質Alpha提示透光感，**STL沒有顏色或透明度**；這不等於實印透明，也不能將座墊位置當作幾何空氣。模型是融合網格，可編輯頂點、逐面材質及生成參數，不是預拆成可動零件的裝配套件。

鄰接科學三館樓體、三角採光構造、黑色圓形鋪面、人物、庭院地磚、排水溝與景觀不屬於本紀念設施，未納入。

## 列印限制

**未實印，不保證免支撐。** 真格柵、排間懸挑、半階、薄座墊裙邊、斜殼與扶手有薄件、橋接及支撐拆除風險。全局0.2mm切層與局部0.8mm核心檢查保留全部失敗項，不以水密或單連通網格冒稱可免支撐列印。縮小模型會增加薄件風險；請按設備、材料和擺向自行切片、評估支撐並實印。[完整QA](QA.md)。

## 重建與驗證

使用Python3.12及Blender4.3.2；依賴見`requirements.txt`，Blender需另裝。從模型目錄執行：

```bash
python build_model.py
python qa_model.py
python check_features.py
python verify_exchange.py
blender -b -t 8 --python-exit-code 1 --python render_model.py
blender -b -t 8 --python-exit-code 1 --python verify_scene.py
blender -b -t 8 --python-exit-code 1 --python verify_render.py
python rebuild.py --output ../independent-new --threads 8
python verify_package.py
```

`rebuild.py`要求新的輸出目錄。同環境CPU Cycles固定seed、無降噪；PNG只去除文字／日期metadata，不改像素。隔離重建比較核心四檔與五PNG bytes，Blend幾何／材質另驗，不宣稱跨路徑Blend檔bytes一致或跨軟硬體渲染一致。修改模型後須更新release，重跑QA與來源審查，不沿用舊hash。

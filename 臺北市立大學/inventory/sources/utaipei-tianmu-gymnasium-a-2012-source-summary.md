# 臺北市立大學天母體育館A棟：來源摘要

範圍為2012年天母體育館A棟單棟外觀。現屬臺北市立大學，教育部115學年度名錄代碼3002；前身臺北體育學院不另計一校。B／C館及博愛校區不在本件範圍。

## 主要來源

- [校方原始營運簡報附件頁](https://pe.utaipei.edu.tw/p/405-1020-29708,c4359.php?Lang=zh-tw)：11頁PPT有三層平面、兩剖面、西側入口及部分北面照片；未確認竣工章。原PPT SHA256為9e5af5715a2f9e9a16035136ed67808ba1b81ab9becdd506ade33991a7253c0d。
- [市府工程資料](https://nco.gov.taipei/News_Content.aspx?n=528B8D8F449CEE76&s=996D01EB6491A8AC&sms=47D2B47B3DA0736F)：三層鋼構、建築識別及工程背景。
- [屋頂廠商作品頁](https://gomore.com.tw/2015/project_TUTMA.html)：完工東側高視角可見銀色雙向曲面、採光帽及粉檐；施工照只輔助結構形式判讀。
- [承包商原相簿](https://www.hcgc.com.tw/project/display/114)：混合建築相簿，僅使用逐張確認為A棟的外觀照。
- [國土測繪中心PHOTO2服務](https://wmts.nlsc.gov.tw/wmts?SERVICE=WMTS&REQUEST=GetCapabilities)：只輔助屋頂平面比例及方位。NLSC2024水印不是已驗攝影日期。
- [校方沿革](https://schedu.utaipei.edu.tw/p/412-1014-3.php?Lang=zh-tw)：2012年前身建築歸屬現今臺北市立大學。
- [教育部115學年度名錄](https://stats.moe.gov.tw/files/opendata/u1_new.json)：正式校名及代碼3002。

## 直接資料、估計及製造調整

兩官方文字的啟用月份不同，只採共同支持的2012年。校方簡報不是已確認的竣工圖，早期四層加二層地下室舊方案不混入模型。剖面400／400／582按cm解讀為樓層間距，得2FL 4.00、3FL 8.00、RFL 13.82 m。名目約1:500；整體、曲面與採光帽尺寸是比例推估，不承諾測量精度。

粉色波形為牆頂飾板下緣，東西短面三段、南面兩段；北面只實證近B梯入口、捲門、相鄰窗與局部下緣，遠端窗列及整面波形仍保守推定。方位由圖照及正射相關推定，原圖未確認北箭頭。

窗框約1.04 mm、梯欄改約1.2 mm實心側板，粉檐平端及中央帶留足厚度；採光帽未量測角部局部抬頂／底部修形，略改輪廓，不是已驗構造。沒有添加來源看不到的角柱或大斜撐。局部薄特徵、支撐及未實體試印限制見模型說明。

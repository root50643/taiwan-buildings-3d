**新建模／歷史影像限定片段，不是整棟模型或測繪成果。** 此套件重建中央高入口、實際貫通的斜角門洞、門頂淺格梁、兩排橫帶窗、兩側細長窗帶、少量左翼與前階梯。右方受樹木遮擋的翼部不補鏡像；後側及深度為明確裁切邊界，不代表實際背面。既有彰師大其他模型不變。


## 檔案
- `model.stl`：單一連通、封閉實體，單色列印交換檔。
- `model.3mf`：相同三角面，7 種可編輯顯示材質。**不是已分配耗材／擠出機的切片工程**。
- `scene.blend`：相同交付幾何、可編輯材質、5 個預覽所用攝影機設定（腳本可重建）、燈光；無參考照片或外部紋理。
- `build_model.py`、`render_model.py`：生成與實際網格渲染程式。`mesh.json`、`palette.json` 提供可讀面與材質資料。
- `qa-topology.json`、`qa-layers.json`、`qa/*.json`：原始 STL 拓樸、590 層幾何截面、特徵檢查、3MF/Blender 實際編輯回讀、渲染紀錄。
- 另見 [來源與幾何對照](SOURCES.md)、[驗證與列印限制](QA.md)。

## 重建
Python 3.12 套件：numpy、trimesh、manifold3d、shapely、lib3mf；渲染使用 Blender 4.3.2 / Cycles CPU。

```sh
python build_model.py
python qa_model.py --out .
python check_features.py
python verify_exchange.py
blender -b --python render_model.py
blender -b --python verify_scene.py
```

請先在支援 mm 的切片器檢查方向、支撐和最小特徵。門洞上方約 43 mm 跨距、斜角肩部與格梁需要支撐／拆件評估；**未做實際列印或機器切片，不保證免支撐**。0.9 mm 窗框是有背板的浮雕，不是獨立懸空細棒。不要只因網格封閉就直接判定可印。

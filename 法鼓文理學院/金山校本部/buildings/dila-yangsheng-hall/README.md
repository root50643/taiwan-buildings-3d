## 檔案與重現

- `model.stl`：100 × 150 × 46.990002 mm，單一連續底座與表面殼。
- `scene.blend`：從交付 STL 匯入，可編輯網格；相機、燈光均保留。
- `build_model.py`：原創參數式 CSG 源程式，未使用第三方網格。
- `render_preview.py`、`previews/`：八張實際 STL 視圖，含南北低視角及屋頂細部。
- `sources.md`、`source-dimensions.json`：來源與局部推定；`QA.md`、JSON/CSV：數位檢查。

以 Python 3 與 `requirements.txt` 所列套件執行 `python build_model.py`，再以 Blender 4.3.2 執行 `blender -b -t 5 --python render_preview.py`。最後執行 `python run_all_checks.py`。驗證不修補輸入 STL；清潔目錄重建 SHA 與 Blend 幾何、PNG 位元組均另核。

## 來源口徑與推估

建築師頁為2015年作品口徑，區公所紀錄為2014-08-11竣工，兩者不互相替代。公開文字的建築高22.7 m用於長條棟；球場7 m淨高不等於全館高度。西館17 m、外廊低帶、地形及到達平台高度均為照片與平面限制下的局部推定。南平台局部高6.2 m與建築DATUM=4 m的零點不同，請見來源表。

建築師球場層平面沒有可讀官方比例尺，採0.0603 m/像素與NLSC屋頂長寬交叉配準，僅為建模比例。NLSC字樣/年份不等於航攝日期。五條主館屋頂帶僅做低幅起伏，未主張工程天窗剖面；同頁行政樓剖面及樓梯間照片沒有拿來當球場剖面。

西長邊五盒位置由平面支持，南凸盒的側面玻璃可見；西五盒側玻璃屬類比簡化，沒有聲稱所有西側實景皆確證。東面與西低層不清楚的細窗省略。兩橋只保留近館段與模型支根，不延伸整座宿舍或道路。

## 列印簡化與限制

建議底座朝下；切片前依機器、材料及懸挑方向評估支撐。

- 南端兩層共用大框內，0.935 mm中板、內退0.85 mm欄帶及1.0251 × 1.0251 mm中央柱為加粗簡化；細柱根接樓板，欄帶根接側牆。
- 玻璃為有背牆的凹面與融合細框；玻璃不透明。走廊、橋下與上下平台之間仍保留可辨認凹空。
- 玻璃細框與橋欄最小寬約0.82 mm，已接近0.8 mm數位篩檢參考線；不適合任意再縮小。小框、欄杆、橋端、懸挑及細簷可能需要支撐。
- 原始構件先落在0.00001 mm共同建構格再做CSG，避免跨軸浮點座標造成相切薄屑，沒有以修補吞掉錯誤。
- 地形只示意兩段大階梯和擋牆，不是現況地形或結構模型。未實際試印；數位檢查不保證免支撐、切片成功或特定機器可印。

數位審核紀錄見隨附報告；是否正式發布以統一發布清單為準。第三方原照、PDF與私人核對圖不在此包。

本批僅揚生館；其他教學、行政、住宿與宗教空間未建模，不代表全校完成。後續可延續建築師整體校園來源逐棟研究，先釐清法鼓文理學院與僧伽大學／寺院棟界。

## 獨立特定薄損例外
原始235層770個Polygon逐件侵蝕及opening零消失／分裂。351個>1%是8族跨層樣本，不是351根柱；原WKT及正式opening數值完整保留，沒有改用理想矩形取代。原截面矩形身份只作佐證，原面法線及根另測：東橋102筆最小1.5376511mm、南下擋牆2筆1.5376510mm、南角墩67筆1.2301178mm、西北角墩117筆1.2301216mm、北橋51筆1.5376511mm、南上擋牆2筆1.5376492mm、內退欄杆兩柱9筆1.0250988mm、西北屋簷角1筆1.7426681mm。所有警告探測起點在原實體內；兩欄柱向下接樓板、向上接欄帶，其餘指定樣本根連至基底，336原面控制射線重現。
9筆欄柱樣本最大損失13.14696384744%、保留86.85303615256%，細欄不得以全層最大0.14996534288%掩蓋。8筆原作者0.6mm角區外直邊微殘差最高0.006287658521mm²保留；獨立真四角0.41mm區外最高0.006852099738mm²／原構件0.1025258520%，完全在原邊界0.005mm內，不能稱純角零損或抹除數值。上述有限尺寸及根證據支持本件特定例外，非全方向／全域最小壁厚或實體可印保證。細欄、橋欄、挑簷仍須切片評估支撐和拆除，不得任意縮小，未實際試印。

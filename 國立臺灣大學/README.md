# 國立臺灣大學建築模型

首批 **5 件外觀近似模型**，位於校總區。這不是全校建築完成清單；歷史前棟及學院主要教學棟的範圍限制詳見個別說明。每件獨立展示尺寸，沒有共同校園比例尺。

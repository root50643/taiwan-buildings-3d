# 國立高雄科技大學｜燕巢校區

本批 1 件局部外觀模型。全校及本校區都尚未完成，沒有宣稱完整建築數或完成率。

地址：高雄市燕巢區深中路58號。合併前／來源校名：國立高雄應用科技大學。

本批圖資模型只含入口翼，排除相連右轉圖書館翼、完整後部及室內。四組立面框各三列高窗不等於整棟樓層數。

# 數位檢查索引

- [來源／外觀解讀](source-appearance-review.json)：三張原圖實看、四柱與八邊帽頂解讀、簡化及預覽覆核。
- [建模幾何摘要](build-geometry.json)：尺寸、單件連通性與材質三角面數。
- [STL／接觸面／承托解析](geometry-validation.json)：保留柱架11、吊鐘2旗標，並非實際FFF切片。
- [Core 3MF與編輯重存](exchange-validation.json)：嚴格讀取、面序／顏色對應與量化誤差。
- [乾淨重建](rebuild-validation.json)：同版本依賴的10檔SHA一致。
- [場景重開](scene-validation.json)：網格、材質與組裝變換；不帶照片、外部庫或內嵌腳本。
- [渲染紀錄](render-manifest.json)／[PNG像素與metadata](preview-validation.json)。

這些檢查只支持有界外觀／幾何／配色交付，不代表測繪精度、真機可印、免支撐、膠合或全校完成。原始照片、私人恢復包及診斷G-code均不公開。

# 國立成功大學・光復校區

[返回學校總覽](../README.md)

本校區目前收錄 16 件數位外觀近似模型；包含局部段或同一財產不同量體，件數不等於完整建物棟數。各件含底座最長150mm、獨立縮尺。尚未完成全校，未實體試印或進行印表機切片驗證。

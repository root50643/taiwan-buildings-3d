# 大葉大學學思亭｜完整方亭外觀模型

![實際模型預覽](previews/front.png)

[彩色可編輯 Blender](scene.blend) · [七色 3MF](model.3mf) · [無色 STL](model.stl) · [生成器](build_model.py) · [檢測與限制](QA.md)

大葉大學校本部、圖書館東側環山步道上的獨立學思亭。依校方連結的 2003–2012 年歷史照片及拍攝日期不明的官方全景製作；**不是 2026 現況測繪、不是精密比例模型或實體試印認證**。

## 保留的完整形態
四根紅色方柱、上下兩圈連續紅梁、四坡金屬屋頂向中央方帽匯聚、三側黑色水平欄杆與開放入口、低地坪、中央厚石塊與窄底座。中央方帽功能未查證，使用有背襯的不透明格紋；不是玻璃透光模擬。方帽格紋亦簡化，非精確格數。石塊用途未知，不稱桌、祭壇或紀念碑，也不添加字樣。

依正面完整照片保留兩側各三凳與前方一張獨立凳，凳下留空。後方被中央石塊遮蔽的座位細分省略，不臆造整齊後排；因此室內家具細節非完整複製。屋面接縫、欄杆支柱數、接合與比例均為可列印展示近似；屋底不杜撰隱藏工程構造。

## 尺寸與操作
整體 126 × 126 × 107 mm，含人造展示底座；記錄地坪寬108 mm、屋簷寬108 mm。沒有測量資料，不指定真實 1:N 比例。STL 不含色；3MF 展示材質不是多色擠出機配置。Blender 含同一實際網格與七材質，可修改材色及頂點；生成器提供構件參數。五張預覽均由交付網格渲染，無照片貼圖。

`python build_model.py` 生成 STL/3MF/mesh/palette；`python qa_model.py` 與 `python check_features.py` 檢查原始網格；`blender -b --threads 4 --python-exit-code 1 --python render_model.py` 重建場景及五圖。依 requirements.txt 安裝依賴。交換檢驗另需官方 lib3mf。

**屋簷、凳面、長橫梁及欄杆需要切片器支撐/方向規劃。薄處測試仍有失敗，詳 QA.md；沒有免支撐或成功列印保證。** 不含山坡、樹木、階梯、路燈及遠處建物。來源照片不隨包散布。

# 有庠科技大樓：原始網格與可重現性驗證

本件是依建築初期照片重建的代表性外觀模型，所有尺寸均為估計，並非實測圖或現況測繪。建築外觀來源審查與以下製造前檢查分別記錄。模型保留兩個天井、不平行雙翼、兩端巨大框架及玻璃盒；沒有以填平孔洞取代幾何修復。

## 檢查方式與原始結果

最終原始二進位 STL 為 47,770 個三角形、單一閉合表面，模型外框 219 × 107 × 119 mm。驗證直接使用此 STL，不進行網格修補或重新三角化。所有工具、原始輸入、結果與控制測試皆以 SHA-256 綁定。

- 水平切片使用 0.2 mm 間距及 0.031、0.071、0.137 mm 三組錯位，逐層、逐原始多邊形檢查 0.8 mm 參考寬度的侵蝕與開運算；個別面積損失上限維持 1%。
- 密集射線檢查使用每個原始面 10 個樣點，共 477,700 條射線。完整原始 CSV 包含實際 C++ origin/direction 的 lossless hexadecimal 數值，不能以重新計算的相近射線替代。
- 原始數值密集射線與總彙整的 strict_passed=false 保留原樣。每一個原始警示都必須有對應的完整精確有理數線段／事件分類，涵蓋同一 STL 上的全部原始面；不得只以警示名稱豁免。0.8 mm 條件不變。
- 全原始面的閉區間 AABB 候選組合及精確接觸檢查記錄所有真實接觸。合法的同一表面頂點／邊接觸與不合法穿越或重疊分別處理。
- normal 與 Python -O 各自重新執行。作者與獨立檢查的完整科學資料原 bytes 比對；只有已明列的執行耗時及其報告雜湊連結可不同，原報告不改寫。

最終實測數量、精確警示結果、控制測試計數與所有完成狀態，見機器可讀的 QA-RESULT.json 及其原始證據。此說明文字本身不構成通過憑據。

原通用彙整在密集射線警示處停止給予嚴格通過，因此其後續模式一致性欄位也未標為通過。該原始 JSON 完整保留；真正的跨模式與作者／獨立一致性，另由完整科學原 bytes 比對記錄證明，不能改寫原通用結果。

## 原碼、場景與九張圖

在本次記錄的工具環境中，原碼必須重建完全相同 bytes 的 STL 與色域資料；完整使用中的場景狀態須相等，包括 Noise 節點 mapping、材質、燈光與全部相機。獨立九圖重播固定為 Cycles CPU、64 samples、單執行緒、固定 seed，且關閉 denoising。此環境無可用 OIDN，沒有宣稱使用它。

公開 PNG 僅移除狹窄白名單內的動態／私有文字 metadata，不重編像素。IDAT、解碼 RGBA 及所有保留 chunks 的等值均須驗證。公開圖、原始圖、重播圖、場景與來源審核逐張相互綁定。

## 限制與列印前確認

有限射線與切片取樣不能證明整個連續表面的全域最小壁厚，也不代表已實際試印。原始數值警示沒有被改成一般 strict 通過。精確補證與完整正反控制只支持這一份凍結模型及所記錄的驗證範圍。

本件尚未實體試印。懸挑、框架內頂及玻璃盒等部位需要支撐；請按設備、材料、層高及擺放方向檢查切片預覽。未量測的細節、背面與遮蔽面仍含簡化，所有尺寸與地理方向不得當作實測資訊。

# 國衛院竹南院區：station 48 外觀次量體

本包是國家衛生研究院竹南院區公開環景「48 ABSL3實驗大樓」所見白色塔狀建築外觀的可列印近似模型。只選取照片中的這一外觀量體，不包含既有疫苗工廠主量體，也不代表完整設施或法律上的獨立棟數。

## 來源與範圍

- 官方公開校園環景：https://campus.nhri.org.tw/
- 定位：station 48，畫面標名「ABSL3實驗大樓」。環景日期標示「2017 春景 Spring」。
- 官方站點縮圖：https://campus.nhri.org.tw/3dspace/thumb/049.jpg
- 外觀參考檢視日期：2026-10-11。實際建模前已檢視該站點的公開實景照片；縮圖僅供來源定位。
- 可辨識特徵：白色大面積中央牆、左側細長凹入玻璃帶、右側較寬玻璃面、平頂與立面端部高差，以及可見的地面入口外框。
- 照片中的空中連橋連向主建築。本模型省略整段連橋及其接頭；連橋的存在只能支持外觀量體相分離，不能據此推定法律或構造上的獨立建築棟數。
- 不包含照片中的獨立遮棚、植栽、路燈及地景物件。底座為模型展示與附著用，並非實測基地。
- 不研究或呈現室內、設備、管線、作業、防護或保全配置；亦無隱藏內部構造。
- 本包未重製或附送第三方參考照片。預覽圖均由本包實際 STL 生成。

## 近似程度

這是公開照片導向的外觀縮尺作品，並非竣工圖、工程測量或現況完整紀錄。照片帶有仰角、遮擋及環景變形，不能當作精確比例依據。完整背面、側面、屋頂深度及實際尺寸未獲驗證；本模型以封閉平面和簡單平屋頂保守補足，不添加未見的門窗、附屬量體或屋頂設備。

右側較低量體的高度差取自照片中的可見立面輪廓，其延伸深度仍為近似。中央牆上只保留放大且稀疏的表面分縫；分縫、玻璃格線與入口框的尺寸及節奏已為 FDM 製作調整，不應當作實際磚縫、樓層數或門窗數的精確記錄。入口一部分受到連橋遮擋，僅以淺浮雕表示可見外框。

## 尺寸與列印

- 單位：毫米。包含底座的外接尺寸為 116 × 82 × 150 mm，最長方向 150 mm。
- 各建築模型均為獨立展示尺寸；本模型沒有與其他校園模型共同比例尺。
- 一個相連、封閉的實體，底部位於 Z=0，底座厚 3 mm；無可分離零件及內部空腔殼。
- 依目前方向底座平放列印，不要把 STL 當成公尺尺寸匯入。
- 建議起點：0.4 mm 噴嘴、0.16–0.20 mm 層高、3 道外牆、10–15% 填充。這些是建議，沒有實際切片或試印驗證。
- 正向細節最細為 1.1 mm 寬的窗格框；入口中框為 1.3 mm。各框均與後方實體相連，並非懸空細桿。
- 中央淺縫寬 0.65 mm、深約 0.325 mm；縮小列印可能使它們消失。最薄突出頂部立面片厚 2.6 mm、高出主屋面 3 mm。
- 玻璃凹面深約 0.75–0.95 mm，窗框前凸約 0.5–0.65 mm。入口量體向主立面前伸約 4.55 mm，但從底座一路相連，沒有懸空入口樓板。
- 不需要為本來的空中連橋設置支撐，因為連橋已省略。凹面上緣及少量外凸邊緣可能受印表機的短距懸垂能力影響；請先檢查切片預覽，必要時局部支撐或調整方向。未保證免支撐。
- 立面與底座是同一實體。STL 沒有顏色；預覽中的淡白及青灰色只是 Blender 顯示材質。

## 檔案

- `model.stl`：毫米二進位 STL，供切片。
- `model.obj`：同一外觀網格，供交換編輯。
- `scene.blend`：可編輯的 Blender 場景，內含與 STL 一致的一個網格、顯示材質與預覽相機。
- `build_model.py`：原始可重建幾何程式。
- `render_preview.py`：匯入實際 STL，輸出正面、背面及正立面 PNG，並保存 Blender 場景。
- `front.png`、`rear.png`、`elevation.png`：已逐張目視檢查，完整框住模型與底座。「front／rear」只表示預覽方向與主要參考立面的相對關係，並非測量確認的官方方位或建築正背面名稱。
- `requirements.txt`：Python 套件版本。
- `validate_model.py`、`validation.json`：可重跑的檢查程式與本次結果。
- `model-info.json`：機器可讀的來源、尺寸及限制。
- `SHA256SUMS`：除其自身外所有交付檔案的 SHA-256。

## 重建與驗證

使用 Python 3，先執行 `python -m pip install -r requirements.txt`，再執行 `python build_model.py`。Blender 4.3.2 已用於本次輸出；可用 `blender -b -t 4 -P render_preview.py` 重建場景與預覽。最後執行 `python validate_model.py --blender blender --output validation.json`；若 Blender 不在 PATH，將 `--blender` 後改為本機 Blender 執行檔位置。

`scene.blend` 使用毫米場景單位。原始 Python 程式是尺寸調整與重新建模的來源；Blender 場景中的三角網格可直接編輯，但並非保留布林歷史的參數化場景。檔案可以移到其他資料夾使用，不需要原製作環境的路徑或參考照片。

本次檢查通過：原始二進位 STL 長度、有限數值、原始法線單位長度及與三角形繞序一致性、非退化三角形、封閉性、每條邊恰有兩面、每個頂點連結為單一環、單一相連表面、無分離封閉內殼、正體積、底座 Z=0、最長 150 mm、來源重建 STL 雜湊相同，以及 Blender/STL 三角形幾何一致。

模型共有 1,030 個三角形、517 個頂點；非流形邊及不合法頂點連結均為 0。這些檢查不等於實際切片、實物列印、完整自相交證明或任何建築工程認證。

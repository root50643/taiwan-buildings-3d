# 本版幾何與重現檢查

此文件只適用於本資料夾的重新建模版本。獨立稽核已確認限定條件下的幾何與重現檢查通過；原始 137 筆嚴格法向失敗仍完整保留。這不是全域最小壁厚或免支撐列印保證。

## 本版精確紀錄

- STL SHA-256：`47b25ef7c42c2827008b04a711eda1c6555ba90ee547445d8209e7363d2076e9`。
- 15,224 個原始三角形、7,610 個精確座標頂點、單一表面殼；原始法向、每邊與頂點連結檢查通過。
- 266 層未四捨五入截面、660 個原始 Polygon；每個 Polygon 均通過 0.8 mm 開運算存活／不分裂檢查，最大個別面積損失約 0.2751%。
- 152,240 筆固定原始法向樣本中，**137 筆短於 0.8 mm，strict dense 仍為 false / exit 1**。它們分屬北西外角 56、北東屋頂外角 25、南西外角 48、低端尖角 8；不是所有角點都可豁免。
- 137 筆均保留原始短弦與完整交點，另有實際原始邊、固定內角平分方向及根部證據。274 個原法向／根部完整區間與 5,480 個全網格材料／空氣點通過作者端檢查。

精確值與檢查綁定以各 JSON 報告及 SHA256SUMS 為準；獨立複核結果請由學校目錄的 QA 連結查閱，並核對本版 STL 雜湊。

## 完整重跑

Python 3.12、requirements.txt 所列版本、g++（支援 C++17/OpenMP）及 Blender 4.3.2。先執行 python build_model.py，再以低記憶體 CPU 模式產生實際 STL 預覽：

    MALLOC_ARENA_MAX=2 LP_NUM_THREADS=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 blender -b -t 1 --python-exit-code 1 --python render_model.py
    python run_checks.py

run_checks.py 包含來源／參數追溯、原始二進位 STL、每一個原始截面元件、全部面之固定重心座標射線、特定角點的真實原始邊與連通面片證據、完整首次材料及隨後空氣區間、全網格材料／空氣點檢查、故意破壞的法向／短閉環／非法 Polygon 負例，以及獨立重建／重新開啟 Blend／五視角重新渲染。

## 判讀原則

- 不使用網格修補、頂點座標四捨五入、重建後替代網格、刪面或忽略小截面。
- 原始 STL 必須是單一表面殼；逐一檢查原始儲存法向、面積、每邊恰兩面、反向共邊、頂點連結循環與正體積。
- 0.2 mm 間距截面使用原始邊方向一致的未四捨五入交點，閉合及 Polygon 合法性均失敗即停止。每一原始 Polygon 個別做半徑 0.4 mm 開運算；不能消失或分裂，個別面積損失也不能以整層平均隱藏。
- strict dense 的短於 0.8 mm 首次法向材料弦保留為 false / exit 1。它們不會因另一方向較長而被刪除或改寫。
- 只有四個事先限定的來源角點、距真實原始垂直邊 0.35 mm 內，才進入額外證據檢查。必須證明相鄰真實面、連通近共平面片及固定內角平分方向，並保留原法向的完整交點和隨後空氣。
- long double 原始三角形射線及平行面區間裁切核查整個首次材料／隨後空氣區間；全原始網格立體角另驗材料與空氣點。有限樣本中至少 0.8 mm 的連續根部支持不等同全域最小壁厚，也不保證實體列印成功。
- 保存的 Blend 只含一個標示 STL SHA 的可列印網格，另有明確命名的渲染地面。驗證重新開啟的可列印網格所有三角形座標及方向，與原始 STL 完全一致。
- 五張預覽直接由實際 STL 渲染；材質只區分現有凹窗、凸遮陽盒及底座，沒有照片貼圖或影像生成。獨立重渲染須像素及 PNG 位元組一致。只移除 Cycles 的文字計時中繼資料，不更動像素。

精確數值、每筆保留診斷、完整交點及點控制保存在 JSON / gzip 報告，均以 STL SHA-256 綁定。qa-summary.json 保留稽核前的作者端證據彙總；獨立複核結果另列於學校目錄的 QA 連結，不覆寫原始 strict false 診斷。

# 國立中央大學太空及遙測研究中心館｜150 mm 外觀模型

此為公開外觀資料研究模型，非測繪、施工或正式切片檔。每棟獨立縮尺，含底座最長150 mm，不能直接當作同一比例校園拼圖。本檔尺寸約 150 × 143 × 105.459 mm。

## 保留的識別特徵
- 三層凹字雙翼、深內院與內縮入口
- 連續突出遮陽盒及水平屋頂簷口
- 較高屋頂接收塔、外梯與傾斜凹面碟天線

## 證據與簡化
- 三層凹字量體、內院與屋頂天線有2026公開實照；外側後立面與總深仍未充分可見，素面簡化，非測繪。
- 天線以直径50 mm、軸向厚2 mm的旋轉拋物碟近似，傾角/尺寸目測，非可運作天線。背肋、饋源桿、鋼索、欄杆等纖細構造省略。
- 屋頂樓梯改為有實體支承的加厚階梯，附屬小屋位置/尺度近似；院內窗框、出挑遮陽盒與門廊粗化。
- Commons01/03摘要日期2026-08-14，04/05摘要2026-08-13，雖檔名同為08-14，保留差異；不以2025官方圖冊年份當拍攝年。
- 薄特徵篩查5個警示截面均在天線最高弧緣z101.071–105.071 mm。最頂層截面僅3.6863 mm²，被0.8 mm形態開運算全部移除；保留警示，需切片檢查/可能犧牲尖薄弧緣，不能保證印出完整邊緣。

全部來源及照片/設計圖區分見 sources.json。來源原照片、PDF、內部對照圖不隨模型發布。照片年代不同，不聲稱完整2026現況。

## 檔案與重建
- model.stl：單一連通列印實體，單位毫米
- scene.blend：由交付STL匯入的可編輯網格（不是參數化BIM）；預覽材質只供展示
- build_model.py：可攜參數化量體來源，無需來源照片即可重建
- previews/front.png、rear.png、elevation.png：從實際STL渲染，不是設計效果圖；名稱為相機視角，非精確方位

使用 Python 3.12，依 requirements.txt 準備相依套件，Blender 4.3.2。

    python build_model.py
    blender -b -t 2 -P render_preview.py
    python validate_model.py
    python check_layers.py
    python check_thin_features.py

## 幾何檢查及列印限制
原始STL法線與繞序一致、水密、每邊兩面、頂點鏈單環、單連通表面、無分離內腔殼、正體積、乾淨重建同SHA-256、已存Blender/STL三角幾何一致，詳 validation.json（passed=True）。

0.2 mm幾何截面共 527 層，全部閉合=True。另以1 mm間距檢查0.8 mm XY形態開運算薄特徵，5 層損失面積超過1%；尖角也會被計入，見 thin-feature-check.json。這不是全域壁厚保證，也不是正式切片或試印。

底座平放。整片傾斜碟天線底面為大懸挑，必须設計可移除支撐，注意細支座受力；遮陽盒與門廊也需局部支撐。建議先以0.4 mm噴嘴、0.2 mm層高在實際切片軟體檢查外壁、橋接、支撐可移除性與底板附著，再決定列印設定。小窗框、曲面尖端與薄簷口可能不完整重現；不得將幾何通過寫成「免支撐、保證可印」。

SHA256SUMS含可發布檔案雜湊。尚未實體試印。此為全校持續研究中的一件，不代表全校完成。

## 截面數值方法修訂與補查

本發布包已直接採用canonical-edge-v2薄篩工具與結果，固定共邊插值方向，要求節點度數2、閉環及各Polygon有效，再做1 mm間距的0.8 mm XY開運算。舊版可能因共邊端點分開計算後取整而漏環，不能沿用舊面積值。這項修正不改STL、Blender或重建來源；真實薄特徵警示照常保留。

另以0.2 mm間距逐層補查閉環及Polygon有效性，共 527 層通過，見[有效性報告](contour-validity-check.json)與[可攜檢查程式](check_contour_validity.py)。這項較密補查沒有做薄篩開運算；薄篩採樣間距仍是1 mm。兩者都不是正式切片、試印或全域壁厚保證。

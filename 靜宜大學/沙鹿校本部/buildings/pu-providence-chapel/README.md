## 範圍與可辨識特徵

依公開一層平面、縱剖面及多角度照片重建完整聖母堂外觀，含前端截平入口、前低後高的四片曲殼、十字形天窗實體凹帶、屋頂十字架、突出的側門廊、地下室承台與東側外階。不含獨立避靜中心；室內、板材細縫、精細扶手、雕像及設備省略。

屋殼不是四個相同圓頂。平面為後尖前截平的魚形；長向高點偏後，前後曲殼高差依剖面控制，左右曲率以多角照片作近似。缺乏製造座標與橫剖面，因此局部自由曲面、玻璃帶、側門尺寸不是精確測量。

入口上方採截平橫樑，不作一般完整圓拱門。玻璃以有背襯的凹面與加粗框表現，未作透明材料或薄懸空窗片。橫向玻璃帶凹差約1.925mm、主要帶寬約10mm；頂部靠十字架處漸收凹差，以保留連根厚度。

地形只表達入口及後端步道接近主層、側向下坡露地下室的關係，非地形測量。矩形底座及其斜面是展示支撐，不屬建築原有台基。外部台階級數與側窗採可印近似。

## 比例與尺度不確定性

輸出單位：毫米。含底座最長150mm；114×150×約75.2mm。建築採每實際公尺3.5mm的均勻比例，約1:285.7；展示地形另作簡化。

原刊平面長向以35m作近似，描點外緣面積約598.77㎡，與公開607㎡量級相符。607㎡的建築面積定義可能與屋殼外緣不同，沒有強制縮放成607㎡，也未將地下室總樓地板面積或避靜中心面積混入。

公開高度18.5m未說明起算點及是否含十字架。本模型主殼最高點約高於主層15.3m，主層相對下坡展示地坪約3m；十字架頂約高於主層17.8m。這些是分開記錄的比例近似，不能聲稱符合實測18.5m。控制點、原圖像素尺寸、尺度假設見[parameters.json](parameters.json)。

## 檔案與重建

- [model.stl](model.stl)：唯一列印幾何。
- [scene.blend](scene.blend)：由交付STL匯入的可編修網格、相機與預覽場景。
- [build_model.py](build_model.py)：原創參數重建來源，含平面及剖面描點。
- [requirements.txt](requirements.txt)：Python套件；Blender另需4.3.2或相容版本。
- [sources.json](sources.json)：來源、年代、用途及限制。
- [validation.json](validation.json)、[layer-component-check.json](layer-component-check.json)、[qa-summary.json](qa-summary.json)：數位驗證。
- [SHA256SUMS](SHA256SUMS)：逐檔校驗，不含自身。

安裝requirements後執行 python build_model.py；再執行 blender -b -t 4 -P render_preview.py；最後 python run_all_checks.py。驗證不呼叫repair、buffer(0)或make_valid。獨立暫存目錄重建須產生同一STL SHA；saved Blend須與STL每個三角形一致。

## 列印注意與QA界線

底座朝下。十字架軸與橫桿約1.4mm，根部深入主殼。天窗及窗框作實體連接而非漂浮薄片。跨距、側門頂部、曲面坡度及細件仍需依材料與列印機在切片器檢查支撐。

以0.2mm層高、起始z=0.071mm驗證原網格閉合輪廓；每個原始Polygon均須有效，0.4mm erosion及接續opening均保留單一Polygon，不准消失或分裂。0.8mm參考篩檢不是全方向最小壁厚，也不是實際Cura／Prusa工具路徑或實體試印；不保證無支撐可印。十字架有44個超過1% opening面積損失的警告層，不能只以「正常角損」略過；精確數值、特定例外及風險見下節。

## 十字架44個警告層：僅此幾何的特定例外

本說明只適用STL SHA256 `df84e1b7a4290b799082c7d2a2d23427fd6bb5cb3719ee2c82f73c152c84847b`。獨立審核確認原STL、重建、Blend、376個0.2mm層及7張PNG一致；但這不會消除下面的細件警告。

- 參考寬度0.8mm（erosion半徑0.4mm，再opening），固定起始z=0.071mm。超過1%面積損失共44層，全部位於z=66.471–75.071mm的十字架直軸／橫桿矩形截面。
- 最高損失發生在z=71.071mm：原面積2.1560013999999996mm²，損失0.13815224151264832mm²；損失6.407799248768964%，保留93.59220075123104%。全部44層的損失都位於原截面頂點0.41mm鄰域內，鄰域外損失面積為0mm²。
- 原始三角形法向射線抽樣：直軸厚1.4×1.5400009mm；橫桿截面約7.6999998×1.5400009mm。在x=−0.5、0、0.5mm的3根指定向下射線，均連續到z=0底座才首次離開實體。這只檢查指定十字架截面及根部，不代表整棟全方向最小壁厚。
- 全部376個原Polygon在erosion與opening後仍各為單一Polygon，零消失、零分裂。44層面積損失是經定位及根部證據審查後，針對此固定SHA接受的特定例外，不是把1%門檻全面放寬，也不授權其他模型援用。

列印前仍須在實際切片器檢查十字架、橫桿與接根的支撐及工具路徑。橫桿可能需要支撐；拆支撐時應避免扭折直軸及根部。請勿任意縮小模型；縮小會等比例減少細件厚度，必須重新檢驗與評估。尚未實體試印，不保證無支撐可印、細件強度或成功率。

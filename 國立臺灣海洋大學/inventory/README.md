- 馬祖校區：原坂里國小改建；現行圖含行政辦公室、教學樓、教職員宿舍、國際學舍、學生活動樓、餐廳及自習室、球場、海洋實驗室。
- 桃園觀音校區／桃園產學分部：藻礁暨海洋生態館A棟、產學育成中心B棟的竣工現況仍待核；不可用早期效果圖或預計完工日期代替。
- 貢寮：水生生物研究暨保育中心為共享復育園區中的校外研究基地，另有美豔山中間育成場域；不把整個園區或漁港全算海大建築。
- 校外祥豐教職員／國際學生宿舍另列4棟群待拆分；都更MOU不是拆除或新館落成證據。
- 附屬基隆海事高中先記關聯提示，不混進大專院校建築完成數。宜蘭推廣班、USR合作點、海研船泊位不因名稱即算本校獨立校舍。

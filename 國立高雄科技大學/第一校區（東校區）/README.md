# 國立高雄科技大學｜第一校區（東校區）

本批 0 件局部外觀模型。全校及本校區都尚未完成，沒有宣稱完整建築數或完成率。

地址：東側：高雄市燕巢區大學路1號；西側：高雄市楠梓區卓越路2號。合併前／來源校名：國立高雄第一科技大學。

東西兩側同屬第一校區；東侧地址在燕巢區，不等於深中路58號的燕巢校區。清冊的第一校區研究項合含東西兩側，尚未全部核出棟界。

Geometry: actual exported NPZ/STL/3MF parity, finite/positive faces, winding, watertight, each edge exactly twice, one connected component. See QA.json.
Blender: actual saved file opened; visible mesh equals exported mesh, hidden editable pieces retained, no external images. See BLEND-QA.json.
Independent source/visual review: see independent-review.json. This is historical exterior approximation, NOT survey/full-campus/current-condition certification.
Manufacturing: no trial print, no guarantee of support-free printing or nozzle compatibility. All nominal building dimensions estimated. Rear/far-side details neutral; rear annex excluded.

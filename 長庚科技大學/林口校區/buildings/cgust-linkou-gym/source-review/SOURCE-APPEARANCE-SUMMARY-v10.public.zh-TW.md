# 長庚科技大學林口體育館：來源與外觀審核摘要

2026-10-17｜模型 v10｜來源與外觀審核通過，適用於低細節、相對比例的原創外觀代表模型。

模型保留入口端較低、設備端較高的分段主弧屋頂，以及設備端較窄、較低、偏教學樓側的次弧頂。兩端不同平頂附翼、入口退縮、兩向屋面平台和既有角落直立體均可辨。球場側與教學樓側分開處理，遮蔽處採保守省略。九張原創圖逐張審視，外架斜桿與露空保持可讀。

尺寸、曲線、窗格與構件截面是模型估計。官方公布的15.5公尺建物高度因量測基準未明，沒有用來推算完整比例。這不是工程測繪或2026現況重建；照片日期未證。2011–2012工程期間、2022排水改善與後續電梯規劃分開解讀，沒有把規劃的電梯當成已完工外形。

實心內芯、淺凹窗、加粗方柱與平面斜桿、B側局部接頭、加厚雨棚及小型承托皆屬模型簡化。原照片、圖紙與地圖影像未作公開貼圖或複製。此結論不替代製造檢查或實體試印。

主要外觀依據：[寬聯營造工程資料](https://www.kwanglien.com.tw/work-detail/27/)、[校方道路照明資料](https://generalaffairs.cgust.edu.tw/p/132-1007-949,r41-1.php)、[校方配置圖說明](https://newsletter.cgust.edu.tw/archives/2521)。高度背景：[全國運動場館資訊網](https://iplay.sports.gov.tw/GymInfo/IndexPrint/13362)。

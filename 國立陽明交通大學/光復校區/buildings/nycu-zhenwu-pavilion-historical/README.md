# 陽明交大光復校區振吾亭｜歷史照片時期本體

此模型依校方典藏建成照片製作，不是現在現況、測繪復原或完整場地。

## 可見結構與推定
- 多角照片支持平環形屋頂、中央露天天井、交替實面與放射透空肋區、矩形環柱、中央獨立高柱及擴大直紋頂帽。
- **4 實面／4 透空扇區、8 環柱、每區約6肋是多照片推定配置，不是官方明載精確數量**；等距角度、截面和比例皆名義化。
- 中央頂帽近圓截面與24條代表紋路為簡化近似，不能從照片證明精確截面或紋數，不推測功能。
- 原始彩照已褪色，米灰屋面、灰柱與深色頂帽僅為未校色近似。
- 典藏095–097標年代1979，不代表重新查證的拍攝日期；不保證之後未改建。

## 刻意排除
1979示意畫的巨大上翹翼面**沒有**併入建成照片模型。池、水、椅、刻字標牌、長階梯、坡地、植栽與湖岸全部省略；圓形底盤只是作者製造支撐，不是現地平面／水池／地形。模型為亭體研究，非完整場地。

## 檔案
- `model.stl`：單色單連通封閉網格。
- `model.3mf`：同幾何附四色基本材質。
- `scene.blend`：同網格、燈光相機與隱藏可編輯建構零件。
- `previews/`：6張 Blender 實際網格渲染，並非來源照片。
- `build_model.py`：P 參數可修改；`parameters.json`記錄本次參數，修改應在腳本P中進行。

尺寸123×123×62.2 mm；6708三角。無實體試印；懸挑屋面、細肋與柱的列印方向和支撐仍需切片驗證。QA僅證明幾何、格式與重建一致，不證明考據精度。

矩柱經正面照片覆核後加寬為切向0.68／徑向0.52名義單位，非細桿；約為屋簷直徑5.9%的切向寬度，屬照片比例近似。

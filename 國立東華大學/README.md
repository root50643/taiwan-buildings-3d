六件皆明示參考年代，不是2026震後現況測繪。管理學院北面、各館遮蔽面和細構保守簡化；藝術件排除B/C、演奏廳、橢圓入口與連橋。圖資A南面以2020完成照、北面以2000施工期影像，屋頂另核2026公告所附未標攝影日俯視底圖；不是單一年份的竣工測繪。

2026現況更正：行政／圖書館S05結構補強7/21竣工確認、9/18驗收合格；圖書館4–6F是另一裝修案，8/27開工、預計2027-02-25完工。補強完成不代表所有裝修完成。理工一館D棟與B頂樓舊山牆已拆，異地新館不能因有預定日期就當已完成。

102筆清冊包括群棟、同棟使用單位、非建物與待核範圍，不是102棟或模型數。美崙、屏東及校外／附屬範圍仍未製作。

每件有自建腳本、STL、可編輯Blend、actual STL預覽、來源及fail-closed全檢。人社二另附架空斜廊和斜弧罩原STL射線；理工三館另附架空通道射線。未實體試印或跑切片器工具路徑，數位QA不保證可印；印前確認支撐與橋接。公開包不重新散布原照片/PDF，不抓現成mesh。

# 國立政治大學 大仁樓

彩色四層主體幾何研究模型；官方建物編號60-20、校圖A25（20），山下校區。依官方外觀照片及消防平面簡圖建立長形主體、中央回折樓梯、長廊、左側細分房間、二樓中央入口與有界外階／坡道；不包含完整校園地景。

- `scene.blend`：可編輯網格、六種材質與相機。
- `model.3mf`：毫米單位、逐三角面材質；可修改頂點與材質。
- `model.stl`：單色幾何交換格式，不保存顏色。
- `previews/`：同一網格的五個視角。
- Python生成、檢查及重建程式：見 `requirements.txt`、`QA.md`。

## 範圍與限制

平面採共用60×9正規化座標、每單位2.5毫米；不是實測公尺或測繪比例。四層、無地下室；內梯為有限厚度階板及轉折平台，非填實樓層。入口配對為二樓候選；兩照片作同一廊側的不同視角候選，不據此聲稱背面全見。

模型146 × 222 × 53 mm，含3 mm整合底座；尺寸、曲率及構件厚度均為相對估計／列印尺度。官方15.5 m建物高度未說明量測基準，長寬未知，不提供精準1:N，也不代表2026現況。2011–2012為所見工程期間，照片拍攝日未證；2022排水防水工程不等於主弧頂增建，113學年度電梯僅有規劃證據，未加假想井道。

保留A入口端較低、B設備端較高的兩段主弧頂，B端偏T教學樓側的窄低次弧頂、S側與B向平台、不同附翼、入口退縮及既有角落直立體。角落體用途未知，不命名為電梯。T側樹後未知下牆保守省略，不鏡像補窗。模型採實心內芯、加粗方柱、Y向加寬平面斜桿、B側局部接頭及加厚雨棚；這些均為製造簡化，中央斜向露空仍保留。玻璃以原創不透明材質表示。

屋簷、雨棚及支架有懸空／橋接區，須按設備、材料及切片預覽評估支撐與移除路徑；未實體試印。222 mm長邊尚未計brim、skirt或支撐邊界。縮小或修改後不能沿用原尺寸QA。有限截層／法線射線不證明任意方向的全域最薄壁；原normal／-O各10 flags、strict=false與exit1保留，同次actualhex精確有界補證另列，未移樣本或降低0.8 mm門檻。

公開原創模型、原碼、原創九圖、來源連結及明列數位證據；來源照片、地圖、PDF與私有研究比較圖不公開。機器視圖代號不主張真北；兩個courtyard代號實為主外架與B端屋面近景，不表示本棟有中庭。

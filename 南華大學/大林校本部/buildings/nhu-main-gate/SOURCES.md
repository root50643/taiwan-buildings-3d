# 來源與建模界線

原始證據與精確網址、下載狀態、雜湊見 `SOURCE-EVIDENCE.json`。

1. 南華大學官方「南華簡介」明確標示校門照片，實看完整正面。
2. 校方網站直接連結官方 VR；VR index 直接載入 `pano.xml`。設定中的 node50 係「校門口」，node44 為其「進入校園」連接節點。
3. 按設定中的公開tile模板讀取之實際影像已在工作目錄核對；node50可見前方斜視與右端深度，node44可見背面主結構。
4. 照片引用僅用研究，模型包不含原照、人像或照片貼圖。照片不是本模型的授權附贈素材。

幾何保持照片可確認的主要量體；屋頂上表面、精確坡度、內部結構、文字與裝飾細紋不足以復原。雙檐採有翹端的名義薄實體，柱飾灰色凹面簡化為淺實體色層。這些均為可編輯近似，不能用作測繪、施工或結構分析。

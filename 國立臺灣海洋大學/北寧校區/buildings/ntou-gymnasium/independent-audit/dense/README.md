# 獨立原面密採樣與曲面局部根證據

執行 `python reproduce_independent_dense.py --model-dir ../.. --output recheck`。需 requirements 套件另加 pandas==2.2.3、g++ C++17/OpenMP；預設定位本模型。程式 exit0 只表示完成重現，不覆蓋原嚴格短弦警告，也不是免支撐或可印保證。

全部5630原三角各15個固定重心權重，共84450點；作者10點子集56300點的1227短弦全重現，新15點共1791。保留每筆原始第一實體段與後空氣，不延長成其他材料段。最短原法向首段0.000033553360433773575mm。

局部根方向僅用實際進出面內向單位法向之和，不依根長挑方向。1791筆皆能沿原面鄰接曲面、最多4片，到一個實際有限凸邊；最大點至邊距0.7826560592651362mm、匹配面法向差5.288988101219061度、一側為精確同向面，最小共同內向margin0.24481443126685387。第一連續根最小6.562808332310677mm；不是全域最薄壁。原法向和所選根整段及後空氣各多站共64476全原三角長雙精度solid-angle控制通過，未略過首段後的空氣，兩組射線完整區間沒有沿面。

所有模型法向的後沿面另由 boundary 補充檢查；不能把這些1791短段的結果當其他長弦全部無沿面。全密CSV保持原 infinity，代表沒有第三入射的無界後空氣；JSON對應null只為嚴格格式，不表示厚度0或遺失測量。原CSV、原首出口及完整events仍保留。

公開腳本已在獨立暫存完整執行；CSV與winding逐byte重現，JSON除上述Infinity→null格式外所有原值相同。有限採樣、浮點運算與曲面局部路徑不能證明製造公差穩健或全域厚度；仍需切片支撐、試印與小心移除支撐。

# 來源、年代與建模判讀

## 主要幾何來源：2014 施工階段
- 實式木造「關於實式」作品年表：<https://mhtde.com/關於實式/>，項目標為 **2014／高雄／高雄大學 Demo Building**。
- 該項公開照片：<https://mhtde.com/wp-content/uploads/2020/04/P8201550.jpg>。本次實際讀取並檢視照片像素，顯示五道主框架已立起、屋面尚未鋪設；高低兩翼、雙拼木梁、叉形柱與灰色接點可辨。
- 2014 是作品年表標示，不將檔名、網站上傳路徑日期或照片 EXIF 推作精確施工日。
- 來源為參與承造者，而非大學公告；其參與身分另由下列設計者作品資料列名實式空間設計公司交叉核對。

## 設計者第一手公開說明
陳啟仁〈從理論到實踐的校園建築－高雄大學木構造示範屋 Demo Building〉，《台灣建築》2016 年 3 月號，第 246 期，公開頁日期 2016-03-02：<https://www.ta-mag.net/ta/News.php?id=889>。

公開文字說明 V 形屋面、X 柱框架、懸臂及雙拼接點概念；南向屋面 23.5°。本模型僅將 23.5° 用於高翼主梁，其餘比例未稱精確。文字列建築面積 454.14㎡，未拿面積反推平面尺寸。完整印刷內容未取得；該頁圖片請求 403，已停止該圖片讀取，不聲稱讀到內文圖版或施工圖。

## 建模推定與排除
- 五道主框架數及主要X形/雙拼構法以主照片直接觀察；框距名義等距，是簡化研究，未具尺寸圖驗證。
- 低翼坡度、翼長、柱傾角、梁柱斷面、柱座、鋼連接片與橫向墊塊為照片比例近似；墊塊減量、螺栓省略。
- 連續展示底板是作者支撐，不是實際基礎、地坪或施工安全構造。
- 不建屋面、後期百葉/幕牆、內部房間、設備、人物、工地圍籬、散件及吊裝臨時物。
- 研究模型不供工程設計、受力分析或施工。照片著作權保留原權利人，本包不再散布參考照片。

## 內容
- `model.stl`：單一連通、封閉三角網，顏色不在 STL 中。
- `model.3mf`：同一個實體網格、8 種逐面顯示材質，可編輯顏色；不是自動多料列印設定。
- `scene.blend`：相同原始面與材質的可編輯場景。
- `build_model.py`／`mesh.json`／`palette.json`：參數化來源與直接網格資料。
- 五張實際網格預覽：正面、正立面、入口斜視、頂面、截斷後方。

可辨識特徵為寬階梯、白色斜扶壁、高細柱、紅褐色直向牆帶、退縮入口、平懸挑屋頂。上方校徽僅保留素色板，不描摹小字或臆造徽章。

## 範圍與限制
展示尺寸 **156 × 70 × 100.5 mm**，只是便於檢視的相對尺寸，無比例尺、無測繪／竣工圖。台階數、窗格數、跨距、厚度和階梯深度是可讀性近似，不能當成建築實際數據。左右和後方為明確的模型截面；背板是展示封口而不是後立面重建。未添加來源看不到的屋頂機電、室內、側翼或欄杆，遮蔽處只沿用可見開間的規則窗格近似，不宣稱實測細節。官方 PDF 中太陽能陣列為不可施作的規劃圖，**未建模為既有設備**。不作建築師歸屬判斷。

## 重建與 QA
Python 依賴見 `requirements.txt`；Blender 4.3.2 或相容版本。lib3mf 2.x 的官方 Python binding 必須可 import。

```sh
python build_model.py
python qa_model.py --out .
python check_features.py
python verify_exchange.py
blender -b --python render_model.py
blender -b --python verify_scene.py
```

`QA.md` 和 `qa/` 保存數位測試。懸挑屋頂、柱廊間隙、入口橫梁須由使用者在切片軟體判斷方向與支撐；0.9 mm 窗框浮雕可能被實際擠出寬度弱化。**未經 FFF 機器切片與實體試印，不能稱為免支撐或保證可印。**

第三方照片與 PDF 不在交付包內；來源與取捨見 `SOURCES.md`。

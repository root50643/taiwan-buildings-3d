## 爾雅樓（第三學生宿舍）範圍

爾雅樓（第三學生宿舍）2021履歷竣工照片主要外觀近似：13F階梯退差、約兩層斜切裙房、中段窄凸翼低約兩層、前外階入口、後端厚白框上窗與落地門、完整退縮綠頂與中央抬高PV設備區。138×110.7×190.1mm、8材質Blend/3MF/STL及5實mesh圖；12962三角單閉殼、951層0.8mm組件檢查通過，格式真編輯存讀與乾淨九檔重建一致。後中上窗排及體育館旁低部小開口按可見規律近似，非逐格測繪；僅取得3/4/6/7F平面，不含學思、舊體育館、舊宿舍、白棚或B2。需支撐評估、未實印；原照拍日不明，2024存檔不是拍攝年。 [模型與來源](buildings/ntunhs-erya-dorm/README.md) · [QA警告](buildings/ntunhs-erya-dorm/QA.md)。既有文教與學思模型及其角損／列印限制不變。

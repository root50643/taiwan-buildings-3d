# 國立成功大學・成功校區

[返回學校總覽](../README.md)

本校區目前收錄 10 件數位外觀近似模型；包含局部段或同一財產不同量體，件數不等於完整建物棟數。既有9件含底座最長150mm；56亭含局部兩端收尾為228mm展示長，各件獨立縮尺。尚未完成全校，未實體試印或進行印表機切片驗證。

# 來源與辨識界線｜中央大學鹿林天文台 SLT

## 身份、基地與年代

- [鹿林天文台官方介紹](https://www.lulin.ncu.edu.tw/about/)：國立中央大學天文研究所／台灣天文研究聯盟使用的校外觀測基地，位於玉山國家公園塔塔加鹿林前山，標高2862m。不是桃園中壢校本部。
- [2003年官方年報 PDF](https://www.lulin.ncu.edu.tw/download/document/AnnualReport/Lulin_Report_2003.pdf)，PDF第10頁〈基礎建設〉：SLT主建築1998年開工、1999年1月完成，含6m八角頂；另段明確區分2002年9月落成的LOT控制中心。此頁為歷史與屋頂類型證據，**不是立面或施工尺寸圖**。
- 官方識別航空圖標明本棟為「0.4m SLT NCU」；右側粉紅白色二層主樓是「1m LOT NCU」。現有望遠鏡口徑／更換日期不能代替主樓建造年，模型不含光學儀器。

## 從來源到模型的取捨

1. 確認完整SLT單棟是相連的低長翼／高觀測座，不把全基地、LOT、儀器棚當作同一建築；另建中文「鹿林天文台觀測基地」目錄。
2. 以2022前方閉合雙窗狀態配合2023反側可見護籠梯，表達靜止的外觀；不是運動機構、屋頂開合方案或混用鄰棟開窗姿態。
3. 八角頂的6m文字只確定大致尺度和多面形類型；沒有測量標定，照片透視像素不能直接等同公尺。所有模型毫米皆推估展示尺寸。
4. 保留八角直段／內收斜段、正面凸起雙片、梁端、頂欄和梯的空隙。杆件加粗、護籠及窗格數量簡化；沒有把護籠填成實心板。
5. 門窗是附面實體浮雕，建築為封閉量體，未建立室內、望遠鏡、機械傳動、地下基礎或隱蔽接合。後方微小穿孔、精確板縫及金屬厚度無法確認。
6. 顏色是照片衍生的近白、灰金屬、暗色窗與灰綠小簷邊，不是量測色票；不移植LOT粉紅牆、綠色大窗簷或紅色控制中心文字。
7. 不宣稱這些較早照片證實2026仍無變化。完整「外觀近似」不等於完整測繪、完整內部或全基地重建。

## 去重與排除

研究於固定庫版本`f3335c15ec3547511cbc377942ade7e306ce2116`全tree搜尋鹿林／Lulin／SLT／Seisi／天文等，並檢讀中央大學55份索引、模型README及生成器文字，未見相同SLT模型；校本部遙測館不是鹿林觀測基地。新模型僅補此一完整外觀項目，不宣稱學校全數覆蓋。

## 模型範圍與證據限制
- 多翼斜屋面、D完整斜四邊形高端、O真退縮廊下、三角植栽庭院、下沉灰廣場、主要玻璃框與階梯保留。O不是植栽三角院。
- 依建築師平剖面及2025年8月、11月多角照片原創參數化。PLAN描點用1888×1334顯示圖，原圖2048×1448；均非有尺寸鍊竣工測繪。全樓跨度、玻璃模數、曲折細節與地形是有界近似。
- D高端是完整斜切短邊；剖切PLAN露綠角不可作額外屋簷折點。H、D、O用兩正常透視相機共同核形，仍有數至約15px/1024投影誤差；不把相機擬合當實測。
- 新06圖EXIF含pano及Luminar Neo，04亦經Luminar處理；06只佐完整輪廓，不能當無畸變正射。照片時間依頁面dateTaken及EXIF，不以網址目錄推年。
- 剖面GL101與GL96相差5m。白帶落在大階梯上口旁的較高草地可由04/06互核，但末端恰接GL101仍是假設；模型上層7.9mm、B1頂2.4mm。舊照片末端被樹遮，不把樹緣當地坪硬控制。
- 白帶低端約1/3暗實段，中高2/3玻璃以退0.5mm、1.3mm背接與根接淺框表達；它不是無牆的大通道。玻璃的透明性未模擬。
- 植栽、家具、隱蔽機電、屋頂金屬板縫/草皮條紋及細格柵省略；不宣稱室內完整復原。

## 列印近似與警告
- 單位毫米；含底座140×150×約20.824mm，底座朝下。不要任意再縮小。
- 中央屋尖加直徑約1.6mm局部圓鈍，沿原斜面法向背接；這是列印加厚，不是實際建築細節。另一高斜簷末端有約1.2mm寬列印平帶，避免末層0.27mm薄條。
- 玻璃背側低部腳帶與上街道伸入講堂玻璃腳下，以避免細頸；B1廣場沒有整體抬升。階梯段有微重疊，避免共面零體積殼。
- O第一方柱約1.3×1.3mm；斜簷、廊下、窗框及屋尖可能需要支撐。拆支撐時避開細柱和圓鈍端，勿以其提拿模型。
- 62個原Polygon opening損失超過1%，分O方柱42、白帶/細框16、屋尖4；全部數值見warning-review.json。不能只稱一般角損，亦不以全層平均掩蓋。
- 數位QA不是全面最小壁厚、Cura/Prusa工具路徑或實體試印；不保證免支撐或列印成功。

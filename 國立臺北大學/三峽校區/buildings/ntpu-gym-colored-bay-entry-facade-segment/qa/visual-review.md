## 可接受
- 薄立面段、藍大凸窗／紅低框／黃窄框之相對排列可辨識，非平面色塊。
- 藍框左側不透明寬牆與右側玻璃回折在右斜視可辨認，凸出深度不被誤當平面。
- 左三層凹陽台、底層凹入廊與頂部橫梁開槽保留。
- 俯視呈窄展示切段，背面留白且 README 明示任意展示截面，不假造全館背面／屋頂。
- 原照片未測量，屋緣微傾與窗距有近似，可在目前聲明範圍接受。

## 必改：紅／黃窗格不應套相同密集橫格
來源 a2 紅色短框內為以直向窄格為主的玻璃／遮簾，不是多層橫向通風柵。初版紅框渲染出約三條顯著橫向帶，識別失真。請改成約 8 個直向窄格；至多保留一條不搶眼橫分隔，承認格數為列印近似。
黃色狹框在照片中是約 3 直列、中央一條主要橫分隔，初版約 5 層密橫格過多。請改成約 3 列×2 大層（或等價保持高直窗特徵的列印簡化）。藍色大框既有多層網格可維持。

## 不改成新主張
不要因本審查加入整棟、後翼、真實屋頂或不同四館量體；展示切面仍需留白揭露。不能聲稱來源照片攝於 2025 發文日。局部 .75 mm 窗櫺不足已在 README 誠實列出，並不因視覺通過而轉為列印保證。

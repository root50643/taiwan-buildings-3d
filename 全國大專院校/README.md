# 全國大專校院建築模型清冊

更新：2026-10-21。這是持續補齊的機構、校區與建築研究清冊，**不是全國建築模型已完成的宣告**。

## 範圍與計數

教育部115學年度四類官方名錄共列158所獨立機構：一般／技職139所、宗教研修學院8所、空中大學2所、軍警大專校院9所。另列5個附設進修單位，歸所屬大學，不重複算成學校或建築。

149所非軍警學校均已對照114學年度教育部手冊，擷取231筆校區地址；其中2筆為政大附中／實小，預設不列入高教建築範圍。其餘229筆也不等同229座校園或建築：學校手冊可能包含院區、中心、宿舍等，且跨校共用校地須再去重。軍警9校已完成機構列冊；海軍官校僅有公共紀念鐘樓本體模型，仍未完成校區或全校逐棟盤點。

全國建築總數仍未知。每所學校完成一棟，不能標示全校完成；每棟模型完成，也必須另驗證可列印性與已發布狀態。

## 檔案

- `institutions.json`／`institutions.csv`：全158所、教育部代碼、校名、類型、縣市、官網、來源、處理進度。
- `campuses.json`／`campuses.csv`：231筆校區地址、原始手冊年度與排除註記。
- `coverage.json`：計數與尚未完成的範圍。
- `affiliated-continuing-schools.json`：5個附設單位，避免重複列校。
- `official-status-changes-115.json`：115學年度官方異動；2個附設進修學院轉型為進修部，不是兩所大學停辦。
- `historical-institutions-review.json`：舊年度有、115名錄不再出現的代碼，待區分停辦、合併或改碼；缺席不直接代表停辦。

## 工作順序

依北部76校、中部30校、南部43校、東部及離島9校分批。各校依序：

1. 核對所有校區、院區與共用校地。
2. 對照官方校圖與樓館索引，建立逐棟清單；停用、施工、改建、拆除各自記錄。
3. 收集公開外觀及足夠的平面／尺度依據；資料不足時明標缺件，不以制式方盒取代真實外觀。
4. 建立模型及來源紀錄，標註推定尺寸與簡化部位。
5. 驗證閉合、水密、法向、尺寸、最小壁厚、支撐與切片；軟體檢查通過不等於實際試印。
6. 發布後記錄確切路徑、版本與驗證結果。全校完成須以已去重逐棟清單為分母。

## 來源與權利限制

公開可閱覽不代表圖片、底圖或他人3D模型可再散布。此清冊僅保存必要的事實資料與連結，不附校方照片、既有3D資產或原始全本手冊。模型應自行製作，逐件記錄來源與重用限制。軍警機構僅採官方公開、訪客導向的一般校園外觀；不蒐集管制或敏感設施資料。

嘉南藥理大學新增 J 司令台／運動場看台歷史代表，與王趁圖書館合計2套；22個列印件只計一套建築模型。[完整列印限制與發布覆核](../嘉南藥理大學/publication/cnu-j-grandstand-historical/PUBLICATION.md)。原主體切片不放行，須短向橋接／橋下支撐，仍有約8.3 mm內橋、逐段側拆與膠合定位限制；未實物驗證。國立中山大學西子會館先前已發布，本次將清冊原漏同步的3套校正為4套，未新增或修改其模型。

澎科海科南北棟／二樓連廊／單層會議廳共計一包，該校合計3套；8種STL／10件不是10套建築。數位有界條件GO，未試印或試合、非2026現況。宜蘭6套與空大2套為先前已發布內容的索引補同步。

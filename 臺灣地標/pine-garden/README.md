照片可見明暗不均的老化屋頂及灰色牆體，但光線、遮蔭與年代不確定。`parameters.json` 的 RGB 與粗糙度只是來源色系的視覺近似，**未作色卡校正、材質掃描、逐像素取樣或 2026 現況調查**。不把藤蔓/樹影塗成建築材料。

40 個門背面與 40 個橫窗背面不補白色：原網格沒有獨立的窗框、玻璃或門下板。側山牆通風凹槽面 5468、5469、5518、5519 均保持未驗證中性灰。`face-material-map.json` 使用零起算的原始 STL 三角面序號；程式以每面全部頂點及法向的完整一對一比對映射到 Blender，**不假設匯入面序一致**。

## 既有限制不變

- 主棟模型，不含整個園區、其他館舍、松樹或景觀設施。
- 十跨規整立面是原模型近似，不聲稱實際精確跨數。長寬高、深度與屋頂比例未經測量。
- 拱廊是深盲凹槽，不是可通行的室內；欄杆被加厚、做成浮雕欄板。
- 背窗、側窗和山牆通氣窗沿用原版推定，這次照片並未證實它們。補色不提高幾何準確度。
- 前方為 −Y、背方為 +Y；這是模型相對方位，不是地理羅盤方位。

## 檔案與編輯

- `model.stl`：與既有公開原檔逐位元相同；不含色彩。
- `scene.blend`：實際可編輯的單一原幾何網格，三個材質槽、逐面材質及 `original_stl_triangle_index` 面屬性；沒有照片、貼圖、嵌入程式或隱藏的美化建築網格。
- `model.3mf`：毫米單位、單一物件、逐三角面基礎材質。已用 lib3mf 嚴格讀回與往返核對，但切片軟體支援各異，不能保證多色列印自動分派耗材。
- `parameters.json` / `face-material-map.json` / `build_materials.py`：公開、離線、可重現的補色來源。
- `build_model.py`：保留原版幾何作者程式作歷史與另案編輯使用；**補色重建不執行它**，避免布林引擎版本改變原版三角面。若另案重建/改幾何，舊材質面序表不可直接套用。
- `previews/`：正背斜視、正背立面、右端、俯視六張，均渲染實際完整交付網格，不含來源照片像素。

## 離線重現

使用 Python 3.12、`requirements.txt` 的固定版本與 Blender 4.3.2：

```sh
python -m pip install -r requirements.txt
python reproduce.py --out ./rebuild-output
```

可用 `--blender /path/to/blender` 指定 Blender。若 lib3mf 與網格驗證套件分裝於不同 Python，可用 `--export-python`、`--mesh-python` 指定；所有輸入都在本目錄，不需網路、來源照片或私人檔案。重建會核對原 STL、色彩面表、原幾何拓撲、3MF 材質與幾何、Blender 編輯存回、原生場景重新渲染及預覽 metadata。

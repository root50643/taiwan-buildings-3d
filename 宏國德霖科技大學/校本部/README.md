李祖原聯合建築師事務所作品。東側巨框頂部向內斜收，保留深走廊、南五片約對5–9F與北兩片約對5–6F斜陽台，另有較低平露臺。前廊抬高、連續斜退長窗與不對稱北上屏／下入口圍出開放中庭；兩端核心有別，不鏡像未知背面。

名義1:400，整合基座222.5 × 125 mm、總高約114.9 mm。PC柱軸距81.90m與局部C–G 20.30m不是全棟外緣尺寸；公布45.4m測高基準未知，主框45m／主屋面40m與前裙樓、院深、框厚均為推估。4.8／4.4m來自設計分析的樓層節奏，非精確實測標高。西背面、南側遮蔽處與北側後段未知而保守簡化，模型封閉牆不表示實物沒有門窗。

玻璃為不透明退縮實體；細格柵與欄杆合併粗化。斜角0.65mm圓角與高頂框端部0.5mm接合餘量是製造簡化，不是真實立面配件。樓梯梯段、院內階梯、池橋環路地景、小管線、標誌、隱藏B1與完整室內省略；不加入舊方案A/B、2018景觀更新、2020內裝或年代未定屋頂PV／設備。

前橋廊、深廊樓板、陽台與高框需要支撐，尚未實體試印；材料強度、支撐清除、樹脂排液、方向與切片適用性未驗證。有限XY切層及法線射線不證明任意位置／方向的全域最小壁厚。原normal／-O各3 flags與strict false保留，同次原CSV lossless hex射線有精確補證，未移樣本、未換理想射線、未降低0.8mm門檻。

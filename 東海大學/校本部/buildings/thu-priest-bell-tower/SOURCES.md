# 來源與重建界限

- [文化部國家文化記憶庫／文化資產條目](https://tcmb.culture.tw/zh-tw/detail?id=20171116000001&indexCode=BOCH_CountryCulture_11)：正式身分、四片對列牆、黃釉菱格面、混凝土窄端、鐘與軸座；三張完整照片。

- [東海大學總務處](https://general.thu.edu.tw/web/album/list.php?page=3)：官方相簿索引與畢律斯鐘樓相簿連結。

- [東海大學總務處官方連結相簿](https://photos.app.goo.gl/ErdAUagRb4VqeJt78)：六張完整照片；正反面、兩側縫、上部與下部、遠景。

- [東海大學](https://thupr.thu.edu.tw/newsdetail.php?id=52602)：2022整修紀錄；限制當前外觀主張。

所有照片拍攝日期未知。文化部圖片路徑日期不是拍攝日期；一檔名似有2017日期，僅線索，不採為已證實拍攝時間。2022整修訊息不能支持2026現況。歷史高度文字的讀法存在衝突，未採作尺寸；模型mm僅設計尺寸。

四片厚板的兩排／每排兩片關係、中央通道、側縫、鐘的喇叭口、U形架與座均由多角度照片支持。磁磚排數、精確厚度、底座邊界、鐘體內壁與機械接合均簡化；鏡像對稱非現場精密調查。無複製官方來源原圖。

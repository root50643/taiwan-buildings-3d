# 薄特徵與支撐注意

本文件記錄原始STL的限制；不是降低驗收標準或實體試印證明。

## 完整檢查與未隱藏的數值

- 0.2mm逐層，z=0.071至66.071mm，331層；有效原Polygon共1047。
- 每個原Polygon侵蝕0.4mm後與接續膨脹0.4mm後均保有單一Polygon；零消失、零分裂。每個分量及合成形狀皆先assert valid，不修復invalid。
- 整層>1% opening損失70層，連續位於z=52.271–66.071mm。最大原始fraction為0.09593913655528649。
- 原Polygon>1%損失568項，最大fraction為0.09987884182374136，出現在z=50.271mm的屋脊端飾截面；該截面面積1.3831982729279948mm²，侵蝕／opening各保有1個Polygon。
- 不能僅報「整層<1%」忽略小構件；本版公開每層總面積、損失面積及每原Polygon未四捨五入的損失比例。見 [layer-component-check.json](layer-component-check.json)。
- canonical v3另有1.0mm篩檢67層，其中14層>1%；不以稀疏檢查取代0.2mm全層。見 [thin-feature-check.json](thin-feature-check.json)。

## 特徵尺寸與風險

| 特徵 | 源幾何設計 | 風險／處理 |
|---|---|---|
| 中央十字與尖塔頂 | 最小1.2×1.2mm截面；十字橫臂4.4mm長 | 方角opening自然損失；頂端脆弱，橫臂有小懸挑，不宜縮小 |
| 6處屋脊端飾 | 逐段加粗、最窄截尖1.15mm；不做針狀零寬頂 | 搬運、拆支撐易折；最高小截面仍有約9.99%方角損失 |
| 前柱 | 柱身2.5mm見方，約24mm高，底部和頂部確實相接 | 不以柱廊填實取代；可能因共振或支撐拆除損壞 |
| 三柱跨與水平露臺 | 淨跨約15.4–15.7mm，板厚2.9mm | 需實際切片評估支撐／橋接，不能承諾免支撐 |
| 門窗粗梃 | 1.05mm寬，深入到凹槽背牆並交疊；非游離細線 | 工具路徑仍可能簡化細節；拆支撐勿刮傷 |
| 欄杆 | 1.5mm以上實心帶，淺菱形凹紋 | 不做細脆鏤空；小凹紋可能隨噴嘴解析度消失 |
| 氣窗／屋檐／坡頂邊帶 | 與實體坡頂或牆確實融合，氣窗頂作1.3mm截平 | 尖角可能鈍化，懸挑及相鄰細節仍須檢查 |

0.4mm opening會圓化所有凸方角；例如1.2mm方形截面損失約0.138mm²，即約9.59%，不代表整個截面消失。本版仍保留上述警示，不把這個觀察推廣成所有損失都無害。

## 列印前

1. 以毫米匯入，確認150×130×66.1mm左右，底座朝下。
2. 先查看柱廊梁下與屋檐支撐、尖塔十字橫臂、窗口附近的工具路徑；勿將支撐不易移除的細節當可靠結果。
3. 本次僅數位QA。未執行實際Cura／Prusa切片工具路徑或實體試印；XY篩檢不涵蓋斜向最小厚度、壁強度、收縮或材料／機台限制。
4. 若要修改細件、比例或支撐友善程度，另建新版並重新跑全套QA；正式凍結版本不覆寫。

## 對實際網格的補充驗證

[指定截面圖](qa/ornament-sections.png)由交付STL直接抽取，沒有把源參數方形當成檢測結果。翼端飾z50.271mm實測1.176096×1.176093mm；中央十字桿z63.071mm實測1.200000×1.199999mm。

[ornament-check.json](ornament-check.json)另量6支屋脊端飾及中央尖塔：在閉合頂面下0.001mm處，以正負X／Y射線取得實際寬度，端飾最小約1.15014mm、中央桿約1.2mm。7支構件根部向頂端的軸向射線均連續，無中途空隙；整體仍以單一連通表面與vertex-link檢查排除分離殼。這是指定位置與方向的測試，不能擴張成全表面最小厚度保證。

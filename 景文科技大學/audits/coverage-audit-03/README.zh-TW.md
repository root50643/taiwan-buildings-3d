# 景文科技大學覆蓋與缺口

截至2026-10-13，七件公開外觀研究模型：D宿舍、E電資、F人文、H餐旅、I圖資、L設計及ABC連體群一件，共涵蓋九個主要館碼。不是全校完成，亦非七件精密實景復原。照片年代未知，網頁仍在不表示2026即時現況。

## V5證據修正
273頁七種各館PNG實際是示意插畫，A/C還共用一圖，並非各館照片。原八館清單不能當八張實拍、八個獨立建築或全校總數。這次另取得並實際檢視官方實景照片才製模。官方校圖另標F人文館，已補入；第一餐廳是F同棟用途。

## 邊界及尚未完成
- A商管二館、B行政大樓、C商管一館：校圖顯示相接，暫按一連體研究群處理，保留三個館碼；物理拆分數未定。新補行政03高角度實拍已涵蓋B與院落內側，可製作一件ABC群近似模型；A/C未見端面保持素面，未複製插畫成兩模型。
- 警衛室：校圖具名小符號，尚缺足夠具名外觀/尺寸，未建。
- 七件模型的未見背側、深度、曲率、窗距、翼棟接合與部分屋頂仍近似。E正面部分依示意圖補助，完整實拍側面不等於完整全棟實景還原。
- 停車場、球場、道路、回收區不是建築物總數。屋棚及其他未具名附屬量體仍需完整盤點。

## 現行版本與檢查
- 第一批v3：L/I/H；v1與v2僅歷史稽核，勿重复計數。
- 第二批v3：D/E/F；F修正單一大拱柱廊及另一端跨層框、陽台，原第二批及v2僅歷史稽核。
- 第三批：ABC連體群一件，不重複計三件。
- 七件各自含底板最長150mm，獨立比例；Python、STL、可編輯Blender、實際正背PNG、sources與檢查隨包。來源原照片不公開。

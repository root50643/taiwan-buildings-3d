# 國立彰化師範大學進德校區｜王金平游泳館入口立面與淺弧屋簷前段

**新建、來源限定的局部展示模型，不是整棟復原。** 主體依官方 PDF 第 13 頁空拍；2017 年 Cowky 地面照片補充窗格與色彩。兩份照片的入口上罩版本不同，本模型明確採空拍的垂直條狀罩，未混搭舊紅色布條。不是 2026 現況認證。

![前側預覽](previews/front.png)

## 內容與範圍
- 四跨／五條黃柱線、灰色下牆、上方格狀藍灰窗、下方窄窗帶。
- 左中黃綠色突出入口塔、旁側凹入門洞、垂直條紋入口上罩。
- 真正淺弧曲面屋簷及連接屋面立縫；窗與門有實際幾何凹深，不是貼圖假洞。
- 只保留前立面與短屋頂段。灰色背面、側剖面及底座是展示封口，不是已調查的建築立面或基地邊界。
- 未建後方主體、泳池內部、外側樓梯、植栽、招牌文字、機電設備，未加入規劃中的光電板。後方綠色場地不是本模型的第二層。

## 開啟與編輯
- `scene.blend`：原始三角網格、九種可編輯材質、攝影機／燈光；沒有嵌入腳本或外部照片。
- `model.3mf`：同一原始表面、逐三角形材質；顯示色不等於印表機／擠出機配色。
- `model.stl`：同一單一連通封閉表面，STL 本身不含材質。
- `build_model.py`／`mesh.json`／`palette.json`：可重建來源與網格資料。
- `previews/`：前、背、正面、頂、入口右側五視角，均渲染同一交付表面。

尺寸 **184 × 65 × 56.625 mm** 為任意正規化展示單位，無現地尺度依據，不可反算建築尺寸。前側為 -Y。比例是照片的人工定性校準，不是攝影測量。

## 品質與列印限制
請讀 [QA.md](QA.md)。原始拓樸、交換檔、可編輯材質均有程式驗證，但不是「直接可列印」承諾。0.75 mm 橫窗框及 0.375 mm 屋頂立縫高度低於 0.8 mm 細節篩檢；局部侵蝕會損失細節，即使每個水平切片的整體連通分量都保留。屋簷懸挑與門窗凹槽須另行切片／支撐評估。沒有實體列印或結構分析。

## 重建
Python 安裝 `requirements.txt`，並使用 Blender 4.3.2 或相容版：
```sh
python build_model.py
python qa_model.py --out .
python check_features.py
python verify_exchange.py
blender -b --python render_model.py
blender -b --python verify_scene.py
```
來源照片未隨包分發；參考連結與對應見 [SOURCES.md](SOURCES.md)。新創網格、程式與文件依本包 `LICENSE`；參考來源各自權利不變。

## 範圍與來源
2003 新館，RC 地上 9 層、地下 2 層；地下層不全露出。以官方 2017 南面、2020/2025 北面、2023 正射與 B2–9F 示意平面交叉配景。原照片私人留作核對，公開包只列來源連結。這不是測繪、逐窗精確復原或全地景模型。

保留南五層低弧、北高帽狀弧屏與頂連續厚邊、北最高兩排真正透空及後退牆、下部背接玻璃、南北兩向透空格梁、逐層不同退台、中央封閉曲玻璃、東西不等樓梯凸塊、入口深凹和後高前低棚。庭園沒有全填為室內，北頂格口沒有全封玻璃。窗框是背接淺細節，未把空調或反光當已知逐窗尺寸。

## 尺度與不確定性
含底最大 150 mm；1m 名義建築尺度縮為 1.8 mm，底座 3 mm。最高 46m 是照片敏感的名義試配；40–52m 為初始試配範圍，並非測得界限或統計置信區間。九層不代表九個等高層。透視、前後深差和屋頂高程視差都會影響比例。

約 54×58m 是主弧屋面投影量級，不是地面牆基，也不是包含東西所有凸塊的外包絡。OSM 約72m深包含入口與階梯，不套成橢圓主體。中央實屋面約44×18m不等於前白牆全寬；入口棚名義26×6.5m在影像估計上界內，階梯另算。北帽以同正射可見弧線擬合，端部收接高屋面；非整個北半橢圓都升到同高。平面各頁局部尺度不同，各層退縮採有界近似，不能聲稱精密疊圖。

0.2mm、固定起點0.071mm檢查429層1003個原Polygon；逐原Polygon erosion(-0.4)/opening皆保留一塊，零消失、零分裂。整層損失最大0.304642716%，不能據此免看局部構件。

459個跨層原Polygon樣本的opening損失超過1%，含入口柱、北屏柱和南弧入口楣以上柱段。最差3.9331514275%，保留96.0668485725%；該樣本z58.071mm、面積3.5624521448mm²、損失0.1401166374mm²。0.41mm頂點鄰域外仍有0.0010123675mm²；所有樣本中角外最大0.0020759794mm²。不能把全部損失稱為純四角。

459個警告原面局部caliper最小1.7986177458mm；這是指定截面、指定方向的實際原STL首弦，不是全域全方向壁厚。所有警告柱段驗證直達底座或入口楣的連續實根。1866個額外局部首弦涵蓋南北窗背板與柱搭接、中央曲玻璃、北格梁、斜棚，另驗格梁接退台牆、入口柱/階梯根以及北兩排真空。斜棚法向最薄工作值約1.02mm，已由原面採樣；數位細差保留，不等於試印或強度保證。

原始逐樣本數值見 detailed-component-check.json、warning-caliper-check.json、surface-ray-check.json。全套可執行 run_all_checks.py 重跑，原始 STL 不 repair。本版薄損例外已經獨立終核並獲主審限定接受，精確補充見 independent-final-review.json。

## v2 局部修訂與仍保留的方向性短弦
v1 獨立密查辨認曲玻璃刻槽的極窄反向尖唇及入口弧面與矩形切口的有限銳楔。v2 只把槽切刀改徑向向外張開，入口最前段作局部徑向截角；中央曲面不整片增厚，真凹深、北上兩排透空與格梁不變。v1 保留 HOLD。新舊 SHA 與範圍見 [revision-v2.json](revision-v2.json)。

新入口仍有普通有限凸角：近角點的法向首段可小於 0.8mm，不能把後方牆跨空氣加總；滑近頂點更短的值亦保留。側窗中框的側向約0.252mm短弦是背接淺浮雕，背向首段另列，不當作全方向厚壁。局部截面、逐原面內移曲線及根見 [local-corner-profiles.json](local-corner-profiles.json)、[local-back-roots.json](local-back-roots.json)，已完成有限族分類，不能以整層低損失代替局部證據。

最高細橫槽另由名義39.8m降至39.2m，使頂帶留0.64m（輸出約1.15mm），修掉中間試件曾有的0.072mm連續頂帶。水平槽切刀向外延長以穿出真凸包表面；內刻深及其餘水平節奏不改。局部凸角法向短弦仍逐值公開，並未承諾全表面首弦皆大於0.8mm。

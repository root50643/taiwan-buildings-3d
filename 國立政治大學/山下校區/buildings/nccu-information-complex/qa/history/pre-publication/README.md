# 國立政治大學資訊大樓（含電算中心）

國立政治大學山下校區的完整 L 形連體建築外觀參考模型。長向資訊翼、垂直電算翼及兩者的連接部位屬同一模型，不按行政單位拆成兩棟。

版本：官方 PDF 所記錄的資訊大樓／電算中心連體外觀與平面參考版。照片攝年未知，並非已核對 2026 現況。

## 檔案

- `scene.blend`：可編輯幾何及七色材質的 Blender 場景。
- `model.3mf`：毫米單位、逐面材質，適合在支援 3MF 材質的軟體中再編輯。
- `model.stl`：同一表面幾何的無色 STL。
- `previews/`：同一實際模型的五個相機視角。
- `build_model.py`、`render_model.py`、`rebuild.py`：參數化建模與重建程式。

## 表現範圍與限制

低翼保留四層主體、開放屋頂框架與局部封閉端房；高翼保留標示為五樓露台的側翼退縮（露台位於四樓上方），再區分六樓及屋頂；南端有局部抬高厚簷。資訊翼西側退凹入口與電算翼南側內縮入口各有階梯和支柱，曲梯核東側完整外階及相接平台也保留。階梯升降方向及高程採有限近似，不是來源測得尺寸。外階遠端的細長圓頭外場通路不視為建築本體，模型停於完整階梯的自然平台邊界。不包含前景廣場、樹木、道路或鄰棟。

來源圖為消防安全設備簡易平面圖，不是建築竣工圖。尺寸、層高、細窗數量與高度、局部核心頂部及地形均為近似；隱蔽地下室內部沒有重建。原始照片、平面像素及閱讀輔助圖不包含於模型或材質。

未實際列印。薄窗框、欄杆、屋頂框梁及入口懸挑部位須依比例、材料和設備調整支撐；數值水密不等於可直接列印、無內支撐或結構安全保證。檢查結果與警示見 `QA.md`。

## 重建

安裝 `requirements.txt` 所列套件及 Blender 4.3.2。執行 `python build_model.py` 後執行 `blender -b -t 4 --python-exit-code 1 --python render_model.py`。`python rebuild.py --output NEW_DIRECTORY` 在全新目錄重建並比較四個核心輸出與五張 PNG。`python run_all_checks.py` 執行幾何、材質編輯、特徵及場景重開檢查。

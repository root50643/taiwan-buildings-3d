# 國立高雄科技大學｜第一校區（西校區）

本批 1 件局部外觀模型。全校及本校區都尚未完成，沒有宣稱完整建築數或完成率。

地址：東側：高雄市燕巢區大學路1號；西側：高雄市楠梓區卓越路2號。合併前／來源校名：國立高雄第一科技大學。

產創園區A棟位於西側。建築師頁的「燕巢校區」註記與官方第一校區地圖／地址衝突，採官方資料歸區並於模型來源完整揭露。第一校區東西兩側不是兩所學校。

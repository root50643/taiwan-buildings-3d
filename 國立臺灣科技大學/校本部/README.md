# 校本部｜國立臺灣科技大學

[回學校入口](../README.md)

這是依公開實拍自主建模的可3D列印外觀研究集。本批只有三件局部段，並未完成全校或三棟完整測繪。未見側背面以素面研究背板處理，不捏造窗格。各件含底座最大尺寸150毫米、獨立比例，附STL、Blender可編輯網格、參數腳本、來源與數位驗證。

原始第三方照片和PDF不隨公開包散布；只列來源URL與支持特徵。尚未做實際切片工具路徑或實體試印，不能保證可印或無需支撐。

# 國立屏東科技大學第二餐廳｜彩色完整外觀近似模型

[學校圖鑑](../../../README.md) · [內埔校本部](../../README.md) · [全部模型](../../../../README.md)

內埔校本部；本案是第二餐廳，不是第一餐廳。範圍包含高單層主方廳、四坡紅褐屋頂、中央方形低四坡採光構件、相連東側三片低坡服務翼與中央有頂灰平面，以及削角外廊、非對稱南北外階和局部半地下外露窗帶。不是只截取屋頂，也不包含鄰棟光電板或整校。

## 檔案與比例
- `model.stl`：單一封閉連通外表面，無材質。
- `model.3mf`：同一三角網格，8組可編輯基礎材質。
- `scene.blend`：同網格、可編輯頂點與材質、燈光與相機；不依賴外部照片或貼圖。
- `previews/`：5張真正最終網格渲染，非概念圖。
- `build_model.py`、`render_model.py`、`rebuild.py`：可重建幾何及五圖；`mesh.json`、`palette.json`保存頂點/面/配色。

展示外框約252 × 182 × 43.925 mm。圖示3970、1775、2570依建築圖常用厘米解讀為39.70m主跨等比例依據；模型3.5mm對應1m、約1:286，但並非竣工實測比例保證。外地台是有限展示支座而非地形測繪。X向東、Y向北、Z向上；西入口在−X，東翼在＋X，北階靠主廳中央、南階偏西，未作圖紙Y軸鏡射。

## 來源與版本限制
依1989年6月／1990年8月設計圖、官方1997年3月竣工記載、2012年5月遊記所刊的兩張第二餐廳外觀，以及拍攝日期未知的官方NLSC正射建立。不是2026現況或某一日四面逐窗實測；正射上NLSC2024浮水印不是拍攝日期。設計圖補服務翼和背側細部，小窗框、瓦紋、門扇與欄柵分格皆縮尺近似。採光頂依正射方形低四坡表現，不套用第一餐廳內景的16罩。

中央服務翼凹區是有頂廚房灰平面及周緣高側窗，不是挖通地的露天院。南北原服務院內細小後加物無法確證，省略，不聲稱現況全空。商店招牌、設備、內裝、地下內部與不可見屋頂空腔省略／實心化；玻璃是深色或灰綠不透明實體代理，可自行改材質，不代表真透光列印。

## 重建與驗證
Python需numpy、trimesh、manifold3d、shapely、rtree；Blender 4.3.2 CPU；lib3mf獨立驗證。
```sh
python build_model.py
blender -b -t 4 --python-exit-code 1 --python render_model.py
python run_all_checks.py --lib3mf-python /path/to/python-with-lib3mf --blender blender
python rebuild.py --output /new/empty/output --blender blender --threads 4
```
`rebuild.py`要求新目錄，驗證4個核心資料檔與5PNG逐位元相同。檢查碼見`SHA256SUMS`。本模型為非官方教育/視覺近似，不用於施工、結構或安全判定。

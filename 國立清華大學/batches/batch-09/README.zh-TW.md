# 清華第九批：2件公開外觀近似模型

李存敏館、竹屋（原住民族科學發展中心）。每件最長150mm含底座，獨立比例；本批manifest僅兩件。全校未完成。

兩件16項數位網格檢查通過，485/187個0.2mm抽樣截面閉合。李存敏館薄篩零警戒，竹屋3層厚坡屋頂收尖截面警戒，詳個別說明。柱廊、深框、出簷均需支撐評估；未正式切片、未G-code、未實體試印。

只用公開外觀照片，不重建室內或任何設備配置。李存敏館網眼與竹屋竹紋減量加粗，未知背面與各翼深度明示近似。參考照片不發布，未擷取官方原始3D資產。

南大推廣教育大樓目前僅低翼/曲牆外觀充分，主高樓與完整配置不足，留缺口；竹師會館來源多為內部展覽，缺足夠外觀。生科一二館、體育建物及整修中建築仍繼續補證，不泛化補數。

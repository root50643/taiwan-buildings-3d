## 保留原始結果與方法

舊版原 573 個朝下三角形、面積 `2661.308596 mm²`、所有原中心及垂直 first-hit gap 原樣使用；原 198 個薄弦與 156 層輪廓旗標未重新定義。R2 使用它自己的同方法原報告 585 面、`2693.694403 mm²`，沒有把舊面 ID 移植給新網格。面數或旗標數不同，不能單憑其增減判定可印性。

[`support_analysis.json`](support_analysis.json) 與 [`r2-support_analysis.json`](r2-support_analysis.json) 保存逐面 bbox、原 gap、下方最近實體三角形／接觸座標、實體支承參照截面及中心水平距離。屋頂斜皮的支承以 Z=33.000013 的上層實體腳印為參照，避免斜皮自己成為「旁邊承托」；上蓋以 Z=53.8 的窗帶實體為參照，其餘用各原中心 Z−0.000013。這是原中心的距離，並非全構件最大懸挑或承重分析。

每個原中心的半 gap 高度另試外部水平點路徑，原版 524/573、R2 536/585 找到直達外部的方向，兩版各有 **49 個未找到該測試直線出口**，沒有轉為通過，也不能據此說它們為密閉孔。構件的其他高度／轉彎路徑另以實體線量測補證；點路徑是零半徑，不是工具淨空保證。

## 可拆路徑與狹槽

後棟及入口的 207 條實際 STL 全直線交點、原面索引、可重跑原始碼見 [`support_access_review.json`](support_access_review.json)，易讀詳述見 [`support_access_review.md`](support_access_review.md)。所有線交點數為偶數。後棟／入口下列量測以舊件為準，R2 分群結果保留相同群範圍；沒有假定一條線足以證明整個通道。

- **前棟屋簷**：外露窄環狀出挑，原中心水平距 0.154–1.442 mm，屋頂 skin 與上層腳印的半徑差為 1.5 mm。外側有露台，下方 gap 約 6.75–17.69 mm，並非同高度的密閉房間。假如切片產生支撐，只能在外沿分段接觸、朝外或沿露台取出；尚未驗證有限工具能覆蓋所有弧段，原 11 個中間高度直線測試未找到出口仍保留。
- **R2 高側上蓋**：35 條補充線及兩個實體截面見 [`r2-clerestory-access.json`](r2-clerestory-access.json)。支承 bbox XY 為 `[-39,-10.5]` 至 `[-5,-5.5]`，上蓋為 `[-40,-11.5]` 至 `[-4,-4.5]`。前、左右、後側中央軸向出挑均實測 **1.000 mm**；前側角點對支承的斜向距離為 **1.414214 mm**，不能把 1 mm 當所有方向的最大距離。前側可向 −Y、左／右可向 ∓X，後側先向 +Y 到外部院落，可能受後棟阻擋，需要側向轉出。外露出挑不構成密閉孔；仍未證明實際支撐斷開／取出。

## 程式版本與重跑

原 `support_analysis.json` 對應 [`support_analysis_original_run.py`](support_analysis_original_run.py)，SHA-256 `46d7d0df5ff9fcafbbdc3c4a2bd2e98bf759dfe8bfb3517998ab9553e00c481b`。R2 對應 [`support_analysis.py`](support_analysis.py)，SHA-256 `7684ab1a372aa28631d3dcee07b8710945ff1302e69336f5838d10d0a8b12400`。後者只把輸入 thin count 的欄位改為可用於新報告的描述，幾何量測與分群相同。其他程式 SHA 亦在各輸出 JSON，原報及原版本均保留。

```text
python support_analysis.py --stl MODEL.stl --input-report MATCHING-EXTENDED.json --output NEW-support.json
python support_same_z_supplement.py --stl MODEL.stl --report NEW-support.json --output NEW-same-z.json
python support_null_chords.py --stl MODEL.stl --report NEW-support.json --output NEW-lines.json
python support_clerestory_r2.py --stl MODEL.stl --output NEW-clerestory.json
```

STL 與其原 extended 報告必須 hash 相符；不允許跨網格套用 face ID。不得覆寫原證據。未對有限工具、實際生成支撐或支撐拆除作通過宣稱。

# 官方校圖研究佇列

2026-10-13增量；與機構清册分開更新。

- `official-map-queue.json`：158校皆有研究狀態，35校已有44個官方地圖／導覽／建物索引入口。
- `official-map-links.csv`：相同連結的平面表。
- `campus-scope-observations.json`：成大、臺大、清大、臺東的來源範圍差異與去重提醒。

掃描149個非軍警官網，109個首頁成功讀取，40個未成功；其餘9校的教育部軍警原始資料不含官網，待另查。自首頁取得的連結不代表其內容就是完整建物名錄；也可能是導覽照片、VR、景點或交通圖。首次自動連結檢查40個入口，36個成功讀取；其後補3個已由網頁工具核對的入口及1個建模研究核對的清華官方PDF。每一筆保留獨立的驗證層級與後續步驟。

沒有發現連結不等於校方沒有地圖。HTTP失敗也不等於校方網站停用。需用校方子頁搜尋或瀏覽器補查。未處理學校明確留在佇列中。

這些是公開資訊入口，不是原圖或3D資產授權清單。不得把官網可瀏覽等同可下載再散布。全國逐棟盤點未完成、全國建築數未知；景點數與教室數均不可當作棟數。

# 國立雲林科技大學建物研究與續接

2026-10-21更新。已有7件外觀模型；雲旭樓及資訊大樓為局部範圍，尚未全校完成。

55個研究項目不是55棟建物。清單混合群棟、使用單位、構築物、局部段及範圍調查；圖書館／藝術中心和活動中心／相連表演廳各同群作一件。

## 範圍與狀態
- 官方現行入口連至2025校圖，教育部條目同一斗六校區。龍潭路南北及四維路側不另虛構分校。
- 智慧科技大樓ST與綜合教學大樓FB是不同位置；2026-09停車柵欄公告不當全棟落成日。
- 「未研究」不表示查無資料，實際查過仍不足的細節列在known_evidence_gaps。
- 國際園地／願景館與原員生餐廳的新舊翼對位尚未完成，不再以舊地圖同群標籤推定單一棟界。

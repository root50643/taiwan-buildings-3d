# 國立臺東大學校園建築模型：首批 3 件

本批為知本校區三個代表外觀模型；不是全校完成。師範及理工學院只做官方照片中的主要教學棟群，並未完整覆蓋院落、所有翼棟。臺東校區尚未建模。

- [圖書資訊館](../../知本校區/buildings/zhiben-library-information/README.md)：山形主棟及低層資訊翼的簡化外觀。
- [師範學院主要教學棟](../../知本校區/buildings/zhiben-teachers-college/README.md)：四層棟群與中央塔。
- [理工學院主要教學棟](../../知本校區/buildings/zhiben-science-engineering/README.md)：五層錯落斜頂與凸窗。

每件含 150 mm 最長邊 STL（含底座）、可重建程式、可編輯 Blender、由實際 STL 產生的正背面 PNG、來源、支撐說明及完整數位驗證。三件是各自獨立縮尺，不可直接組成同尺度校園。照片只連結、不再散布。未進行切片驗證或實體試印。

## 盤點與後續缺口

`campus_inventory.json` 記錄本次從實際檢視校方校圖所得的兩校區建物工作清單及缺口。知本校區下一批候選包括行政服務大樓、人文學院、鏡心書院、第一／第二學生宿舍與餐飲中心、學生活動中心暨綜合體育館。雖有主要外觀，仍需多面與最新現況核對。臺東校區有新舊圖名差異，暫不把歷史建物直接當成仍存建物。

現階段模型是可列印的外觀詮釋，不是測量級複製。看不到的背面留白或簡化，深度、屋頂及窗距估計詳見各模型 README。較早年代的公開照片不能保證 2026 年現況。沒有以重複立面或校圖框線虛造未見建築。

## 驗證

各件 validation.json 全數通過：原始 STL 法線、封閉性、邊與頂點流形、單一連通表面、無獨立內部空腔殼、正體積、最長邊 150 mm、乾淨重建 byte hash 與 Blender 三角幾何一致。檢查不代表已完成獨立全域自相交驗證、切片或試印。

原始程式在 Python 3.12 / numpy 2.5.4 / trimesh 5.1.1 / manifold3d 3.5.4，Blender 4.3.2 驗證。共用驗證及渲染程式沿用本儲存庫既有校園模型的作法再調整。

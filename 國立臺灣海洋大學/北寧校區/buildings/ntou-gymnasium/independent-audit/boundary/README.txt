NTOU revision independent full-ray boundary supplement

Place this folder at model/independent-audit/boundary. Run python run.py. Alternative: python run.py --model-dir /path/to/model-folder --output-dir /path/to/results. Requires Python 3, NumPy, and g++ with OpenMP. The model SHA must be 752b4c147bd18874b1c49890596c260e58015520f71f60cebc6ee6144700ef49. Original files are never changed. Scratch files are created in a temporary directory and removed on successful completion.

The original 15-point dense first-hit/parity strings and full 29 raw flagged rows are retained verbatim in inputs. They are comparison evidence only: every query index, source point and original winding normal is regenerated from model.stl and exact-source weights. exact_source.cpp uses 15 weights, not the author's earlier 10. Placeholder query coordinates are deliberately ignored because the source face/sample indices are supplied. No external sibling data or private paths are required.

Coverage: author same 10 points 56,300 rays, 12 boundary rays / 24 first-after triangle intervals, 8 raw parity flags. New 5 points 28,150 rays, 98 boundary rays / 385 intervals: 43 first-after rays / 96 intervals and 69 farther rays / 289 intervals. These ray counts overlap. Total 84,450 rays: 110 boundary rays / 409 original triangle intervals; first-after 55 rays / 120 intervals, farther 69 rays / 289 intervals. First-material boundary interval count is zero. All 29 raw flags have their reconstructed after probe on a positive-length exact original-surface interval. The author's 10-point 12/24 result is reproduced, not contradicted.

All 409 intervals have exact rational original-source-point coplanarity and parallel direction proofs, rational affine barycentric endpoints, and seven interior stations. Both sides are offset along each actual original triangle winding normal by 1e-5 and 1e-6 mm; the full original mesh solid-angle sum checks inward=1 and outward=0. Together with origin outside/inside, nine first-material stations, and three stations per nonboundary first-after gap there are 12,827 controls, zero failures at 1e-8. No on-surface winding is interpreted as air or material; boundary is never counted as a bulk extension. All original first-hit material intervals remain unchanged within finite precision (maximum boundary-ray delta 2.14e-14 mm; maximum across all 84,450 first-material intervals 4.12115e-13 mm).

Opposing coplanar verification has two independent parts: tolerant longdouble full expanded-AABB screen and exhaustive exact rational canonical-plane grouping. The exact check has 391 plane groups, four with both windings, 120 opposite coplanar face pairs, all with disjoint original AABBs. Therefore zero exact positive-area opposing overlap. This is not a general noncoplanar self-intersection test.

Finite-sample limitations and all tolerances are retained in result summaries. This supplement makes no global continuous thickness, printability, support-free or exception-approval claim.

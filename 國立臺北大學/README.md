圖書館模型不含後方低層資訊中心、通湖平台與其附屬樓梯；並非全圖資大樓完成。曲率、橋位、進深與少量遮蔽部位是竣工照片推估。

本批是手工參數化外觀近似，未抓取現成3D mesh。來源照片與PDF未重新散布。沒有實體試印，也不宣稱免支撐或保證可印。底座朝下，實際列印前請用切片器檢查屋簷、曲帶、跨橋與露臺。

## 新增：綜合體育館彩色凸窗入口立面段

本校目前 **3 套**，套件數不等於整棟建築數，非全校完成。此體育館立面段與既有圖書館、心湖會館不同；不是全體育館。

[![彩色凸窗入口立面模型](三峽校區/buildings/ntpu-gym-colored-bay-entry-facade-segment/previews/front.png)](三峽校區/buildings/ntpu-gym-colored-bay-entry-facade-segment/README.md)

依2019建築師正面照與校方低斜角照片建立的彩色凸窗入口立面薄切段，非完整四棟體育館。藍深凸窗有左實牆及右玻璃回折，黃窄凸窗、紅色低入口框、左凹陽台與穿空梁均為幾何；7材質3MF/Blend/STL，任意照片尺度及背面展示切面明列。原始單殼拓撲與252層截面通過，但0.75mm窗櫺局部0.8mm侵蝕失敗如實保留；須支撐與細節評估，未實印。

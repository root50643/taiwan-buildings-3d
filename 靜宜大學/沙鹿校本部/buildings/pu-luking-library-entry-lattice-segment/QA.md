# 數位驗證與限制

- 原始二進位 STL：2490 三角面、1099 頂點；1 個連通封閉表面，體積 147970.251299 模型 mm³。無壞面、重複面、非流形邊、面向錯誤、壞頂點 link 或非有限座標。只作精確座標焊接統計，未修補輸出 STL。
- 565 層：0.2 mm 未四捨五入的高度倍數加最高處減 0.001 mm。全部輪廓有效，每個正連通分量在 inward 0.4 mm erosion 後仍有面積，無薄片豁免。見 qa-layers.json。
- 66 個格孔（前 36／側 30）逐孔以九點候選探測至少一個穿透空氣路徑；斜撐穿越的格孔亦不被填死。另驗證 3 個架高入口前方空隙。見 qa/feature-validation.json。
- **局部細節損失非零**：每層 inward 0.4 / outward 0.4 mm morphological opening，最差在 z=108.800 mm，損失 1.674372 / 77.520029 mm²，即 **2.1599% 該層面積**。這不是總體積損失、切片器走線或實機測試；主要是角落圓化，不能用元件存活宣稱局部細節完美。
- 3MF 與 STL 精確三角座標／順序相同，lib3mf strict 無警告，實際改一種材質並寫出重讀，其他色與面指派保留；生成器重建 3MF、mesh.json、palette.json deterministic。見 qa/exchange-validation.json。
- Blend 重開精確比對網格與材質，再修改單一材質存檔重開確認；無外部貼圖、嵌入腳本或其他資產。見 qa/scene-validation.json。
- 五張實際模型渲染，全頂點位於安全畫框；見 qa/render-manifest.json。獨立來源外觀檢查見 qa/visual-review.md。

## 模型內容
根據花蓮縣文化局公開照片，自行建立二層長形主棟、上下連續拱廊、二樓欄杆節奏與日式雙坡長屋頂。模型範圍僅為主要展覽洋樓，不含其他館舍、松樹或園区設施。

- 尺寸：150 × 72 × 57.4 mm（含底座）
- STL 單位 mm；正面 −Y；底面 Z=0
- 單件、實心體量、封閉連通；拱廊是深盲凹槽，不是室內通道
- build_model.py 是原創可參數修改來源；scene.blend 提供可編輯網格
- 正、背面預覽都是實際交付 model.stl 的渲染，不另加建築美化物件

## 判讀與取捨
主要依據官方照片確認上下兩列圓拱、規律柱列、二樓細欄杆、簡樸灰牆及長向日式雙坡屋頂。參考照片有樹木遮擋及透視，未取得測量圖，長寬高和窗、拱間距由照片合理化；模型以十跨的規整節奏表現長立面，不聲稱復原精確實際跨數。完整背面與部分側面未被清楚拍攝，後窗列、山牆小通氣窗及深度是簡化推定，沒有做不存在的背面連續拱廊。二樓欄杆改成有直條淺凹的厚實矮牆，避免細桿易斷；瓦列及屋脊也有加粗。

## 建議列印
底面平放；PLA、0.4 mm 噴嘴、0.16–0.20 mm 層高、3 道外牆、10–15% 填充可作切片起點。拱頂與屋簷可能需要局部支撐，先看逐層預覽；不要把數位封閉檢查當成無支撐保證。窗框、欄杆凹紋與瓦列是小型浮雕，部分只有 0.4–0.8 mm 的可見起伏；建議保持原尺寸。未做實體試印。

## 重建與驗證
以 requirements.txt 的固定版本安裝依賴，建議 Python 3.12：

    python build_model.py
    python validate_model.py model.stl --output validation.json
    python verify_rebuild.py
    blender -b -t 4 -P render_preview.py
    blender -b scene.blend -t 4 -P verify_blend.py

validation.json 檢查封閉、單連通、面方向、所有邊二面共享、所有頂點單環及最長邊 150 mm。rebuild_validation.json 檢查原始 STL 法線、無負體積內殼、單一閉合邊界、Euler=2、逐層连续性及來源重建 SHA-256 相同。blend_validation.json 核對 Blender 主體與 STL。這些數位檢查不包含實體支撐測試與完全獨立的全域自交證明。

## 列印與組裝

主體、屋蓋均以各自 STL 的 z=0 平面置床。兩分件分開切片；場景預設為組裝姿態，不能直接把其位置當分件列印位置。主體中央實心頂台的頂面在 z=85 mm；將屋蓋在 x/y 置中並上移 85 mm，平面接觸後試放、再以適合材料的膠固定。此處是手動對中的平面對接，沒有插銷、卡扣、裝配公差或防呆定位機構。可在塗裝前以中央屋蓋兩邊各外伸 4 mm 為對中參考。

門廊採實心淺凹、階梯縮短；立面窗戶以最深 0.45 mm 的實心背襯凹紋表示。翼端開放柱梯填實；綠化、細欄杆、機電、招牌及室內省略。退台護牆設計厚 2 mm；這些是列印化簡，不能解讀為實際建築的封閉牆、無窗或實心門廊。分印屋蓋採實心平底，不含不可拆內部支撐。

本件未實體試印、未驗證真機耗材、翹曲、附著、膠合強度或裝配手感。主體在 45° 自動支撐 QA 設定下實際產生外部支撐；窗凹頂緣等小懸空的去支撐及表面效果仍待真機確認，不能宣稱免支撐。200 mm 長底座須確認實際可用列印範圍，brim 會額外佔床。窗凹紋只 0.4 mm，實際可見程度受噴嘴、層高、縮放與塗裝影響；縮小會降低護牆和紋理的可靠度。所附 generic G-code 僅為幾何 QA，必須以真機設定重切，不代表試印成功。

## 重建

使用 Python 3.13 與 [requirements.txt](requirements.txt)；在此資料夾執行：

```text
python -B source/build_model.py --output-dir models/rebuild
python -B source/render_preview.py
```

生成器讀取 parameters.json，不需要照片、網路、私人路徑或原作者檔案。渲染器載入固定 v2 的實際分件 STL；重新生成到其他資料夾後，請先比較輸出，再明確更新固定版本。STL 單位為 mm，沒有地理座標或宣稱統一校園比例。窗列與端部六條淺槽是符號化外觀，不代表實際樓層、窗數或開放梯間構造。場景材質僅便於辨識，STL 不帶顏色；預覽沒有新增來源之外的造型。

第三方原照、官方原圖／PDF、憑證及私人路徑不隨本套件散布。來源連結與本機實看檔案雜湊載於來源紀錄，以便讀者自行核對；這不授予第三方影像或建築設計的權利。

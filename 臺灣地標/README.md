# 臺灣地標｜38 組外觀研究模型包

收錄 38 組臺灣地標相關外觀研究模型包（含局部研究，不等於38棟完整建築），提供原創參數化模型、STL、可編輯 Blender 場景，以及由模型本身渲染的預覽。原有24座150 mm級模型之外，新增臺北表演藝術中心：2022完成設計的完整主建築比例詮釋，展示底板約258×218 mm；非現況測繪，照片日期不明。另新增北投圖書館完整歷史原設計外觀：2006完成設計及2026年4月整修前的有界近似，保留折變屋頂、溪側外露地下層、凹入陽臺與開口設備屏；不是整修後現況、測繪或校色真色。另新增日月潭向山行政暨遊客中心：2010完成設計的完整不等雙翼，含兩道透空雨棚、下降綠屋頂、凹入路徑及接地庭院；兩翼合計一套，不是2026現況測繪或校色真色。另新增大溪武德殿完整主殿：2014調查狀態、2000–2001修復後及2016廊道前，保留曲線入母屋、分離側門平臺與僅右側外梯；不是現今整個博物館園區或未改動的1935原貌。另新增埔里紙教堂：2008重組完成、2009照片佐證的完整單棟歷史近似，保留58根疏密橢圓紙柱、覆蓋中央的膜頂與懸吊細桿；不是1995神戶場地、整個園區、2026現況或臺灣竣工實測。另新增臺北府城北門／承恩門：依2017–2022公開來源系列建立的完整歷史外觀近似，保留真實透空拱形門洞、四向上層開口與連續瓦屋頂；照片拍攝及插入日期不明，F02與F04為同一短向面，不是確定拍攝年份的測繪復原或2026現況。另新增旗後燈塔完整連接主建築：依2020年第一期竣工圖與完成照片建立八角塔、短連接頸及整個辦公展示翼的單棟外觀近似，保留四向開口差異、低平翼頂及開放塔側退凹；不含整個園區，不是2026現況測繪。完成照片支持的燈室白色斜格與上緣、玻璃下暗帶已逐構件勘誤，色值仍為未校準近似。各包尺寸與列印限制請讀專屬README。

## 使用前先讀

- 單位為毫米（mm），各模型以獨立成品大小設計；原有24座最長邊約150 mm，新增臺北表演藝術中心的底板約258×218 mm。38組模型包並非共同比例，不能用來反推真實建築尺寸。
- 模型依公開外觀照片等資料重新建立幾何，屬桌上型外觀詮釋，並非測繪、工程或官方授權模型。未確認的背面、屋頂與細節可能經過推定、簡化及加粗。
- 數位網格驗證不等同切片或實體試印成功。尚未完成實際切片測試及實體試印；列印前請檢查逐層路徑、薄壁、懸垂、支撐與拆除空間。
- STL 不包含預覽材質或色彩。Blender 場景的地板、相機、燈光只供預覽，請勿當作列印模型匯出。
- 本庫不分發參考照片；各模型 README、sources.md、參考來源.md 或 source_review.json 保留來源網址及建模限制。第三方照片、建築設計、雕塑與商標權利不因本庫公開而獲得授權；商用或再散布前請自行確認適用權利。

旗後燈塔的[專屬README](qihou-lighthouse-main-2020/README.md)提供九張實際模型視圖、公開數值重建與79個可編輯組件；保留第一期歷史範圍、竣工圖需現場覆核、尺寸鏈差異及未校準材質限制。水平剖面為模型切面，不是原始圖面；來源署名與特定資料集174433之OGDL條款另列，原始PDF、照片、職員資料與私人審查不公開，不表示第三方建築設計權利一概放行。

松園別館為既有主棟的限域材質升級，不新增建築、不改原 STL 幾何；僅正面有來源支持的屋頂與砌體補色，背面、側面與門窗凹槽保留未驗證中性材質，不是全館真實色彩復原。六張實際模型視圖見[預覽目錄](pine-garden/previews/)；離線材質重建與新版檢查依[專屬 README](pine-garden/README.md)，不沿用下列舊檔名流程。

原有交付目錄包含 build_model.py、requirements.txt、render_preview.py、validate_model.py 及數位檢查結果。請在該模型目錄依其 README 安裝相依套件並執行重建；不同模型的參數和重建流程可能不同。

- model.stl：列印用幾何。
- scene.blend 或 editable.blend：可編輯模型與預覽場景。
- previews/：實際模型渲染圖，並非建築實景照片。
- validation.json 及其他檢查報告：原交付包的數位檢查結果，公開整理時未重新執行全部建模或切片流程。
- publication-manifest.json：公開檔案大小、SHA-256 與 Git blob SHA-1；清單不列自身，避免循環雜湊。

## 公開整理與完整性

18 個原始交付壓縮包涵蓋 24 座模型，均通過 ZIP CRC 完整性檢查；原包附帶的 228 筆 SHA-256 校驗全部相符。初次公開整理時，STL、Blender 場景、建模原始碼和預覽圖維持原交付位元組；松園別館本次僅原 STL 與幾何作者程式維持原位元組，材質場景、預覽及重建檢查已依專屬 README 升級。三份 validation.json 移除含暫存工作路徑的 rebuild_stdout 記錄欄位，相關校驗清單已更新；數位驗證數值未變更。沒有加入研究照片、私人下載連結或執行日誌。

## 龍虎塔 STL 下載方式

龍虎塔的 STL 較大，另以 Release v1.0.0 附件提供：[下載 dragon_tiger_pagodas_150mm.stl](https://github.com/root50643/taiwan-landmark-buildings-3d/releases/download/v1.0.0/dragon_tiger_pagodas_150mm.stl)。GitHub 的原始碼 ZIP 不包含此 STL。請將下載檔改名為 model.stl，放入 dragon-tiger-pagodas/ 目錄，再依該目錄 README 執行驗證或預覽。檔案幾何與既有驗證雜湊維持不變；publication-manifest.json 將此檔標記為 release_only。

# 燕巢校區

地址：高雄市燕巢區深中路62號。目前收錄圖資大樓一套整棟可見地上外觀近似；全校另有和平校區兩套，非全校完成。生科大樓A、B須分辨；燕窩1樓學生餐廳不另計獨棟；圖資大樓又稱圖書及資訊大樓。

燕巢圖資大樓（圖書及資訊大樓）：約2011–2012完工期整棟可見地上外觀比例近似，兩翼、中央封閉大廳、凸弧玻璃、完整屋面、入口平台／真通道、外梯及後露臺合計一套；不是和平圖書館、高科大燕巢圖書館、竣工圖或已確認2026現況。前方外弧為花台／坡道不是房間；最低弧門為1F、窗帶不等於樓層，不臆造隱藏B1。約1:400、245×215mm展示底板不是實際基礎；4660×3240cm尺寸鏈不等同外牆／挑簷外緣，6884.74／7481m²差異不平均硬套輪廓。架高周邊薄帶、圓形採光環斜撐與兩側不同翼向保留；局部視角east/west/south檔名不代表地理測量方位。7材質3MF、STL、可編輯Blend與467隱藏建構分件、公開Python及9張建築檢視圖與1張統一角度代表圖；重疊分件不與外殼同印。204截面、19空間射線、完整自交掃描與8控制、原生編輯及公開輸入重建通過；約0.6mm細件、平台／屋簷／採光環需支撐與尺度評估，未真正切片或試印、非免支撐認證。個別照片日期不明，2012簡報預定開館日不當成已核實實際開館。

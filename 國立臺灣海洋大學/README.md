## 使用
各模型資料夾提供STL、可編修scene.blend、獨立參數重建程式、實際mesh多視圖預覽（新夢泉另含上色3MF）、來源、數位檢查與SHA256。單位是毫米，底座朝下。請閱讀各模型的支撐與薄件警示。

原始STL水密與拓撲、原始法向、單表面、獨立重建SHA、Blend幾何一致及0.2mm封閉有效輪廓均檢查；0.8mm形態opening是輔助篩檢。沒有實體試印或Cura／PrusaSlicer實際工具路徑驗證，不保證任何機器或材料均可直接列印。

[首批歷史檔案SHA256](SHA256SUMS) · [2026-10-13舊版歷史驗證摘要](batch-validation.json)。該歷史摘要綁定舊體育館STL SHA 0e59d54a22fcad3dbfac8ac30a16743165768828504982a66c0d62b824fac3f0，當時all_passed不能套用這次新STL；現版請讀[原始QA摘要](北寧校區/buildings/ntou-gymnasium/qa-summary.json)與[獨立修版限定裁定](北寧校區/buildings/ntou-gymnasium/INDEPENDENT-REVISION-AUDIT.md)。來源照片與PDF沒有重新散布。

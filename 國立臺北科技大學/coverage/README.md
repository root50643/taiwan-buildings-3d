## 現況與棟界關鍵修正

- 2024-11校史館已遷至一大川堂。紅樓、宏裕3樓的舊「校史館」不另算建物。
- 林森舊誠樸樓拆改，現名隆玉科技大樓；2022竣工、2025-09揭牌。先鋒國際研發大樓的工程名為精勤樓。
- 臺北目前另有2025新增建啤校區；只有部分啤酒工場基地撥用，不能把全廠建築都算北科。
- 校外場域除新北、南港宿舍，還有圓通雅筑宿舍及桃園虎頭山進駐基地。南港僅敬業樓5樓；租用範圍不是全棟所有權。
- 萬里（含新北與基隆統計分列）、龜山未開發；草漯／觀音校地與智慧綠能共創基地是同一基地。學校面積統計版本有差異，不拿土地面積推建物數。
- 東校區第二期教研大樓、多功能中心與大安職務宿舍需最新工況；工程首頁「進行中/未動工」多處落後於其他官方資訊。

## 如何續接

[remaining-evidence.json](remaining-evidence.json)逐筆列來源URL、別名、範圍、狀態和下一步。「未研究外觀」代表尚未逐棟搜尋，不代表公開資料缺乏。真正已查的缺口是新地圖平台讀取失敗、建啤撥用棟界、局部川堂以外的修復後屋頂／兩翼照片，以及施工案缺少最新完工實拍。

優先順序：
1. 補一大川堂完整L形與屋頂實拍，擴充新的局部或全棟版本，保留已凍結首版。
2. 宏裕、第六教學、行政與圖書館合列群先核棟界；續補先鋒後面及屋頂、億光最新修繕後細部及首層遮蔽、隆玉側後面。三案已查來源與實際缺口見JSON。
3. 依清單逐棟處理西校區常設校舍，留意2025三教翻新。
4. 宿舍依最新修繕後實拍與租用樓層邊界製作；群棟與場域不可用一個代表模型充作全校完成。
5. 建啤先查移交圖與文資管理範圍，再做特定現存棟；未開發校地不虛構建物。

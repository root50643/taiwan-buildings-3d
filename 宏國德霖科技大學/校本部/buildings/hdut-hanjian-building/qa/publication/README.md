# 公開檔案與原始證據

科學原件保留在 AUTHOR-SCIENCE-FREEZE-v14.json 所綁定的私人備份。公開包的原件拓樸、逐層 Polygon、全部 dense CSV、flags、exact contact 與同次原 hex 補證均保留原 byte；不清理或重寫這些數據。

SOURCE-RENDER-VERIFICATION.public.json 只將執行命令內的機器絕對路徑映射為 ${MODEL_ROOT} 與 ${PYTHON}。PUBLICATION-PATH-PROJECTION.json 記錄原檔／公開檔 SHA256、每一個變更 JSON pointer、原字串 hash 及公開字串；其他 JSON 結構與值逐項完全一致。這是有標示的路徑投影副本，不冒充原報告。

例行 stdout/stderr 與已被正式說明取代的早期白模計畫不散布，逐檔原 hash、大小與省略原因保留於映射表。數值結果、flags 和觀測資料不因省略日誌而刪減。原 raw PNG 只提供 manifest/hash，公開 PNG 的 IDAT／RGBA／色彩 metadata 不變，僅移除白名單 File／時間文字欄位。

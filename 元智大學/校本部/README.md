含底座123×150×54.3mm。保留西斜收大口、懸盒和圓柱、兩覆蓋中庭、南低擴建及獨立西南窄翼。北窗無證省略；東北停車坪為地面。31m主屋面／12.2m南翼等均為跨年影像配比，不是測繪分翼標高；低翼樹遮牆基與B1地腳仍未知。原照片／PDF不隨公開包散布。

數位原STL與重建檢查通過；6筆具體角損樣本來自最上階踏2跨層、東突出竪牆頂4跨層，不是6支柱，最大3.1487690%損失、96.8512310%保留。全部角內／法向／下根明細見建物QA，仍須統一獨審重算裁定；未試印、非全域最小壁厚證書，大口與懸盒需切片支撐評估。

## 續作範圍
其餘教學、行政、宿舍及校園建築未在本批建模。研究條目、設施點與鄰樓不當完成件數；後續依官方校圖及各棟來源續接。

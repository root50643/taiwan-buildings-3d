# 臺灣建築物 3D 模型

依地點整理的臺灣建築外觀模型集，收錄 **450 組模型／列印包**：原有國立聯合大學 38 組、國家衛生研究院竹南院區 9 組、臺灣各地地標 24 組，另新增下列大專校院 379 組。模型套件數不等於獨立建築棟數，也不表示全校或全國完成。

每個地點資料夾保留模型、可編輯原始檔、Blender 場景、實際模型預覽、來源說明與既有驗證資料。點選下方圖片，進入該地點的三欄建築圖鑑；個別模型的詳細資訊可展開查看。

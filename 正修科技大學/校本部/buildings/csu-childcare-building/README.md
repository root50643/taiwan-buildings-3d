正修科技大學校本部，幼兒保育館／幼保大樓，館號22。完整獨立主棟：六層＋局部屋突，不是七層全樓、同校幼兒園或後方圖書科技大樓。以2024-08-27雙向空拍為版界，不宣稱2026現況；較早近照只補仍吻合下部。非官方、非測繪、非結構工程模型。

## 檔案
- `scene.blend`：可編輯三角mesh，8組實材質；不是只有貼圖或不可編輯預覽。
- `model.3mf`：同一幾何，8種基礎材質；多色能力仍依切片器與印表機。
- `model.stl`：同一三角表面，STL格式本身不含顏色。
- `mesh.json`、`palette.json`：幾何／逐面材質及sRGB色票。
- `previews/`五張：直接由交付3MF幾何生成，無AI重繪、無參考照片或鄰棟。
- `build_model.py`、`render_model.py`、`rebuild.py`及驗證程式；QA結果見`QA.md`與`qa/`。

## 主要辨識特徵
前長面波折窗帶與豎肋、右側寬玻璃核／獨立窄玻璃帶、上部白弧帽及三狹窗與低露臺；後長面平直窗帶、低兩層棕框、挑簷與透空格梁。兩端分別為具白色實牆／真三角與矩形孔的轉折梯／弧形平台，以及具成對大窗帶的較整片高直塔。第六層退縮；中央高白盒旁接低淺弧金屬頂。六組分離、不同高程的PV表達主要分區，不聲稱逐片精確數量；支架下保留空間。後面兩層高棕色入口格架、底層真退凹門廊與低階保留透空。

## 明示近似與列印處理
照片相對比例，不虛構真實公尺尺寸；展示尺寸270×84×144 mm不是建築實測比例。基座非實測地形。主體室內實體化、玻璃不透明，未建立室內或地下。前窗為沿波折牆面的有色實體表層，不宣稱窗洞深度測繪。細管線、空調、玻璃磚小格、欄杆及精確PV片數省略或簡化。外露階梯踏步、平台、屋面／PV邊帽和支架適度加厚，保留大輪廓與可見負空間。

PV表面格線名義寬0.35 mm，附著於板片而非自由懸空桿，可能低於常見噴嘴可辨細節；全局截層0.8 mm檢查不是所有局部厚度保證。階梯、挑簷、格架、PV及弧頂有懸挑，須自行評估方向、支撐、噴嘴與材料。未做實體試印，不承諾免支撐。

## 重建
Python 3＋numpy/trimesh/manifold3d/shapely/rtree；交換驗證另需lib3mf；Blender 4.3.2或相容版本。正式輸出用CPU Cycles 48samples，1200×1200。

```sh
python build_model.py
blender -b -t 4 --python-exit-code 1 --python render_model.py
python run_all_checks.py --lib3mf-python /path/to/python-with-lib3mf --blender blender
python rebuild.py --output /new/empty/directory --blender blender
```

重建腳本要求不存在的新目錄，實核四個core檔和五張PNG完全相同；不承諾不同Blender版本的圖像位元一致。發布時仍需維持既有首頁代表圖，不以本模型替換使用者選圖。

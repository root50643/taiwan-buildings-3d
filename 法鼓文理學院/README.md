## 新增：大願橋中央裁切片段

本校目前 **2 套**，套件數不等於整棟建築數，非全校完成；此橋不同於揚生館模型的局部小橋。

[![橋段模型](金山校本部/buildings/dila-great-vow-bridge-middle-span-segment/previews/front.png)](金山校本部/buildings/dila-great-vow-bridge-middle-span-segment/README.md)

大願橋官方實景 A/B 自選裁切中央片段，非整橋或真實接縫。單側外傾高箱梁、對側低開放欄杆、橫木板、約13外肋與緩曲度；5材質3MF/Blend/STL。相對展示尺度，未以整橋108m換算；不虛構端部或橋墩。原始單殼拓樸及125切片輪廓有效，近頂微片未通過0.8mm侵蝕、細木條和板縫可能丟失，底面需規劃支撐，未實印。

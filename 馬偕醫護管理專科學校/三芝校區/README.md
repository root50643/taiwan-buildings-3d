## 範圍與限制

三芝綜合大樓（共同教室大樓）完整地上主棟外觀近似：五層長體、中央服務核、三段異高坡頂、不同前後玻璃帶、兩端與入口階梯；選無PV作者照片版本。258×92×115.95mm、8材質Blend/3MF/STL及5實mesh圖，27992面單閉殼，580層0.8mm分量侵蝕與格式真編存讀、乾淨九檔重建通過。後基部窗與坡地收口遮擋近似，不含鄰棟、低綠場地、湖或地下室內部。2019是完工年非確定拍日，NLSC2024水印非航拍年；非測繪或2026現況，未實印、需支撐評估。

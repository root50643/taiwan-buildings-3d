# 國立臺東大學第三批：兩件知本與一件臺東校區模型

本批三件為第一、第二學生宿舍主要棟群、食品生技實習工廠（原中正堂）。這不是兩校區全校完成。宿舍僅主要棟群；第二宿舍旁餐飲中心另列；人文學院與第一批學院的遠側翼棟仍部分未完成。

鏡心書院D棟因導覽照片可能同時涵蓋A/B及D、無法排除重複而隔離，不納入本批或完成數。

所有模型最大尺寸150 mm，各自獨立縮尺；提供STL、Blender、可攜原始程式、實際STL預覽、來源與近似、支撐需求、原始STL及0.2 mm截面驗證。未做實體試印或切片器驗證。照片不再散布。

完整建物盤點將以113學年度官方年報45項建築資產和兩校区地图交叉更新。年報第46列是合計，不是第46棟。資產項不一定等於獨立樓棟；共同教學大樓可能含多棟，不能把資產項數冒充精確建築棟數。

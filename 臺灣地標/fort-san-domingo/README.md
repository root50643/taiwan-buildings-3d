# 淡水紅毛城主堡｜150 mm 桌上外觀模型

依新北市立淡水古蹟博物館官方摺頁的主堡照片、空拍與建築介紹，重新建立紅毛城主堡外觀。保留方形厚實堡體、平屋頂、東北與西南兩個突出角樓、南側磚造露臺與小斜頂門廊。這一件不含旁邊另棟英國領事官邸。

## 檔案與尺寸

- `model.stl`：毫米單位，150 × 140 mm 底座，精確全高與面數見 `validation.json`。
- `editable.blend`：由最終 STL 匯入的可編輯網格；開啟時已選取可列印物件。STUDIO ONLY 集合只是攝影棚，不要一起匯出。
- `build_model.py`：原始參數化程式，可調整堡體、角樓、露臺與簡化細節。
- `previews/front.png`、`previews/rear.png`：直接渲染實際 STL，沒有另加非列印裝飾。
- `validate_model.py`、`validation.json`、`SHA256SUMS.txt`：法線、封閉性、拓樸、獨立重建一致性與交付檔案雜湊。

南側露臺朝向模型 −Y。此為照片判讀的桌上模型，非建築測繪或精密等比例復原。各地標個別以 150 mm 最長邊縮放，彼此不是共同地理比例尺。

## 為可列印而採取的簡化

- 主堡內部完全以實體填滿，不製作穹窿、室內隔間或展覽空間。
- 主堡屋頂只保留上方開放的淺露臺，非密閉空腔。南側露臺下方同樣是實體。
- 角樓挑出的托座加厚並作斜面，避免原本細小、易折的懸空構件。角樓並未錯置成四座大型城堡塔。
- 主堡牆面以大片平整粉刷面表現，保留稀疏淺窗凹；沒有替換成規則密集窗格建築。露臺與角樓磚縫縮減為淺橫線。
- 露臺窗門、門廊柱列皆做淺凹／附壁式，不做可進入的洞或穿透內部。
- 國旗與細旗桿、古炮、樹木、園區南門及領事官邸不在本件範圍內。
- 完整背面近照及測量圖不足；背側開口、露臺精確磚紋與細部尺寸採保守簡化。模型不能當作原建物所有開口位置的精確紀錄。

## 列印建議與風險

建議 PLA、0.4 mm 噴嘴、0.16–0.20 mm 層高，以平底座朝下；3 圈牆，12–20% 填充可作起始設定。STL 是幾何實體，切片時仍可使用一般填充率。

角樓懸挑、門廊小屋頂與石壓頂有伸出部分，請先在切片器檢查支撐；角樓下方尤其建議評估局部樹狀支撐。細磚縫約 0.30–0.36 mm 高，0.4 mm 噴嘴可能弱化，這不影響主體形狀。大型底座可依附著力加 brim。

目前只完成數位模型驗證，未實際切片或試印，未保證任何印表機皆能無支撐成功。

## 重建及驗證

Python 3.12 與 `requirements.txt` 內套件；Blender 4.x 供 .blend 與預覽：

    python build_model.py
    python validate_model.py
    blender -b -t 4 -P render_preview.py

檢查包含有限座標、非退化面、封閉性、單一連通邊界、每邊恰接兩面、每頂點單一閉環鄰域、儲存法線、正體積、Euler 特徵數 2、平底 Z=0、150 mm 最大尺度，並另起程序重建比對三角面。建模使用 manifold3d 實體布林運算，未另做三角形互交檢測。不可用於工程、保存修復或建築測繪。

另附 `check_blend.py` 與 `blend_validation.json`，驗證 .blend 中可列印物件的每一個三角面與最終 STL 一致。重跑方式：

    blender -b editable.blend -P check_blend.py

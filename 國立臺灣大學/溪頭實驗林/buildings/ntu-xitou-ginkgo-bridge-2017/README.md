# 銀杏橋（2017竣工外觀近似）

**國立臺灣大學｜溪頭實驗林完整橋梁地標外觀近似。** 以2017年設計團隊的完整平／立面與施工、竣工照片為依據，保留整座主橋、兩岸橋台及有限範圍的接續落岸。不是中央單跨抽段，也不是大學池竹拱橋；**不是2014年尖角40m方案，更不是2026年現況測繪。**

![同一交付網格的整橋斜視：雙峰中央下凹、雙墩四扇與透空橋底](previews/front.png)

## 保留的完整外部構成

- 主橋採官方2017版本的**36m＝8＋20＋8m**。橋身平面為直線，橋面、兩側主梁及扶手沿長向形成**端部→峰→中央谷→峰→端部**的連續圓曲輪廓；不是S形平面、單一上拱或平橋另掛兩個拱。
- **2個跨橋寬的RC主墩 × 每墩兩側各1扇＝4扇木構支架；每扇4道主肋，共16道。** 保留曲直不同的扇肋與銀灰鋼足座，不把後排扇架的透視投影重算為第五道肋，也不將橋墩改成四根獨立柱。
- 兩側起伏厚主梁、木橋面、橋底橫梁及斜撐；扇肋之間、兩排扇架之間與橋底仍有**真實幾何負空間**，不是填實扇板或整塊橋體。
- 隨橋面起伏的分格木欄，具**銀杏扇紋與變向斜格**，不是全橋同方向的平行斜條。端部接續欄以較直立的木條區別。
- 兩端橋台、完整兩側邊跨、右岸短落岸，以及2017平面圖所示**左岸轉折接續階梯**。轉折僅出現在左岸引接，不使主橋變彎。

## 尺度與近似界線

官方文字明列主橋長36m、中央跨距20m、總寬2.0m、淨寬1.6m及橋高3.08m。本模型以**名義1:120**轉換主橋全長與寬度：主橋長300mm、總寬約16.67mm；基座、橋台及接續階梯使整體包絡尺寸大於主橋本身。**官方「橋高3.08m」的定義不能直接等同包含基礎與底板的模型總高。** 目前交付包絡354×62×54.95mm（含底板及橋台）；請先確認設備成形空間，不宜為了塞入平台而忽略細欄縮小後的線寬。精確網格數量與驗證見[QA](QA.md)。

這個名義比例**不表示所有細節已按實測縮尺**。橋面曲率及各點高程、木肋截面與曲線、鋼件厚度、橋台進深與露出高度、階梯角度／階數、木板、欄格及螺栓數量均為圖像推估或規則化簡化。程式目前以每側30格表達主要欄杆節奏；這是模型細分，並非來源確認的實物精確格數。照片色彩受光線及表面狀態影響，配色為材質辨識近似，非現場色票量測。

最下方的薄矩形底板是**額外加入的展示／列印連接板，不是溪床、地形或基地界線**。2017圖所示隱埋聯合基礎未重建；不可將底板或獨立露出橋台解讀為真實地下結構。森林、岩石、溪流、整段步道、人物、施工防護網、鷹架、吊車、臨時管線與材料均不在交付範圍內。

2016年底吊裝、2017年4月初土木工程完竣，以及環境復原後**2017-05-28正式啟用**是不同事件。2017文章刊載、2018作品頁網址年月及2024講義日期都**不是每張照片的拍攝日期**；來源影像沒有可用的相機拍攝日期可據以逐張定年。2026-10-22僅為本次資料研究日期，不宣稱當日現況。2014尖角40m方案及2023轉載所寫40m與採用的36m資料不同；本包不混用，也不自行解釋40m必然包含引道。[來源、差異及使用界線](SOURCES.md)。

## 材質、編輯與列印限制

Blend與3MF保留**8種全不透明逐面材質**，區分主木構、深色欄框、淺色木橋面、銀灰鋼件、RC、額外底板、橋底深色構件與細木板縫。STL不含顏色或材質；3MF的顯示色不等於已配置多材料列印機。

交付為**融合網格**，可編輯頂點、逐面材質及生成參數，**不是已拆分零件、可動結構或工程裝配套件**。修改幾何、材質或生成腳本後，應重新生成五圖、執行驗證及更新hash，不沿用舊審查結果。

**未實印、尚未證實可列印，不保證免支撐。** 此模型狹長，細欄約0.55–0.60mm，另有細小螺栓、鋼件、橫梁及橋底斜撐；薄件脆弱、長跨橋接、懸挑、變形與支撐拆除均有風險。原始拓樸、全局切層、局部薄件／空氣佔據與懸挑報告保留警告，不能為消除警告而封死扇孔。水密或單連通不等於強度、支撐或實印認證；請依設備、材料、縮放與擺向實際切片，必要時放大、分件或調整構件後重新驗證。[完整QA](QA.md)。

## 重建與驗證

環境與版本見`requirements.txt`，Blender為另行安裝的可執行程式。使用相同依賴、Blender版本與CPU渲染設定，從模型目錄執行：

```bash
python build_model.py
python qa_model.py
python check_features.py
blender -b -t 8 --python-exit-code 1 --python render_model.py
python verify_exchange.py
blender -b -t 8 --python-exit-code 1 --python verify_scene.py
blender -b -t 8 --python-exit-code 1 --python verify_render.py
python rebuild.py --output ../independent-rebuild-new --blender blender --threads 8
python verify_package.py
```

`rebuild.py`要求不存在的新輸出目錄，並比較`model.stl`、`model.3mf`、`mesh.json`、`palette.json`與全部五PNG的bytes。最終來源審查另以STL及五PNG的hash綁定；它不是結構計算或實測證書，數值結果以交付QA檔為準。

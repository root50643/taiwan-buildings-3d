# 臺北醫學大學信義校區教學大樓：來源摘要

範圍為教學大樓2021–2022修復後主體，以2023–2024公開照片為依據；未含廣場鐘樓。教育部115學年度代碼1028，前身臺北醫學院不另計校。不是教研大樓、醫檢大樓、附醫或雙和教學研究大樓。

## 直接資料、估計、未知與製造替代

教學大樓三層、14間教室（4+5+5）、兩座U梯及一側凸電梯。NE格柵僅限中段，兩端寬紅磚實牆；SW是開通廊，單一電梯靠NW並有短橋。1F中央穿堂有2F、3F及屋面覆蓋，不是天井。修復後石拱只在有證據的中段，兩端保留直線柱窗。

82m為校方總長且量測端點未定義，4.5m是歷史層高；主屋面13.5m為計算值。名義1:400，進深取約16m並保留16–18m量級；電梯高度、遮陽、拱口、女兒牆與屋頂兩端欄杆配置皆為推估。SE短端沒有完整來源，低細節實面不表示已證實無窗；NW相對方位依場地推定。未知包括完整標高剖面、精確格柵數量、屋頂機電與2024之後完整現況。

模型77道格柵加厚為1.2mm、七拱、圓角／接根、厚化樓板、欄杆及樓梯坡段均屬製造簡化，不冒充實測構造。未加入鐘樓、歷史大雨庇、未定年光電或未知設備。完整分級見[估計與簡化](../../信義校區/buildings/tmu-teaching-building-restored/ESTIMATES-AND-SIMPLIFICATIONS.md)。

# 中臺科技大學天機教學大樓

2004 年完工建築的原創、有界外觀模型。本件只涵蓋天機教學大樓，並非全校完成。原名亦見「綜合教學大樓」；不含鄰棟耕書樓、勤學樓或保健大樓。

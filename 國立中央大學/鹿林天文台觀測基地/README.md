# 國立中央大學｜鹿林天文台觀測基地

**校外觀測基地，不是桃園校本部。** 位於玉山國家公園塔塔加鹿林前山，依[官方介紹](https://www.lulin.ncu.edu.tw/about/)辨識；本分類不是教育部校區地址名錄的擴充認定。

目前1件：SLT主建築1999，2022–2023白色可見外觀近似。不是粉紅LOT控制中心或整座基地，並非2026現況調查、全基地或全校完成。尺寸推估，新增展示底板；薄件與支撐警告保留，未實印。

**合心樓2A既有模型：** 含底座137.5×150×27mm。保留弧面北玻璃、北／東真架空、南實牆上窗、D玻璃連接、E雙層深門廊及F/G抬高平頂。高度A16m（14–19m試配）、E13m（11.5–15m）、F/G14.5m、低頂11.8m，全為跨年影像推估，非測繪。F/G高差1–4m候選採2.7m；低頂精確層位與小天井仍未核，採實底近似，不能把影子當通洞。西側未知窗省略；原照片／PDF不附包。

248高loss是8支方柱各31層樣本，最大3.104916569%／保留96.895083431%，全原真角0.41mm內；原面／根及WKT已記錄，具體例外仍待獨立審查。北東角已留背靠角柱；0.390625mm淺框側緣有向內實牆根≥32.035931mm，是背靠浮雕，不是獨立薄片。各厚度只限指定檢查，不是全局最小壁厚。未試印、不保證免支撐，縮小後須重檢。

[大喜館｜整館光電前外觀近似](中央校區/buildings/tcu-daxi-gymnasium/README.md)：中央校區大喜館：東北低入口翼、西南高球場主館與道路側兩排開放停車棚合為一套光電前整館外觀近似；早期照片及2010／2013街景約束，較晚影像只佐證持續拓樸，非精確2003竣工、單日或2026現況。2003年2月建築師完工記錄與校方2003-02-11清冊保留；11,641m²權狀／11,819m²作品面積不換算占地或高度。寬主屋面加窄架高弧罩，操場側真開拱廊／上層退廊，路側封閉拱窗與低位矩形窗帶不鏡像開洞；雙棚下空間開放、中央走道5mm，低翼高屋面為退縮屋頂量體不是深中庭。118×248×71.9mm為含展示底板正規化模型尺寸，非實測／精確縮尺。8材質3MF、STL、可編輯Blend與736隱藏建構分件、公開Python及9張實際圖；隱藏重疊構件不可與外殼同印。未加光電、後期閘門、室內、地基、鄰棟或未明設備。1.2mm棚柱、1.0mm棚頂／天光罩及0.35–0.44mm附著浮雕為模型厚化；棚頂／拱廊／門廊／外梯需支撐橋接，248mm底板需確認平台，未真正切片或試印、非全域最小壁厚證明。
